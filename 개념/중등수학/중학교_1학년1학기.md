## I. 소인수분해

### 01 소인수분해

#### 핵심 개념

| 용어 | 정의 | 예시 |
|------|------|------|
| **소수** | 1보다 큰 자연수 중 1과 자기 자신만으로 나누어지는 수 | 2, 3, 5, 7, 11, 13, … |
| **합성수** | 1보다 큰 자연수 중 소수가 아닌 수 (약수가 3개 이상) | 4, 6, 8, 9, 10, … |
| **소인수분해** | 자연수를 소수의 곱으로 나타내는 것 | 12 = 2² × 3 |

> ⚠️ **주의:** 1은 소수도 합성수도 아니다!  
> 💡 소수 중 유일한 짝수는 **2**이다.

#### 소인수분해 방법 (나눗셈법)

1. 가장 작은 소수 **2**부터 차례로 나눈다.
2. 몫이 소수가 될 때까지 계속 나눈다.
3. 나눈 소수들과 마지막 몫을 모두 **곱**으로 나타낸다.

**예시: 72를 소인수분해**

```
2 ) 72
2 ) 36
2 ) 18
3 )  9
     3

∴ 72 = 2³ × 3²
```

**예시: 120을 소인수분해**

```
2 ) 120
2 )  60
2 )  30
3 )  15
     5

∴ 120 = 2³ × 3 × 5
```

#### 소수 판별법

√n 이하의 소수로 나누어 떨어지지 않으면 소수!

> 예: 97 → √97 ≈ 9.8이므로 2, 3, 5, 7로만 확인하면 됨

#### 약수의 개수 공식

A = p^a × q^b 이면 **약수의 개수 = (a+1)(b+1)**

> 예: 72 = 2³ × 3² → 약수의 개수 = (3+1)(2+1) = **12개**

### 02 최대공약수와 최소공배수

#### 핵심 개념

| 용어 | 정의 | 특징 |
|------|------|------|
| **공약수** | 두 수의 공통 약수 | = 최대공약수의 약수 |
| **최대공약수 (GCD)** | 공약수 중 가장 큰 것 | 공통 소인수 × **작은 지수** |
| **공배수** | 두 수의 공통 배수 | = 최소공배수의 배수 |
| **최소공배수 (LCM)** | 공배수 중 가장 작은 것 | 모든 소인수 × **큰 지수** |
| **서로소** | 최대공약수가 1인 두 수 | 공약수가 1뿐 (예: 4와 9) |

#### 소인수분해로 GCD, LCM 구하기

```
12 = 2² × 3
18 = 2  × 3²

GCD = 2¹ × 3¹ = 6     ← 공통 소인수, 작은 지수
LCM = 2² × 3² = 36    ← 모든 소인수, 큰 지수
```

#### 공통 나눗셈법 (사다리꼴)

```
2 ) 12  18
3 )  6   9
     2   3

GCD = 2 × 3 = 6
LCM = 2 × 3 × 2 × 3 = 36
```

#### 황금 공식

$$A \times B = \text{GCD} \times \text{LCM}$$

#### 최대공약수 vs 최소공배수 활용 상황

| GCD 활용 | LCM 활용 |
|----------|----------|
| 최대한 크게 똑같이 나누기 | 동시에 반복되는 최솟값 찾기 |
| 직사각형을 가장 큰 정사각형으로 나누기 | 두 버스가 동시에 출발하는 시각 |
| 물건을 남는 것 없이 최대로 묶기 | 두 톱니바퀴가 처음 위치로 돌아오는 시점 |

#### 시험 꿀팁

- 소인수분해 결과는 **유일** (순서 바꿔도 같은 답)
- 1은 소수도 합성수도 아님 ← 시험에서 자주 낚는 포인트!

## II. 정수와 유리수

### 03 정수와 유리수

#### 수의 체계 (포함 관계)

```
유리수 전체
  ├─ 정수
  │    ├─ 양의 정수 (자연수): 1, 2, 3, …
  │    ├─ 0  ← 양수도 음수도 아님!
  │    └─ 음의 정수: −1, −2, −3, …
  └─ 정수가 아닌 유리수: ½, −¾, 0.3, …

자연수 ⊂ 정수 ⊂ 유리수
```

| 수 | 약수 수 | 분류 |
|----|---------|------|
| 1 | 1개 | 소수 아님 |
| 2 | 2개 | 소수 |
| 6 | 4개 | 합성수 |
| ¾ | — | 정수가 아닌 유리수 |

#### 절댓값 (Absolute Value)

- **정의:** 수직선에서 원점(0)까지의 거리 → 항상 0 이상!
- |+5| = 5, |−5| = 5, |0| = 0

| 조건 | 절댓값 |
|------|--------|
| a ≥ 0 | \|a\| = a |
| a < 0 | \|a\| = −a (결과는 양수!) |

- **반수:** 절댓값이 같고 부호가 반대인 두 수 (예: +3과 −3)

#### 수의 대소 비교

- 양수 > 0 > 음수
- 음수끼리는 **절댓값이 클수록 더 작다**

> 예: −5 < −2 (절댓값은 5 > 2이지만, 수로는 −5가 더 작음)

#### 대칭점 정리

| 대칭 종류 | 점 P(a, b)의 대칭점 | 변화 |
|-----------|---------------------|------|
| x축 대칭 | (a, **−b**) | y 부호만 바꿈 |
| y축 대칭 | (**−a**, b) | x 부호만 바꿈 |
| 원점 대칭 | (**−a**, **−b**) | 둘 다 바꿈 |

### 04 유리수의 계산

#### 사칙연산 부호 규칙

| 연산 | 규칙 | 예시 |
|------|------|------|
| **덧셈 (같은 부호)** | 절댓값을 더하고, 공통 부호 | (+3)+(+5) = +8 |
| **덧셈 (다른 부호)** | 절댓값 차이, 절댓값 큰 쪽 부호 | (+7)+(−3) = +4 |
| **뺄셈** | 빼는 수의 부호를 바꿔 더하기 | (+5)−(−3) = (+5)+(+3) = 8 |
| **곱셈·나눗셈 (같은 부호)** | 결과 **+** | (−2)×(−3) = +6 |
| **곱셈·나눗셈 (다른 부호)** | 결과 **−** | (+2)×(−3) = −6 |
| **나눗셈** | 역수를 곱하기 | (−6)÷(+2) = (−6)×(½) = −3 |

#### 곱셈 부호 꿀팁 — 음수 개수로 판단!

- 음수가 **짝수 개** → 결과 **+**
- 음수가 **홀수 개** → 결과 **−**

> 예: (−1)×(−2)×(−3)×(−4) = **+24** (음수 4개 = 짝수 → +)

#### 분수의 사칙연산

| 연산 | 방법 | 예시 |
|------|------|------|
| 덧셈·뺄셈 | 통분 후 계산 | ⅓ + ½ = 2/6 + 3/6 = 5/6 |
| 곱셈 | 분자×분자, 분모×분모 | ⅔ × ¾ = 6/12 = ½ |
| 나눗셈 | 뒤 분수를 뒤집어 곱하기 | ⅔ ÷ ¾ = ⅔ × 4/3 = 8/9 |

#### 혼합 계산 순서

> ① 괄호 풀기 → ② 거듭제곱 → ③ 곱셈·나눗셈 → ④ 덧셈·뺄셈

#### 계산 법칙

- **교환법칙:** a + b = b + a, a × b = b × a
- **결합법칙:** (a+b)+c = a+(b+c)
- **분배법칙:** a×(b+c) = a×b + a×c

#### 시험 꿀팁

- **(−3)² = 9** 이지만 **−3² = −9** (괄호 유무 주의!)
- 뺄셈 → 덧셈으로 바꿀 때 부호 빠짐없이 바꾸기

## III. 방정식

### 05 문자의 사용과 식

#### 문자식 쓰는 규칙

1. 곱셈 기호 × 생략
2. 1·(−1)은 생략 (1×x → x, −1×x → −x)
3. 수는 문자 앞에 (x×3 → 3x)
4. 나눗셈은 분수로 (a÷4 → a/4)

#### 자주 나오는 문자식 예시

| 말로 표현 | 문자식 |
|-----------|--------|
| a의 3배에서 5를 뺀 수 | 3a − 5 |
| x를 4로 나눈 몫 | x/4 |
| 정가 a원에서 10% 할인한 금액 | 0.9a |
| 십의 자리가 a, 일의 자리가 b인 두 자리 수 | 10a + b |
| 한 변이 a인 정사각형의 넓이 | a² |

#### 식의 구성 요소

**예시: 3x + 2**

- **항:** 3x, 2
- **계수:** 3 (x의 계수)
- **상수항:** 2 (문자 없는 항)
- **동류항:** 문자 부분이 같은 항끼리

#### 일차식 계산 (동류항끼리 모으기)

```
3x + 5 + 2x − 1
= (3+2)x + (5−1)
= 5x + 4
```

#### 식의 값 구하기

문자에 수를 대입한 뒤 계산

> x = −2일 때, 3x + 1 = 3×(−2) + 1 = −6 + 1 = **−5**

### 06 일차방정식의 풀이

#### 방정식 vs 항등식

| 구분 | 정의 | 예시 |
|------|------|------|
| **방정식** | 특정 x값에서만 참 | x + 1 = 3 → x=2만 참 |
| **항등식** | 모든 x에서 항상 참 | 2(x+1) = 2x+2 |
| **일차방정식** | 정리하면 ax + b = 0 (a≠0) 꼴 | 2x − 4 = 0 |

#### 등식의 성질

A = B이면:
- A + C = B + C
- A − C = B − C
- AC = BC
- A/C = B/C (C ≠ 0)

#### 일차방정식 풀이 단계

| 단계 | 방법 |
|------|------|
| ① 괄호 풀기 | 분배법칙 적용 |
| ② 이항 | x항은 좌변, 상수항은 우변으로 (부호 바꿔 넘기기!) |
| ③ 동류항 정리 | ax = b 꼴로 만들기 |
| ④ 양변을 a로 나누기 | x = b/a |
| ⑤ 검산 | 구한 x를 원래 방정식에 대입해서 확인 |

**예시: 3(x−1) = 2x + 4**

```
① 괄호 풀기: 3x − 3 = 2x + 4
② 이항:      3x − 2x = 4 + 3
③ 정리:      x = 7
④ 검산:      3(7−1) = 18, 2(7)+4 = 18 ✅
```

#### 계수가 분수·소수일 때

**분수:** 양변에 분모의 최소공배수를 곱해서 정수로 변환

```
x/3 + x/2 = 5
→ ×6:  2x + 3x = 30
→      5x = 30  →  x = 6
```

**소수:** 양변에 10의 거듭제곱을 곱해서 정수로 변환

```
0.3x − 0.1 = 0.5
→ ×10:  3x − 1 = 5
→       3x = 6  →  x = 2
```

#### 특수한 경우

| 경우 | 예시 | 해 |
|------|------|-----|
| 일반적인 경우 | 2x = 6 | x = 3 (해가 1개) |
| 항등식 (양변 같아짐) | 0 = 0 | 해가 무수히 많다 |
| 불능 (모순) | 0 = 5 | 해가 없다 |

#### 시험 꿀팁

- **이항할 때 부호 반드시 바꾸기!** 2x + 3 = 7 → 2x = 7 − 3
- **괄호 앞 음수 주의:** −(x−3) = −x + 3

### 07 일차방정식의 활용

#### 문제 풀이 4단계

1. **미지수 설정:** 구하려는 것을 x로 놓기
2. **방정식 세우기:** 문제의 조건을 등식으로 표현
3. **방정식 풀기:** 위에서 배운 방법으로 x 구하기
4. **확인하기:** 구한 답이 문제 조건에 맞는지 검토

#### 자주 나오는 유형

| 유형 | 핵심 관계식 | 예시 설정 |
|------|-------------|-----------|
| **연속하는 수** | 연속 정수: n, n+1, n+2 / 연속 홀수·짝수: n, n+2, n+4 | 합이 24인 연속 두 정수 → n+(n+1)=24 |
| **거리·속력·시간** | 거리 = 속력 × 시간 | 시속 4km로 x시간 → 거리 = 4x |
| **나이** | 나이 차는 미래에도 동일 | 현재 나이 x, 5년 후 = x+5 |
| **농도** | 소금량 = 농도(%) × 소금물량 ÷ 100 | 8% 소금물 xg → 소금 = 0.08x |
| **원가·정가·할인** | 정가 = 원가×(1+이익률) / 할인가 = 정가×(1−할인율) | 원가 x, 20% 이익 → 정가 = 1.2x |

**거리·속력·시간 예시:**

> A, B가 8km 떨어진 곳에서 마주보고 출발. A는 시속 3km, B는 시속 5km.  
> 만나는 시간 x시간으로 설정 → 3x + 5x = 8 → x = **1시간**

#### 시험 꿀팁

- 답 검토 필수! x = −2가 나왔는데 '사람 수'라면 오류
- x가 자연수인지, 길이가 양수인지 조건 확인

## IV. 그래프와 비례

### 08 좌표평면과 그래프

#### 핵심 개념

| 용어 | 정의 |
|------|------|
| **좌표** | 수직선 위 점의 위치를 수로 나타낸 것 |
| **순서쌍** | 평면 위 점 P의 위치 (x, y) |
| **x축** | 가로 수직선 |
| **y축** | 세로 수직선 |
| **원점 O** | 두 축의 교점 (0, 0) |
| **그래프** | 두 변수 x, y의 관계를 좌표평면에 나타낸 것 |

#### 사분면 정리

```
         y축
          |
 2사분면  |  1사분면
 (−, +)  |  (+, +)
─────────O─────────── x축
 (−, −)  |  (+, −)
 3사분면  |  4사분면
          |
```

| 사분면 | x 부호 | y 부호 |
|--------|--------|--------|
| 제1사분면 | + | + |
| 제2사분면 | − | + |
| 제3사분면 | − | − |
| 제4사분면 | + | − |

> ⚠️ **축 위의 점은 어느 사분면에도 속하지 않음!**  
> 예: (2, 0)은 x축 위 → 사분면 없음

#### 대칭점

| 대칭 | 점 P(a, b)의 대칭점 |
|------|---------------------|
| x축 대칭 | (a, −b) |
| y축 대칭 | (−a, b) |
| 원점 대칭 | (−a, −b) |

### 09 정비례와 반비례

#### 핵심 비교

|  | 정비례 | 반비례 |
|--|--------|--------|
| **관계식** | y = ax (a ≠ 0) | y = a/x (a ≠ 0) |
| **특징** | x가 k배 → y도 k배 | x가 k배 → y는 1/k배 |
| **그래프** | 원점을 지나는 **직선** | 원점에 가까워지는 **쌍곡선** |
| **원점 통과** | ✅ 항상 원점 통과 | ❌ 원점 통과 안 함 |
| **a > 0** | 우상향 직선 (1·3사분면) | 1·3사분면에 쌍곡선 |
| **a < 0** | 우하향 직선 (2·4사분면) | 2·4사분면에 쌍곡선 |
| **판별법** | y/x = 일정 (= a) | xy = 일정 (= a) |

#### 비례상수 a 구하는 법

- **정비례:** 점 (x, y)가 주어지면 → **a = y ÷ x**
- **반비례:** 점 (x, y)가 주어지면 → **a = x × y**

> 예: 정비례 y = ax에서 점 (2, 6) 지남 → a = 6 ÷ 2 = **3**  
> 예: 반비례 y = a/x에서 점 (3, 4) 지남 → a = 3 × 4 = **12**

#### 실생활 예시

| 유형 | 정비례 | 반비례 |
|------|--------|--------|
| 예시 | 속력 일정: 거리 = 60x | 넓이 일정: 가로 × 세로 = 12 |
| 관계식 | y = 60x | y = 12/x |

#### 시험 꿀팁

- **정비례 그래프는 반드시 원점 통과.** y = 2x + 1은 정비례 아님! (상수항 있으면 안 됨)
- **반비례에서 x = 0은 불가!** 분모가 0이 되기 때문
- **a의 절댓값이 클수록** 정비례는 y축에 가까워지고, 반비례는 원점에서 멀어짐

## 🎯 전체 단원 핵심 공식 총정리

### I. 소인수분해

| 공식 | 내용 |
|------|------|
| 약수의 개수 | A = p^a × q^b → (a+1)(b+1)개 |
| GCD | 공통 소인수 × 작은 지수 |
| LCM | 모든 소인수 × 큰 지수 |
| 황금 공식 | A × B = GCD × LCM |

### II. 정수와 유리수

| 공식 | 내용 |
|------|------|
| 절댓값 | 원점까지의 거리, 항상 ≥ 0 |
| 음수 곱셈 | 음수 짝수 개 → +, 홀수 개 → − |
| 계산 순서 | 괄호 → 거듭제곱 → ×÷ → +− |

### III. 방정식

| 공식 | 내용 |
|------|------|
| 이항 | 부호 바꿔서 넘기기 |
| 등식의 성질 | 양변에 같은 수 더·빼·곱·나눠도 성립 |
| 거리·속력·시간 | 거리 = 속력 × 시간 |
| 농도 | 소금량 = 농도(%) × 소금물량 ÷ 100 |

### IV. 그래프와 비례

| 공식 | 내용 |
|------|------|
| 정비례 | y = ax, a = y/x |
| 반비례 | y = a/x, a = xy |
| 사분면 | 1(+,+) 2(−,+) 3(−,−) 4(+,−) |
