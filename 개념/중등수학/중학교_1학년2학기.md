# Ⅰ. 기본 도형

## 01 기본 도형

### 핵심 용어

| 개념 | 정의 |
|---|---|
| 점 | 위치만 있고 크기가 없음 |
| 선 | 점이 무수히 모여 이루어짐, 폭 없음 |
| 면 | 선이 움직인 자취, 두께 없음 |

> 차원 관계: **점(0차원) → 선(1차원) → 면(2차원)**

### 직선 · 반직선 · 선분

| 이름 | 정의 | 양 끝 |
|---|---|---|
| 직선 AB | 양쪽으로 무한히 뻗음 | 없음 (무한) |
| 반직선 AB | 점 A에서 시작해 B 방향으로 무한히 뻗음 | 한쪽 끝(A) |
| 선분 AB | 두 점 A, B를 잇는 부분 | 양쪽 끝(A, B) |

### 중점 공식

$$AM = MB = \frac{1}{2}AB$$

### 각의 종류

| 종류 | 크기 범위 |
|---|---|
| 예각 | 0° < 각 < 90° |
| 직각 | 90° |
| 둔각 | 90° < 각 < 180° |
| 평각 | 180° |

### ⭐ 맞꼭지각

두 직선이 교차할 때 서로 마주보는 각 → **크기가 항상 같다**

### 수직과 수선

- 두 직선이 90°로 만날 때 → **수직(⊥)**
- **수선의 발**: 점 P에서 직선 l에 내린 수선의 발 H
- 점 P와 직선 l 사이의 거리 = PH의 길이 (최단 거리)

## 02 위치 관계

### 직선과 직선의 위치 관계

**평면 위에서** (2가지)

| 경우 | 설명 |
|---|---|
| 평행 (∥) | 만나지 않고 나란히 뻗음 |
| 한 점에서 만남 | 교차 |

**공간에서** (3가지)

| 경우 | 설명 |
|---|---|
| 평행 | 만나지 않고 나란히 |
| 한 점에서 만남 | 교차 |
| **꼬인 위치** ⭐ | 평행하지도 않고, 만나지도 않음 — 같은 평면 위에 없음 |

> 꼬인 위치 예시: 직육면체에서 **모서리 AB와 모서리 DH**

### 직선과 평면의 위치 관계 (3가지)

| 경우 | 설명 |
|---|---|
| 포함 | 직선이 평면 안에 완전히 들어있음 |
| 평행 | 직선과 평면이 만나지 않음 |
| 한 점에서 교차 | 직선이 평면을 뚫고 지나감 |

### 평면과 평면의 위치 관계 (2가지)

| 경우 | 설명 |
|---|---|
| 평행 | 두 평면이 만나지 않음 |
| 교선에서 만남 | 두 평면이 하나의 직선을 공유하며 만남 |

## 03 평행선

### 동위각 · 엇각 · 동측내각

두 평행선 l, m을 직선 n이 가로지를 때:

| 이름 | 위치 | 크기 관계 |
|---|---|---|
| **동위각** | 같은 쪽에 있는 각 | 크기가 **같다** |
| **엇각** | 내부에서 서로 반대쪽 각 | 크기가 **같다** |
| **동측내각** | 내부에서 같은 쪽 각 | 합이 **180°** |

$$\text{동위각: } \angle a = \angle e \qquad \text{엇각: } \angle c = \angle e \qquad \text{동측내각: } \angle c + \angle f = 180°$$

### ⭐ 평행선 조건 (역방향도 중요!)

| 방향 | 내용 |
|---|---|
| 평행 → 각 | 평행하면 동위각 = 동위각, 엇각 = 엇각 |
| 각 → 평행 | 동위각이 같으면 (또는 엇각이 같으면) → 두 직선은 평행 |

## 04 작도와 합동

### 작도 규칙

- **자**: 직선을 그을 때만 사용 (길이 측정 ❌)
- **컴퍼스**: 원을 그리거나 길이를 옮길 때만 사용

### 주요 작도 3가지

| 작도 | 방법 |
|---|---|
| 선분의 수직이등분선 | 양 끝점에서 같은 반지름으로 원 → 두 교점 연결 |
| 각의 이등분선 | 꼭짓점 중심으로 호 → 두 교점에서 같은 반지름 호 → 연결 |
| 평행선 작도 | 동위각 또는 엇각을 이용해 같은 각도로 복사 |

### 도형의 합동 (≅)

모양과 크기가 완전히 같은 두 도형 → **합동**

$$△ABC ≅ △DEF \Rightarrow AB=DE,\ BC=EF,\ CA=FD,\ \angle A=\angle D,\ \angle B=\angle E,\ \angle C=\angle F$$

### ⭐⭐⭐ 삼각형의 합동 조건 3가지

| 조건 | 영어 | 내용 |
|---|---|---|
| **SSS** | Side-Side-Side | 세 변의 길이가 각각 같다 |
| **SAS** | Side-Angle-Side | 두 변의 길이와 그 **끼인각**이 각각 같다 |
| **ASA** | Angle-Side-Angle | 한 변의 길이와 그 **양 끝각**이 각각 같다 |

> ⚠️ SAS에서 **끼인각** 주의! 두 변 사이에 있는 각이어야 합니다.

# Ⅱ. 평면도형

## 05 다각형

### 핵심 용어

- **대각선**: 이웃하지 않는 두 꼭짓점을 이은 선분
- **내각**: 다각형 내부의 각
- **외각**: 내각의 이웃한 변을 연장했을 때 생기는 각 → 내각 + 외각 = 180°

### ⭐⭐ n각형 핵심 공식

$$\text{대각선의 개수} = \frac{n(n-3)}{2}$$

$$\text{내각의 합} = 180° \times (n-2)$$

$$\text{외각의 합} = 360° \quad \text{(n에 관계없이 항상!)}$$

### 내각의 합 예시

| 다각형 | 내각의 합 |
|---|---|
| 삼각형 (n=3) | 180° |
| 사각형 (n=4) | 360° |
| 오각형 (n=5) | 540° |
| 육각형 (n=6) | 720° |

### 대각선 개수 예시

| 다각형 | n | 대각선 개수 |
|---|---|---|
| 삼각형 | 3 | 0 |
| 사각형 | 4 | 2 |
| 오각형 | 5 | 5 |
| 육각형 | 6 | 9 |
| 팔각형 | 8 | 20 |

### 정다각형 공식

$$\text{정n각형 한 내각} = \frac{180° \times (n-2)}{n} \qquad \text{한 외각} = \frac{360°}{n}$$

| 정다각형 | 한 내각 | 한 외각 |
|---|---|---|
| 정삼각형 | 60° | 120° |
| 정사각형 | 90° | 90° |
| 정오각형 | 108° | 72° |
| 정육각형 | 120° | 60° |

## 06 원과 부채꼴

### 핵심 용어

| 용어 | 설명 |
|---|---|
| 반지름 (r) | 중심 O에서 원 위의 점까지의 거리 |
| 지름 | 원의 중심을 지나는 선분 = 2r |
| 호 (arc) | 원 위 두 점 사이의 곡선 부분 |
| 현 (chord) | 원 위 두 점을 이은 선분 |
| 부채꼴 | 두 반지름과 호로 둘러싸인 도형 |
| 중심각 | 두 반지름이 이루는 각 (꼭짓점 = 중심 O) |

### ⭐ 핵심 원리: 중심각에 비례!

같은 원에서 **중심각의 크기에 비례**해서 호의 길이와 넓이가 결정됩니다.

$$\frac{l_1}{l_2} = \frac{S_1}{S_2} = \frac{x_1°}{x_2°}$$

### ⭐⭐ 부채꼴 공식 (반지름 r, 중심각 x°)

$$\text{호의 길이 } l = 2\pi r \times \frac{x}{360}$$

$$\text{넓이 } S = \pi r^2 \times \frac{x}{360}$$

$$\text{호의 길이로 넓이 구하기: } S = \frac{1}{2} \times r \times l \quad \text{⭐ 자주 출제!}$$

### 원 전체 (x = 360°)

$$\text{둘레} = 2\pi r \qquad \text{넓이} = \pi r^2$$

### 실전 예제

**예제.** 반지름 6cm, 중심각 120°인 부채꼴

$$l = 2\pi \times 6 \times \frac{120}{360} = 4\pi \text{ (cm)}$$

$$S = \pi \times 6^2 \times \frac{120}{360} = 12\pi \text{ (cm}^2\text{)}$$

| 공식 | 내용 |
|---|---|

| 내각의 합 | 180°×(n-2) |
| 외각의 합 | 360° (항상) |

| 정n각형 한 외각 | 360°/n |

# Ⅲ. 입체도형

## 07 다면체

### 다면체란?

평면인 다각형 면들로만 둘러싸인 입체도형.
> ⚠️ 원기둥·원뿔·구는 곡면이 있으므로 다면체가 **아님**

### n각기둥 · n각뿔 · n각뿔대

| 종류 | 면 (F) | 꼭짓점 (V) | 모서리 (E) |
|---|---|---|---|
| n각기둥 | n + 2 | 2n | 3n |
| n각뿔 | n + 1 | n + 1 | 2n |
| n각뿔대 | n + 2 | 2n | 3n |

> 각기둥과 각뿔대는 공식이 같지만 옆면 모양이 다름: 각기둥 → 직사각형, 각뿔대 → 사다리꼴

### ⭐⭐ 오일러 공식 (모든 다면체에 성립!)

$$V - E + F = 2 \quad \text{(꼭짓점 - 모서리 + 면 = 2)}$$

예: 사각기둥 → 8 - 12 + 6 = **2** ✓

### 정다면체 5가지

| 이름 | 면의 모양 | 면 (F) | 꼭짓점 (V) | 모서리 (E) |
|---|---|---|---|---|
| 정사면체 | 정삼각형 | 4 | 4 | 6 |
| 정육면체 | 정사각형 | 6 | 8 | 12 |
| 정팔면체 | 정삼각형 | 8 | 6 | 12 |
| 정십이면체 | 정오각형 | 12 | 20 | 30 |
| 정이십면체 | 정삼각형 | 20 | 12 | 30 |

> 정다면체는 딱 **5가지**뿐!

## 08 회전체

### 회전체란?

평면도형을 한 직선(회전축)을 기준으로 1회전시켜 만든 입체도형.

| 원래 도형 | 회전체 |
|---|---|
| 직사각형 | 원기둥 |
| 직각삼각형 | 원뿔 |
| 반원 | 구 |
| 직각사다리꼴 | 원뿔대 |

### 회전체의 단면

| 자르는 방법 | 단면 |
|---|---|
| 회전축에 **수직**으로 자름 | 항상 **원** |
| 회전축을 **포함**하는 평면으로 자름 | 원래 평면도형의 **2배 대칭 도형** |

### 원뿔 전개도 포인트

원뿔 옆면 = **부채꼴** (반지름 = 모선 l)
부채꼴의 호의 길이 = 밑면 원의 둘레

$$2\pi r = 2\pi l \times \frac{x}{360}$$

## 09 입체도형의 겉넓이와 부피

### ⭐⭐⭐ 핵심 공식 총정리

#### 원기둥 (반지름 r, 높이 h)

$$S = 2\pi rh + 2\pi r^2 = 2\pi r(h+r)$$

$$V = \pi r^2 h$$

#### 원뿔 (반지름 r, 높이 h, 모선 l)

$$S = \pi r l + \pi r^2 = \pi r(l+r)$$

$$V = \frac{1}{3}\pi r^2 h$$

$$l^2 = r^2 + h^2 \quad \text{(피타고라스 정리로 모선 구하기)}$$

#### 구 (반지름 r)

$$S = 4\pi r^2$$

$$V = \frac{4}{3}\pi r^3$$

#### 각기둥 · 각뿔 (밑넓이 B, 높이 h)

$$\text{각기둥: } V = Bh \qquad \text{각뿔: } V = \frac{1}{3}Bh$$

### ⭐ 암기 핵심

> **뿔의 부피 = 기둥의 부피 × ⅓**
> (같은 밑면과 높이일 때)

### 실전 예제

**예제.** 반지름 3cm, 높이 4cm인 원뿔의 겉넓이와 부피

모선: $l = \sqrt{3^2 + 4^2} = 5$ cm

$$S = \pi \times 3 \times 5 + \pi \times 3^2 = 15\pi + 9\pi = 24\pi \text{ (cm}^2\text{)}$$

$$V = \frac{1}{3} \times \pi \times 9 \times 4 = 12\pi \text{ (cm}^3\text{)}$$

# Ⅳ. 통계

## 10 도수분포표

### 핵심 용어 6개

| 용어 | 뜻 | 예시 |
|---|---|---|
| **계급** | 자료를 나눈 구간 | 70이상~80미만 |
| **계급의 크기** | 구간의 너비 | 10 |
| **계급값** | 계급의 한가운데 값 | 75 = (70+80)÷2 |
| **도수** | 각 계급에 속하는 자료의 수 | 12명 |
| **누적도수** | 처음 계급부터 해당 계급까지 도수의 합 | 22명 |
| **도수의 합** | 전체 자료의 수 | 35명 |

### 도수분포표 예시 (수학 점수, 전체 35명)

| 계급 (점수) | 도수 | 누적도수 |
|---|---|---|
| 50 이상 ~ 60 미만 | 3 | 3 |
| 60 이상 ~ 70 미만 | 7 | 10 |
| **70 이상 ~ 80 미만** | **12** | **22** |
| 80 이상 ~ 90 미만 | 8 | 30 |
| 90 이상 ~ 100 미만 | 5 | 35 |
| 합계 | 35 | — |

### 히스토그램 특징

- 막대 사이 **간격이 없음** (연속된 자료)
- 막대의 너비 = 계급의 크기 (모두 같음)
- 히스토그램의 전체 넓이 = **계급의 크기 × 도수의 합**

### 도수분포다각형

히스토그램 각 막대의 **윗변 중앙점**을 선분으로 연결.
양쪽 끝은 도수가 0인 계급까지 연장해서 닫아줌.

### ⭐ 평균 구하기 (계급값 이용)

$$\text{평균} = \frac{\sum(\text{계급값} \times \text{도수})}{\text{도수의 합}}$$

위 예시 적용:

$$\text{평균} = \frac{55×3 + 65×7 + 75×12 + 85×8 + 95×5}{35} = \frac{2660}{35} = 76 \text{ (점)}$$

## 11 상대도수

### 상대도수란?

$$\text{상대도수} = \frac{\text{그 계급의 도수}}{\text{도수의 합 (전체)}}$$

- 항상 **0 이상 1 이하**
- 모든 계급의 상대도수의 합 = **1** (100%)
- 백분율(%) = 상대도수 × 100

### ⭐ 도수 ↔ 상대도수 변환

$$\text{도수} = \text{상대도수} \times \text{도수의 합}$$

### 상대도수 분포표 예시 (전체 35명)

| 계급 | 도수 | 상대도수 | 백분율 |
|---|---|---|---|
| 50~60 | 3 | 0.086 | 8.6% |
| 60~70 | 7 | 0.200 | 20.0% |
| **70~80** | **12** | **0.343** | **34.3%** |
| 80~90 | 8 | 0.229 | 22.9% |
| 90~100 | 5 | 0.143 | 14.3% |
| 합계 | 35 | **1** | **100%** |

### ⭐⭐ 상대도수가 필요한 이유

전체 수가 다른 두 집단을 **공정하게 비교**할 때 사용!

| | A반 (40명) | B반 (25명) |
|---|---|---|
