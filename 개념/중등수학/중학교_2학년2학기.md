# Ⅰ. 삼각형의 성질

## 1. 삼각형의 성질

### 📌 핵심 요약
- 이등변삼각형의 두 밑각의 크기는 같다.
- 이등변삼각형의 꼭지각의 이등분선은 밑변을 수직이등분한다.
- 두 내각의 크기가 같은 삼각형은 이등변삼각형이다.
- 직각삼각형의 합동조건: **RHA 합동**, **RHS 합동**

### 🔍 상세 설명

**(1) 이등변삼각형의 정의**
두 변의 길이가 같은 삼각형을 이등변삼각형이라고 해요. 이때 길이가 같은 두 변이 이루는 각을 **꼭지각**, 꼭지각의 대변을 **밑변**, 밑변의 양 끝 각을 **밑각**이라고 부릅니다.

**(2) 이등변삼각형의 두 가지 핵심 성질**

① **두 밑각의 크기가 같다.**
- 삼각형 ABC에서 AB = AC이면 ∠B = ∠C
- 증명 아이디어: 꼭지각의 이등분선을 그으면 SAS 합동 → 대응각이 같음

② **꼭지각의 이등분선은 밑변을 수직이등분한다.**
- 즉, 꼭지각의 이등분선 = 밑변의 수직이등분선 = 밑변에 대한 중선 = 꼭지각에서 밑변에 내린 수선
- 이 네 가지가 **모두 일치**한다는 게 핵심!

**(3) 이등변삼각형이 되기 위한 조건 (역도 성립!)**
한 삼각형에서 **두 내각의 크기가 같으면** 그 두 각의 대변의 길이도 같아 이등변삼각형이 됩니다. 즉, ∠B = ∠C이면 AB = AC.

**(4) 직각삼각형의 합동조건 — 가장 중요! ⭐**

| 합동조건 | 의미 |
|---------|------|
| **RHA 합동** | 빗변(H)의 길이와 한 예각(A)이 각각 같을 때 |
| **RHS 합동** | 빗변(H)의 길이와 다른 한 변(S)의 길이가 각각 같을 때 |

여기서 R은 Right angle(직각), H는 Hypotenuse(빗변), A는 Angle(각), S는 Side(변)을 뜻해요.

> 💡 주의: **RAS, RSA**는 합동조건이 아니에요! 빗변이 반드시 들어가야 합니다.

## 2. 삼각형의 외심과 내심

### 📌 핵심 요약
- **외심**: 세 변의 수직이등분선의 교점 → 세 꼭짓점에서 같은 거리
- **내심**: 세 내각의 이등분선의 교점 → 세 변에서 같은 거리
- 외심과 내심은 위치와 성질이 완전히 다르니 헷갈리지 말기!

### 🔍 상세 설명

**(1) 삼각형의 외심**

삼각형의 세 변의 **수직이등분선**은 한 점에서 만나는데, 이 점을 **외심**(O)이라고 해요. 외심을 중심으로 세 꼭짓점을 지나는 원(외접원)을 그릴 수 있습니다.

**외심의 성질:**
- 외심에서 세 꼭짓점에 이르는 거리는 모두 같다 → **OA = OB = OC = 외접원의 반지름**
- 삼각형의 종류에 따른 외심의 위치:
  - 예각삼각형 → 삼각형 **내부**
  - 직각삼각형 → **빗변의 중점** (이게 직각삼각형의 외심!)
  - 둔각삼각형 → 삼각형 **외부**

**외심 관련 핵심 공식 (각도 문제 단골!):**
외심을 O라 할 때, 세 꼭짓점과 O를 이으면 이등변삼각형 3개가 생겨요. 이때 ∠A의 자리에 있는 두 각을 a, ∠B 자리를 b, ∠C 자리를 c라 하면:

$$a + b + c = 90°$$

**(2) 삼각형의 내심**

삼각형의 세 **내각의 이등분선**은 한 점에서 만나는데, 이 점을 **내심**(I)이라고 해요. 내심을 중심으로 세 변에 접하는 원(내접원)을 그릴 수 있습니다.

**내심의 성질:**
- 내심에서 세 변에 이르는 거리는 모두 같다 → **내접원의 반지름**과 같음
- 내심은 모든 삼각형에서 **항상 내부**에 위치 (외심과 다른 점!)

**내심 관련 핵심 공식:**

$$\angle BIC = 90° + \frac{1}{2}\angle A$$

내각의 이등분선이므로, ∠A의 절반을 a, ∠B의 절반을 b, ∠C의 절반을 c라 하면:

$$a + b + c = 90°$$

**(3) 내접원의 반지름과 삼각형의 넓이**

삼각형의 세 변의 길이를 a, b, c, 내접원의 반지름을 r이라 할 때:

$$S = \frac{1}{2}r(a+b+c)$$

**(4) 외심 vs 내심 비교표**

| 구분 | 외심 (O) | 내심 (I) |
|------|---------|---------|
| 만나는 선 | 세 변의 수직이등분선 | 세 내각의 이등분선 |
| 같은 거리 | 세 **꼭짓점**에서 같은 거리 | 세 **변**에서 같은 거리 |
| 외접원/내접원 | 외접원의 중심 | 내접원의 중심 |
| 위치 | 삼각형의 종류에 따라 다름 | 항상 삼각형 내부 |

> 💡 암기 팁:
> - **외**심 → 외접원 → 꼭**짓**점 (밖에서 둘러싸니까)
> - **내**심 → 내접원 → **변** (안쪽에서 변에 닿으니까)

# Ⅱ. 사각형의 성질

## 1. 평행사변형

### 📌 핵심 요약
- **정의**: 두 쌍의 대변이 각각 평행한 사각형
- **4가지 성질**: 대변, 대각, 대각선에 관한 성질
- **5가지 판별조건** 중 하나만 만족해도 평행사변형!

### 🔍 상세 설명

**(1) 평행사변형의 정의**
사각형 ABCD에서 AB ∥ DC, AD ∥ BC인 사각형을 평행사변형이라고 해요. 즉, **두 쌍의 대변이 각각 평행**한 사각형입니다.

**(2) 평행사변형의 4가지 성질 ⭐**

① **두 쌍의 대변의 길이가 각각 같다.** (AB = DC, AD = BC)

② **두 쌍의 대각의 크기가 각각 같다.** (∠A = ∠C, ∠B = ∠D)

③ **이웃하는 두 내각의 크기의 합은 180°이다.** (∠A + ∠B = 180°)

④ **두 대각선은 서로를 이등분한다.** (OA = OC, OB = OD)

> ⚠️ 주의: 대각선의 길이가 같다는 게 아니라, 서로를 **이등분**한다는 뜻!

**(3) 평행사변형이 되는 조건 (판별조건) ⭐**

다음 중 **하나만** 만족하면 그 사각형은 평행사변형:

① 두 쌍의 대변이 각각 **평행**하다. (정의)
② 두 쌍의 대변의 **길이가 각각 같다**.
③ 두 쌍의 대각의 **크기가 각각 같다**.
④ 두 대각선이 서로를 **이등분**한다.
⑤ 한 쌍의 대변이 **평행하고 그 길이가 같다**.

**(4) 평행사변형과 넓이**

- 한 대각선은 넓이를 **이등분**한다.
- 두 대각선은 평행사변형을 **넓이가 같은 4개의 삼각형**으로 나눈다.
- 평행사변형 내부의 임의의 점 P에 대해:

$$\triangle PAB + \triangle PCD = \triangle PBC + \triangle PDA = \frac{1}{2} \square ABCD$$

## 2. 여러 가지 사각형

### 📌 핵심 요약
- **직사각형**: 네 각이 모두 직각 → 대각선의 길이가 같음
- **마름모**: 네 변의 길이가 모두 같음 → 대각선이 수직이등분
- **정사각형**: 직사각형 + 마름모의 성질 모두
- **사다리꼴**: 한 쌍의 대변이 평행
- **등변사다리꼴**: 평행하지 않은 두 변의 길이가 같음

### 🔍 상세 설명

**(1) 직사각형**

**정의**: 네 내각의 크기가 모두 같은 (즉, 모두 90°인) 사각형

**성질**:
- 평행사변형의 모든 성질을 가짐
- **두 대각선의 길이가 같고, 서로를 이등분**한다 → AC = BD, OA = OB = OC = OD

**평행사변형이 직사각형이 되는 조건**:
- 한 내각이 직각이거나
- 두 대각선의 길이가 같다

**(2) 마름모**

**정의**: 네 변의 길이가 모두 같은 사각형

**성질**:
- 평행사변형의 모든 성질을 가짐
- **두 대각선은 서로를 수직이등분**한다
- 두 대각선은 각각 두 내각을 이등분한다

**평행사변형이 마름모가 되는 조건**:
- 이웃하는 두 변의 길이가 같거나
- 두 대각선이 서로 수직이다

**(3) 정사각형**

**정의**: 네 변의 길이가 모두 같고, 네 내각의 크기가 모두 같은 사각형

**성질**:
- 두 대각선의 **길이가 같다**
- 두 대각선이 서로를 **수직이등분**한다

**직사각형이 정사각형이 되는 조건**:
- 이웃하는 두 변의 길이가 같거나
- 두 대각선이 수직이다

**마름모가 정사각형이 되는 조건**:
- 한 내각이 직각이거나
- 두 대각선의 길이가 같다

**(4) 사다리꼴과 등변사다리꼴**

**사다리꼴**: 한 쌍의 대변이 평행한 사각형

**등변사다리꼴**: 평행하지 않은 한 쌍의 대변의 길이가 같은 사다리꼴

**등변사다리꼴의 성질**:
① 평행하지 않은 두 변의 길이가 같다
② 아랫변의 양 끝 각의 크기가 같다
③ **두 대각선의 길이가 같다**

**(5) 여러 가지 사각형의 관계도**

```
              사각형
                │
            사다리꼴 (한 쌍의 대변이 평행)
                │
          평행사변형 (두 쌍의 대변이 평행)
              ╱   ╲
       직사각형    마름모
       (네 각 같음)  (네 변 같음)
              ╲   ╱
            정사각형
       (네 각 + 네 변 모두 같음)
```

**(6) 대각선의 성질 정리표 ⭐ (시험 단골!)**

| 사각형 | 길이가 같다 | 서로를 이등분 | 서로 수직 |
|--------|:---:|:---:|:---:|
| 평행사변형 | ✗ | ✓ | ✗ |
| 직사각형 | ✓ | ✓ | ✗ |
| 마름모 | ✗ | ✓ | ✓ |
| 정사각형 | ✓ | ✓ | ✓ |
| 등변사다리꼴 | ✓ | ✗ | ✗ |

> 💡 암기 팁:
> - **직**사각형 → 대각선 길이가 **같**음 (직→길)
> - **마**름모 → 대각선 **수**직이등분 (마→수)
> - **정**사각형 → 둘 다!

**(7) 사각형 각 변의 중점을 연결한 사각형**

| 원래 사각형 | 중점 연결 사각형 |
|------------|----------------|
| 사각형 | 평행사변형 |
| 평행사변형 | 평행사변형 |
| 직사각형 | 마름모 |
| 마름모 | 직사각형 |
| 정사각형 | 정사각형 |
| 등변사다리꼴 | 마름모 |

# Ⅲ. 도형의 닮음과 피타고라스 정리

## 1. 도형의 닮음

### 📌 핵심 요약
- **닮음**: 한 도형을 일정한 비율로 확대/축소하면 다른 도형과 합동
- **닮음비**: 대응변의 길이의 비
- **삼각형의 닮음조건**: SSS 닮음, SAS 닮음, AA 닮음

### 🔍 상세 설명

**(1) 닮음의 정의**

한 도형을 일정한 비율로 확대하거나 축소한 도형이 다른 도형과 합동일 때, 두 도형은 **서로 닮음**이라 하고, 기호로 **△ABC ∽ △DEF**처럼 씁니다.

**(2) 닮음의 성질**

- 대응변의 길이의 비가 일정 → 이 비를 **닮음비**라고 함
- 대응각의 크기가 각각 같다

**(3) 닮음비와 넓이의 비, 부피의 비 ⭐ (시험 단골!)**

두 닮은 도형의 닮음비가 **m : n**일 때,

| 항목 | 비 |
|------|-----|
| 길이의 비 (변, 둘레, 높이 등) | m : n |
| **넓이의 비** | **m² : n²** |
| **부피의 비** | **m³ : n³** |

> 💡 예: 닮음비가 2:3이면 → 넓이비 4:9, 부피비 8:27

**(4) 삼각형의 닮음조건 ⭐⭐⭐**

① **SSS 닮음**: 세 쌍의 대응변의 길이의 비가 모두 같다

$$\frac{a}{a'} = \frac{b}{b'} = \frac{c}{c'}$$

② **SAS 닮음**: 두 쌍의 대응변의 길이의 비가 같고, 그 끼인각의 크기가 같다

③ **AA 닮음**: 두 쌍의 대응각의 크기가 각각 같다

> 💡 닮음은 ASA가 아니라 **AA**(각 두 개만 있으면 됨)예요!

**(5) 직각삼각형의 닮음 ⭐ (자주 나옴!)**

직각삼각형 ABC에서 직각인 꼭짓점 A에서 빗변 BC에 수선 AH를 내리면:

**△ABC ∽ △HBA ∽ △HAC** (세 삼각형이 모두 닮음!)

핵심 공식들:

$$\overline{AH}^2 = \overline{BH} \times \overline{CH}$$

$$\overline{AB}^2 = \overline{BH} \times \overline{BC}$$

$$\overline{AC}^2 = \overline{CH} \times \overline{BC}$$

$$\overline{AB} \times \overline{AC} = \overline{AH} \times \overline{BC}$$

## 2. 평행선 사이의 선분의 길이의 비

### 📌 핵심 요약
- **삼각형에서 평행선과 선분의 비**: 평행한 직선이 두 변과 만나면 비례식 성립
- **삼각형의 각의 이등분선**: 내각의 이등분선이 대변을 나누는 비
- **평행선 사이의 선분의 비**: 여러 평행선이 만드는 선분의 비
- **중점연결정리**: 두 변의 중점을 이은 선분의 성질

### 🔍 상세 설명

**(1) 삼각형에서 평행선과 선분의 비 ⭐**

△ABC에서 DE ∥ BC일 때:

$$\overline{AD} : \overline{DB} = \overline{AE} : \overline{EC}$$

$$\overline{AD} : \overline{AB} = \overline{AE} : \overline{AC} = \overline{DE} : \overline{BC}$$

> 💡 역도 성립! AD:DB = AE:EC이면 DE ∥ BC

**(2) 삼각형의 내각의 이등분선 ⭐**

△ABC에서 ∠A의 이등분선이 변 BC와 만나는 점을 D라 하면:

$$\overline{AB} : \overline{AC} = \overline{BD} : \overline{DC}$$

**(3) 삼각형의 외각의 이등분선**

△ABC에서 ∠A의 외각의 이등분선이 변 BC의 연장선과 만나는 점을 D라 하면:

$$\overline{AB} : \overline{AC} = \overline{BD} : \overline{CD}$$

**(4) 평행선 사이의 선분의 길이의 비**

세 평행선 l, m, n이 두 직선과 각각 만날 때:

$$a : b = a' : b'$$

**(5) 사다리꼴에서 평행선과 선분의 길이**

사다리꼴 ABCD(AD ∥ BC)에서 AD = a, BC = b이고 AE:EB = m:n이면:

$$\overline{EF} = \frac{na + mb}{m+n}$$

**(6) 삼각형의 중점연결정리 ⭐⭐**

△ABC에서 변 AB, AC의 **중점**을 각각 M, N이라 하면:

$$\overline{MN} \parallel \overline{BC}, \quad \overline{MN} = \frac{1}{2}\overline{BC}$$

> 💡 두 변의 중점을 이은 선분은 나머지 변과 평행하고, 그 길이는 절반!

**(7) 사다리꼴의 중점연결정리**

사다리꼴 ABCD에서 AD ∥ BC이고, AB와 DC의 중점이 각각 M, N일 때:

$$\overline{MN} = \frac{1}{2}(\overline{AD} + \overline{BC})$$

## 3. 삼각형의 무게중심

### 📌 핵심 요약
- **중선**: 꼭짓점과 대변의 중점을 잇는 선분
- **무게중심**: 세 중선의 교점
- **무게중심은 중선을 2:1로 내분**
- 무게중심은 삼각형을 **넓이가 같은 6개의 삼각형**으로 나눔

### 🔍 상세 설명

**(1) 중선의 정의**

삼각형의 한 꼭짓점과 그 **대변의 중점**을 이은 선분.

**중선의 성질**: 중선은 삼각형의 넓이를 이등분한다.

**(2) 무게중심 (G) ⭐**

**무게중심의 핵심 성질**:

① **무게중심은 세 중선을 꼭짓점으로부터 2:1로 내분한다.**

$$\overline{AG} : \overline{GM} = 2 : 1$$

② **무게중심은 삼각형을 넓이가 같은 6개의 작은 삼각형**으로 나눈다.
각 작은 삼각형의 넓이 = △ABC의 넓이의 1/6

③ **무게중심과 꼭짓점이 만드는 삼각형의 넓이 = 전체 넓이의 1/3**

$$\triangle GAB = \triangle GBC = \triangle GCA = \frac{1}{3}\triangle ABC$$

**(3) 외심·내심·무게중심 비교 정리표**

| 구분 | 외심 (O) | 내심 (I) | 무게중심 (G) |
|------|---------|---------|------------|
| 만나는 선 | 세 변의 수직이등분선 | 세 내각의 이등분선 | 세 중선 |
| 등거리 | 세 꼭짓점에서 같은 거리 | 세 변에서 같은 거리 | (해당 없음) |
| 위치 | 삼각형 종류에 따라 다름 | 항상 내부 | 항상 내부 |
| 특별한 성질 | 외접원의 중심 | 내접원의 중심 | 중선을 2:1로 내분 |

> 💡 **정삼각형에서는 외심 = 내심 = 무게중심**이 모두 일치해요!

## 4. 피타고라스 정리

### 📌 핵심 요약
- **피타고라스 정리**: 직각삼각형에서 a² + b² = c² (c는 빗변)
- **피타고라스 정리의 역**도 성립 → 직각삼각형인지 판별 가능
- 다양한 도형에서 피타고라스 정리를 응용

### 🔍 상세 설명

**(1) 피타고라스 정리 ⭐⭐⭐**

직각삼각형에서 **직각을 낀 두 변의 길이의 제곱의 합은 빗변의 길이의 제곱과 같다.**

$$a^2 + b^2 = c^2$$

(a, b는 직각을 낀 두 변, c는 빗변)

**(2) 피타고라스 정리의 역**

삼각형의 세 변의 길이 a, b, c (c가 가장 긴 변)에 대해:
- **a² + b² = c²** 이면 **빗변이 c인 직각삼각형**
- a² + b² > c² 이면 예각삼각형
- a² + b² < c² 이면 둔각삼각형

**(3) 자주 나오는 피타고라스 수**

- **3, 4, 5** (가장 기본!)
- **5, 12, 13**
- **6, 8, 10** (3, 4, 5의 2배)
- **7, 24, 25**
- **8, 15, 17**
- **9, 12, 15** (3, 4, 5의 3배)

**(4) 특수한 직각삼각형의 변의 비 ⭐**

| 삼각형 | 세 각 | 변의 비 |
|--------|------|---------|
| 직각이등변삼각형 | 45° - 45° - 90° | 1 : 1 : √2 |
| 정삼각형의 반쪽 | 30° - 60° - 90° | 1 : √3 : 2 |

> 💡 정삼각형의 한 변이 a이면 높이는 (√3/2)a, 넓이는 (√3/4)a²

**(5) 직사각형의 대각선의 길이**

가로 a, 세로 b인 직사각형의 대각선의 길이:

$$d = \sqrt{a^2 + b^2}$$

**(6) 직육면체의 대각선의 길이**

가로 a, 세로 b, 높이 c인 직육면체의 대각선의 길이:

$$d = \sqrt{a^2 + b^2 + c^2}$$

> 💡 피타고라스 정리를 **두 번 연속** 적용한 결과!

**(7) 피타고라스 정리의 응용**

- **원에서의 응용**: 중심에서 현에 내린 수선은 현을 이등분
- **두 점 사이의 거리**: 좌표평면에서도 활용 가능
- **세 변으로 만든 도형의 넓이 관계**: S₁ + S₂ = S₃

# Ⅳ. 확률

## 1. 경우의 수

### 📌 핵심 요약
- **경우의 수**: 어떤 사건이 일어날 수 있는 가짓수
- **합의 법칙**: "또는", "이거나" → **더하기**
- **곱의 법칙**: "그리고", "동시에", "잇따라" → **곱하기**
- **순서가 있는** 나열 vs **순서 없이** 뽑기 구분이 핵심!

### 🔍 상세 설명

**(1) 합의 법칙 ⭐**

두 사건 A, B가 **동시에 일어나지 않을 때**:

$$(\text{A 경우의 수}) + (\text{B 경우의 수})$$

> 💡 키워드: **"또는", "이거나"** → 더하기

**예시**: 주사위에서 2의 배수 또는 5의 눈 → 3 + 1 = **4가지**

**(2) 곱의 법칙 ⭐**

두 사건 A, B가 **동시에 또는 잇따라 일어날 때**:

$$(\text{A 경우의 수}) \times (\text{B 경우의 수})$$

> 💡 키워드: **"그리고", "동시에", "잇따라"** → 곱하기

**예시**: 동전 1개와 주사위 1개 동시에 던지기 → 2 × 6 = **12가지**

**(3) 한 줄로 세우는 경우의 수 (순서 있음!) ⭐**

**① n명을 한 줄로 세우기**: n × (n-1) × ... × 2 × 1
- 예: 4명 → 4! = 24가지

**② n명 중 r명을 뽑아 한 줄로 세우기**: n × (n-1) × ... × (n-r+1)
- 예: 5명 중 3명 → 5 × 4 × 3 = 60가지

**③ 이웃하여 세우기**: 이웃해야 하는 사람들을 **하나로 묶어서** 세운 후, 묶음 내부에서 자리 바꾸는 경우의 수를 곱하기
- 예: A, B가 이웃하는 5명 줄세우기 → 4! × 2! = 48가지

**(4) 자연수의 개수 ⭐ (시험 단골!)**

서로 다른 숫자 카드로 자연수 만들기 → **0이 포함되는지** 주의!

**예시**: 0, 1, 2, 3 카드로 만드는 세 자리 자연수
- 백의 자리: 0 제외 → 3가지
- 십의 자리: 3가지 (남은 것 중 0 포함)
- 일의 자리: 2가지
- 답: 3 × 3 × 2 = **18가지**

**(5) 대표 뽑기 (순서 있음 vs 순서 없음) ⭐⭐**

**① 자격이 다른 대표 (회장, 부회장)** → 순서 있음
- 예: 5명 중 회장, 부회장 → 5 × 4 = **20가지**

**② 자격이 같은 대표 (대표 2명)** → 순서 없음 (**2로 나누기!**)
- 예: 5명 중 대표 2명 → (5 × 4) ÷ 2 = **10가지**

**③ 자격이 같은 대표 3명** → **6으로 나누기** (3!로 나눔)

> 💡 핵심: 자격이 다르면 그냥 곱하기, 자격이 같으면 자리 바꾼 만큼 나누기

## 2. 확률

### 📌 핵심 요약
- **확률**: (사건의 경우의 수) ÷ (모든 경우의 수)
- **확률은 항상 0 이상 1 이하**
- **여사건**: 1 - (사건의 확률)
- **두 사건의 확률**: 동시에 일어나면 곱, 또는이면 더함

### 🔍 상세 설명

**(1) 확률의 정의 ⭐**

$$P(A) = \frac{\text{사건 A가 일어나는 경우의 수}}{\text{모든 경우의 수}}$$

**(2) 확률의 기본 성질 ⭐**

① **0 ≤ P(A) ≤ 1**
② **반드시 일어나는 사건의 확률 = 1**
③ **절대 일어나지 않는 사건의 확률 = 0**

**(3) 여사건의 확률 ⭐⭐ (정말 중요!)**

$$P(\text{A가 일어나지 않을 확률}) = 1 - P(A)$$

> 💡 키워드: **"적어도 ~", "최소한 ~", "~가 아닐"** → 여사건 활용!

**예시**: 동전 3번 던질 때 적어도 한 번은 앞면
- 여사건(모두 뒷면): (1/2)³ = 1/8
- 답: 1 - 1/8 = **7/8**

**(4) 두 사건의 확률 — 합의 법칙**

두 사건이 동시에 일어나지 않을 때:

$$P(\text{A 또는 B}) = P(A) + P(B)$$

**(5) 두 사건의 확률 — 곱의 법칙**

두 사건이 서로 영향을 주지 않을 때:

$$P(\text{A 그리고 B}) = P(A) \times P(B)$$

**(6) 연속하여 뽑는 경우 — 복원 vs 비복원 ⭐⭐**

**① 복원추출 (다시 넣음)**: 매번 조건이 같음
- 빨강 3, 파랑 2에서 두 번 모두 빨강 → 3/5 × 3/5 = **9/25**

**② 비복원추출 (다시 넣지 않음)**: 두 번째에서 전체 개수가 줄어듦!
- 빨강 3, 파랑 2에서 두 번 모두 빨강 → 3/5 × 2/4 = **3/10**

> ⚠️ 비복원추출은 두 번째 확률에서 **분모와 분자 모두 1씩 감소**!

**(7) 도형에서의 확률 (기하학적 확률)**

$$P = \frac{\text{해당 영역의 넓이}}{\text{전체 영역의 넓이}}$$
