# Ⅰ. 유리수와 순환소수

## 📌 핵심 개념 요약

1. **유리수**: 분수 $\frac{a}{b}$ ($a, b$는 정수, $b \neq 0$) 꼴로 나타낼 수 있는 수
2. **유한소수 vs 무한소수**: 소수점 아래 숫자가 끝나는지 여부로 구분
3. **순환소수**: 무한소수 중 일정한 숫자가 반복되는 소수
4. **판별법**: 기약분수의 분모를 소인수분해하여 2와 5만 있으면 유한소수
5. **순환소수 → 분수**: 공식을 이용해 분수로 변환 가능
6. **결론**: 유한소수와 순환소수는 모두 유리수!

## 1. 유리수의 분류

### 🔹 유리수란?

**유리수(Rational Number)**는 두 정수의 비, 즉 분수 꼴로 나타낼 수 있는 수예요.

$$\text{유리수} = \frac{a}{b} \quad (a, b \text{는 정수}, \ b \neq 0)$$

예를 들어:
- $3 = \frac{3}{1}$ → 정수도 유리수
- $0.5 = \frac{1}{2}$ → 유한소수도 유리수
- $-\frac{2}{7}$ → 음수도 유리수

### 🔹 소수의 분류

소수는 크게 두 가지로 나뉩니다.

**① 유한소수**: 소수점 아래 0이 아닌 숫자가 유한 번 나타나는 소수
- 예: $0.25, \ 1.5, \ 0.125$

**② 무한소수**: 소수점 아래 0이 아닌 숫자가 무한 번 나타나는 소수
- 예: $0.333\cdots, \ 3.14159\cdots$

무한소수 중에서도 **일정한 패턴이 반복되는 것**을 **순환소수**라고 해요.

## 2. 순환소수의 표현

### 🔹 순환마디

순환소수에서 **반복되는 숫자의 한 묶음**을 **순환마디**라고 합니다.

### 🔹 순환소수 표기법

순환마디의 **양 끝 숫자 위에 점**을 찍어 표현해요.

| 순환소수 | 순환마디 | 표기 |
|---------|---------|------|
| $0.333\cdots$ | 3 | $0.\dot{3}$ |
| $0.272727\cdots$ | 27 | $0.\dot{2}\dot{7}$ |
| $1.2345345\cdots$ | 345 | $1.2\dot{3}4\dot{5}$ |

⚠️ **주의**: 순환마디는 소수점 아래에서 처음으로 반복되는 부분이에요. $0.1222\cdots = 0.1\dot{2}$ 처럼 앞부분이 반복되지 않을 수도 있어요.

## 3. 유한소수로 나타낼 수 있는 분수의 조건 ⭐

이 부분이 1단원의 **최고 핵심**이에요!

### 🔹 판별 방법

**기약분수**(더 이상 약분되지 않는 분수)로 고친 후, **분모를 소인수분해** 했을 때:

✅ 분모의 소인수가 **2 또는 5뿐**이면 → **유한소수**
❌ 분모에 2, 5 이외의 소인수가 있으면 → **순환소수**

### 🔹 왜 그럴까? (원리 이해)

유한소수는 분모가 $10, 100, 1000, \cdots$ 즉 $10^n$ 꼴로 나타낼 수 있어야 해요.

$$10^n = 2^n \times 5^n$$

따라서 분모가 2와 5로만 이루어져야 분자와 분모에 적절한 수를 곱해 분모를 10의 거듭제곱으로 만들 수 있어요.

### 🔹 예시

**예 1)** $\dfrac{7}{20}$
- 분모 $20 = 2^2 \times 5$ → 2와 5뿐! → **유한소수** ✅
- $\dfrac{7}{20} = \dfrac{7 \times 5}{20 \times 5} = \dfrac{35}{100} = 0.35$

**예 2)** $\dfrac{5}{12}$
- 분모 $12 = 2^2 \times 3$ → 3이 있음! → **순환소수** ❌
- $\dfrac{5}{12} = 0.41\dot{6}$

**예 3)** $\dfrac{6}{15}$
- 먼저 기약분수로: $\dfrac{6}{15} = \dfrac{2}{5}$
- 분모 5 → 5뿐! → **유한소수** ✅

⚠️ **반드시 기약분수로 먼저 만들고** 판단해야 해요!

## 4. 순환소수를 분수로 나타내기 ⭐

### 🔹 방법 1: 등식을 세워 푸는 방법 (원리)

**예제**: $x = 0.\dot{2}\dot{7} = 0.272727\cdots$ 을 분수로 나타내기

**Step 1)** $x = 0.272727\cdots$ ··· ①

**Step 2)** 순환마디가 2자리이므로 양변에 $100$을 곱하기:
$$100x = 27.272727\cdots \ \cdots ②$$

**Step 3)** ② - ① 을 계산:
$$99x = 27$$
$$x = \dfrac{27}{99} = \dfrac{3}{11}$$

### 🔹 방법 2: 공식으로 빠르게 (시험에 강추!)

말로 풀어보면:
- **분자**: 소수점과 점을 모두 떼어낸 수 − 순환하지 않는 부분의 수
- **분모**: 순환마디 자릿수만큼 **9**를 쓰고, 순환하지 않는 소수 부분 자릿수만큼 **0**을 붙임

### 🔹 예시

**예 1)** $0.\dot{4}\dot{5}$
- 분자: $45 - 0 = 45$
- 분모: 순환마디 2자리 → $99$
- $0.\dot{4}\dot{5} = \dfrac{45}{99} = \dfrac{5}{11}$

**예 2)** $0.1\dot{2}\dot{3}$
- 분자: $123 - 1 = 122$
- 분모: 순환마디 2자리 + 순환 안 하는 1자리 → $990$
- $0.1\dot{2}\dot{3} = \dfrac{122}{990} = \dfrac{61}{495}$

**예 3)** $2.\dot{1}\dot{6}$
- 분자: $216 - 2 = 214$
- 분모: $99$
- $2.\dot{1}\dot{6} = \dfrac{214}{99}$

## 5. 유리수와 소수의 관계 (총정리)

### 🔹 매우 중요한 결론!

$$\boxed{\text{유리수} \ = \ \text{유한소수} \ + \ \text{순환소수(무한소수 중 일부)}}$$

즉,
- 모든 유한소수는 유리수다. ⭕
- 모든 순환소수는 유리수다. ⭕
- 무한소수 중 순환하지 **않는** 것은 유리수가 **아니다**. (→ 중3에서 배울 **무리수**! 예: $\pi, \sqrt{2}$)

### 🔹 자주 출제되는 진위 판단

| 명제 | 참/거짓 |
|------|--------|
| 모든 유한소수는 유리수이다 | ⭕ 참 |
| 모든 무한소수는 유리수이다 | ❌ 거짓 (무리수 존재) |
| 모든 순환소수는 유리수이다 | ⭕ 참 |
| 유한소수로 나타낼 수 없는 유리수가 있다 | ⭕ 참 (순환소수 존재) |
| 정수가 아닌 유리수는 모두 유한소수이다 | ❌ 거짓 |

## 🎯 시험 자주 나오는 유형

1. **순환마디 찾기**: $\dfrac{1}{7} = 0.\dot{1}4285\dot{7}$ → 순환마디 142857
2. **소수점 아래 $n$번째 숫자 구하기**: 순환마디 자릿수로 나눈 나머지를 이용
3. **$\dfrac{a}{30}$이 유한소수가 되도록 하는 $a$의 값 구하기**: $30 = 2 \times 3 \times 5$이므로 $a$가 3의 배수여야 함
4. **순환소수 사칙연산**: 분수로 바꿔서 계산하기

# Ⅱ. 식의 계산

## 📌 핵심 개념 요약

### 1단원: 단항식의 계산
1. **지수법칙**: 곱셈/나눗셈/거듭제곱에서 지수를 다루는 5가지 규칙
2. **단항식의 곱셈과 나눗셈**: 계수는 계수끼리, 문자는 문자끼리

### 2단원: 다항식의 계산
3. **다항식의 덧셈/뺄셈**: 동류항끼리 정리
4. **(단항식) × (다항식)**: 분배법칙
5. **(다항식) ÷ (단항식)**: 역수를 곱하거나 분수꼴로

## 1. 단항식의 계산

### 1-1. 지수법칙 ⭐⭐⭐

지수법칙은 5가지가 있어요. **모든 계산의 기초**이니 완벽히 외워야 합니다!

#### 🔹 ① 지수의 합 (같은 밑의 곱셈)

$$a^m \times a^n = a^{m+n}$$

**같은 밑끼리 곱하면 지수는 더한다!**

**예시**:
- $x^2 \times x^3 = x^{2+3} = x^5$
- $2^4 \times 2^5 = 2^9$
- $a \times a^7 = a^{1+7} = a^8$ ($a = a^1$임을 기억!)

#### 🔹 ② 지수의 곱 (거듭제곱의 거듭제곱)

$$(a^m)^n = a^{m \times n}$$

**거듭제곱을 또 거듭제곱하면 지수는 곱한다!**

**예시**:
- $(x^3)^4 = x^{12}$
- $(2^2)^5 = 2^{10}$
- $\{(a^2)^3\}^4 = a^{2 \times 3 \times 4} = a^{24}$

#### 🔹 ③ 지수의 분배 (곱의 거듭제곱)

$$(ab)^n = a^n b^n$$

**곱의 거듭제곱은 각각에 분배한다!**

**예시**:
- $(2x)^3 = 2^3 x^3 = 8x^3$
- $(-3a^2b)^2 = (-3)^2 (a^2)^2 b^2 = 9a^4b^2$
- $\left(\dfrac{x}{y}\right)^4 = \dfrac{x^4}{y^4}$

⚠️ **부호 주의!**
- $(-2)^3 = -8$ (홀수 제곱 → 음수)
- $(-2)^4 = 16$ (짝수 제곱 → 양수)
- $-2^4 = -16$ ($-$를 거듭제곱에 포함 ❌)

#### 🔹 ④ 지수의 차 (같은 밑의 나눗셈)

$$a^m \div a^n = \begin{cases} a^{m-n} & (m > n) \\ 1 & (m = n) \\ \dfrac{1}{a^{n-m}} & (m < n) \end{cases} \quad (a \neq 0)$$

**같은 밑끼리 나누면 지수를 뺀다! (단, 크기 비교 주의)**

**예시**:
- $x^7 \div x^3 = x^{7-3} = x^4$ (큰 지수 - 작은 지수)
- $a^5 \div a^5 = 1$
- $y^3 \div y^8 = \dfrac{1}{y^{8-3}} = \dfrac{1}{y^5}$

#### 🔹 ⑤ 지수법칙 종합 정리표

| 규칙 | 공식 | 예시 |
|------|------|------|
| 같은 밑 곱셈 | $a^m \cdot a^n = a^{m+n}$ | $x^2 \cdot x^3 = x^5$ |
| 거듭제곱 | $(a^m)^n = a^{mn}$ | $(x^2)^3 = x^6$ |
| 곱의 거듭제곱 | $(ab)^n = a^n b^n$ | $(2x)^3 = 8x^3$ |
| 분수의 거듭제곱 | $\left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n}$ | $\left(\dfrac{x}{2}\right)^3 = \dfrac{x^3}{8}$ |
| 같은 밑 나눗셈 | $a^m \div a^n = a^{m-n}$ | $x^5 \div x^2 = x^3$ |

⚠️ **흔한 실수**:
- $a^m + a^n \neq a^{m+n}$ → 덧셈은 지수법칙 적용 ❌
- $x^2 + x^3$은 동류항이 아니므로 더 이상 정리 불가!

### 1-2. 단항식의 곱셈과 나눗셈

#### 🔹 단항식의 곱셈

**방법**: ① 계수는 계수끼리 ② 문자는 문자끼리 곱하기

**예시 1)** $3x^2 \times 4x^3$
$$= (3 \times 4) \times (x^2 \times x^3) = 12x^5$$

**예시 2)** $(-2a^2b) \times (3ab^3)$
$$= (-2 \times 3) \times (a^2 \times a) \times (b \times b^3) = -6a^3b^4$$

**예시 3)** $(2xy^2)^3 \times (-x^2y)$
$$= 8x^3y^6 \times (-x^2y) = -8x^5y^7$$

#### 🔹 단항식의 나눗셈

**방법 1**: 분수꼴로 고치기

$$A \div B = \dfrac{A}{B}$$

**방법 2**: 역수의 곱셈으로 고치기

$$A \div B = A \times \dfrac{1}{B}$$

**예시 1)** $12x^3 \div 4x$
$$= \dfrac{12x^3}{4x} = 3x^2$$

**예시 2)** $6a^2b \div \dfrac{2a}{b}$

분수가 포함되면 **역수의 곱셈**이 편해요!
$$= 6a^2b \times \dfrac{b}{2a} = 3ab^2$$

#### 🔹 곱셈과 나눗셈의 혼합 계산

**핵심 순서**:
1. 거듭제곱 먼저 풀기
2. 나눗셈을 곱셈으로 (역수)
3. 부호 결정
4. 계수끼리, 문자끼리 계산

**예제)** $(-2x^2)^3 \div 4x^3 \times 3x$

**Step 1)** 거듭제곱: $(-2x^2)^3 = -8x^6$
$$= -8x^6 \div 4x^3 \times 3x$$

**Step 2)** 나눗셈을 곱셈으로:
$$= -8x^6 \times \dfrac{1}{4x^3} \times 3x$$

**Step 3)** 계산:
$$= \dfrac{-8 \times 3}{4} \times \dfrac{x^6 \times x}{x^3} = -6x^4$$

⚠️ **순서 주의!** 나눗셈은 **앞에서부터 차례로** 계산해야 해요. $A \div B \times C \neq A \div (B \times C)$

## 2. 다항식의 계산

### 2-1. 다항식의 덧셈과 뺄셈

#### 🔹 동류항

문자와 차수가 **모두 같은** 항을 동류항이라고 해요.
- $3x^2$와 $-5x^2$ → 동류항 ⭕
- $2x$와 $2x^2$ → 동류항 ❌ (차수가 다름)
- $4xy$와 $4yx$ → 동류항 ⭕ (문자 순서 상관없음)

#### 🔹 덧셈/뺄셈 방법

1. 괄호 풀기 (괄호 앞이 $-$이면 부호 바뀜!)
2. 동류항끼리 모으기
3. 계수끼리 더하거나 빼기

**예시 1)** $(3x + 2y) + (5x - 4y)$
$$= 3x + 2y + 5x - 4y = 8x - 2y$$

**예시 2)** $(4a^2 - 3a + 1) - (2a^2 + a - 5)$
$$= 4a^2 - 3a + 1 - 2a^2 - a + 5$$
$$= 2a^2 - 4a + 6$$

⚠️ **괄호 앞 $-$ 부호 처리에 주의!** 괄호 안 모든 항의 부호가 바뀜!

#### 🔹 이차식의 덧셈/뺄셈

차수가 2인 항이 포함된 다항식이에요. 위와 같은 방법으로 정리하면 됩니다.

**예시)** $(x^2 + 3x - 2) + 2(x^2 - x + 4)$
$$= x^2 + 3x - 2 + 2x^2 - 2x + 8$$
$$= 3x^2 + x + 6$$

#### 🔹 여러 가지 괄호가 있을 때

**우선순위**: 소괄호 ( ) → 중괄호 { } → 대괄호 [ ]
**안쪽부터** 차례로 풀어주세요.

**예제)** $3x - \{2x - (5x - 1)\}$
$$= 3x - \{2x - 5x + 1\}$$
$$= 3x - \{-3x + 1\}$$
$$= 3x + 3x - 1 = 6x - 1$$

### 2-2. (단항식) × (다항식): 전개

#### 🔹 분배법칙 활용

$$a(b + c) = ab + ac$$

단항식을 다항식의 **모든 항에 곱해주는 것**이 분배법칙이에요.

**예시 1)** $3x(2x - 5)$
$$= 3x \times 2x + 3x \times (-5) = 6x^2 - 15x$$

**예시 2)** $-2a(3a^2 - a + 4)$
$$= -6a^3 + 2a^2 - 8a$$

⚠️ **부호 주의!** 음수를 곱할 때 모든 항의 부호가 바뀝니다.

### 2-3. (다항식) ÷ (단항식)

#### 🔹 방법 1: 분수꼴로

$$(A + B) \div C = \dfrac{A+B}{C} = \dfrac{A}{C} + \dfrac{B}{C}$$

**예시)** $(12x^2 + 8x) \div 4x$
$$= \dfrac{12x^2}{4x} + \dfrac{8x}{4x} = 3x + 2$$

#### 🔹 방법 2: 역수의 곱셈

나누는 식이 **분수**일 때 특히 유용!

$$(A + B) \div \dfrac{C}{D} = (A + B) \times \dfrac{D}{C}$$

**예시)** $(6x^2 - 9x) \div \dfrac{3x}{2}$
$$= (6x^2 - 9x) \times \dfrac{2}{3x}$$
$$= \dfrac{12x^2}{3x} - \dfrac{18x}{3x} = 4x - 6$$

### 2-4. 혼합 계산 (사칙연산 종합)

#### 🔹 계산 순서

1. **거듭제곱** 먼저
2. **괄호** 풀기 (곱셈/분배법칙)
3. **곱셈, 나눗셈**
4. **덧셈, 뺄셈**
5. **동류항**끼리 정리

#### 🔹 종합 예제

**예제)** $2x(3x - 1) - (8x^2 - 4x) \div 2x$

**Step 1)** 각 부분 계산:
- $2x(3x - 1) = 6x^2 - 2x$
- $(8x^2 - 4x) \div 2x = 4x - 2$

**Step 2)** 빼기 (괄호 처리에 주의!):
$$= (6x^2 - 2x) - (4x - 2)$$
$$= 6x^2 - 2x - 4x + 2$$
$$= 6x^2 - 6x + 2$$

## 🎯 시험 자주 나오는 유형

### 유형 1: 지수 안의 미지수 찾기
$2^x \times 4 = 2^7$일 때 $x$의 값은?
→ $2^x \times 2^2 = 2^7$ → $x + 2 = 7$ → **$x = 5$**

### 유형 2: 도형의 넓이/부피
- 가로 $3a$, 세로 $4b$, 높이 $2a^2b$인 직육면체의 부피
- $V = 3a \times 4b \times 2a^2b = 24a^3b^2$

### 유형 3: 어떤 식을 구하기 (역연산)
어떤 식에 $2x$를 곱했더니 $6x^3 - 4x^2$이 되었다. 어떤 식은?
→ $(6x^3 - 4x^2) \div 2x = 3x^2 - 2x$

### 유형 4: 잘못된 계산 바로잡기
"$A$에 $3x$를 더해야 할 것을 잘못해서 뺐더니 $5x - 1$이 나왔다. 바르게 계산한 답은?"
→ $A - 3x = 5x - 1$ → $A = 8x - 1$
→ 바른 계산: $A + 3x = 8x - 1 + 3x = 11x - 1$

### 유형 5: 식의 값 대입
$x = 2, y = -1$일 때 $3x^2y - 2xy^2$의 값
→ $3(4)(-1) - 2(2)(1) = -12 - 4 = -16$

## ⚠️ 자주 하는 실수 BEST 5

1. **$a^2 \times a^3 = a^6$** ❌ → 정답: $a^5$ (지수는 더하기!)
2. **$(a+b)^2 = a^2 + b^2$** ❌ → 중3에서 자세히 배우지만 이건 틀려요!
3. **$-3^2 = 9$** ❌ → 정답: $-9$ ($-(3^2) = -9$)
4. **괄호 앞 $-$ 부호 처리** → 안에 있는 **모든** 항의 부호가 바뀜!
5. **나눗셈 순서** → $A \div B \div C \neq A \div (B \div C)$, 반드시 앞에서부터!

# Ⅲ. 일차부등식

## 📌 핵심 개념 요약

### 1단원: 일차부등식
1. **부등식**: 부등호로 수나 식의 대소 관계를 나타낸 식
2. **부등식의 성질**: 양변에 같은 수를 더하거나 빼도 OK, **음수를 곱/나누면 부등호 방향 바뀜!** ⭐
3. **일차부등식의 풀이**: 이항 → 정리 → $x$의 계수로 나누기
4. **수직선 표현**: 해를 시각적으로 표현

### 2단원: 일차부등식의 활용
5. **활용 문제 푸는 단계**: 미지수 설정 → 부등식 세우기 → 풀기 → 확인
6. **유형별 접근**: 수, 도형, 거리·속력·시간, 농도, 가격 비교 등

## 1. 일차부등식

### 1-1. 부등식이란?

#### 🔹 부등식의 정의

**부등호**($>, <, \geq, \leq$)를 사용하여 수나 식의 **대소 관계**를 나타낸 식

#### 🔹 부등호의 의미

| 부등호 | 의미 | 읽기 |
|--------|------|------|
| $a > b$ | $a$는 $b$보다 크다 | "초과" |
| $a < b$ | $a$는 $b$보다 작다 | "미만" |
| $a \geq b$ | $a$는 $b$보다 크거나 같다 | "이상" |
| $a \leq b$ | $a$는 $b$보다 작거나 같다 | "이하" |

⚠️ **언어 표현 주의!**
- "$x$는 5보다 크다" → $x > 5$ (5는 포함 안 됨)
- "$x$는 5 이상이다" → $x \geq 5$ (5 포함!)
- "$x$는 5보다 작지 않다" → $x \geq 5$ ("작지 않다" = "크거나 같다")

#### 🔹 부등식의 해

부등식을 **참이 되게 하는** 미지수의 값. 방정식과 달리 **해가 무수히 많아요!**

**예)** $x + 2 > 5$의 해 → $x > 3$ (3보다 큰 모든 수)

### 1-2. 부등식의 성질 ⭐⭐⭐

이 단원에서 **가장 중요한 부분**이에요! 절대 잊으면 안 됩니다!

#### 🔹 성질 ① 양변에 같은 수를 더하거나 빼도 부등호 방향은 그대로

$$a < b \ \Rightarrow \ a + c < b + c, \ \ a - c < b - c$$

**예)** $3 < 5$의 양변에 2를 더하면 → $5 < 7$ ✅

#### 🔹 성질 ② 양변에 **양수**를 곱하거나 나누면 부등호 방향은 그대로

$$a < b, \ c > 0 \ \Rightarrow \ ac < bc, \ \ \dfrac{a}{c} < \dfrac{b}{c}$$

**예)** $3 < 5$의 양변에 2를 곱하면 → $6 < 10$ ✅

#### 🔹 성질 ③ 양변에 **음수**를 곱하거나 나누면 부등호 방향이 **바뀐다**! 🔥

$$a < b, \ c < 0 \ \Rightarrow \ ac > bc, \ \ \dfrac{a}{c} > \dfrac{b}{c}$$

**예)** $3 < 5$의 양변에 $-2$를 곱하면 → $-6 > -10$ (방향 바뀜!)

💡 **이해 팁**: 수직선에서 $3$과 $5$가 음수배 되면, $-6$과 $-10$이 되는데, $-10$이 더 왼쪽(작음)이고 $-6$이 더 오른쪽(큼)이 돼요. 그래서 부등호 방향이 뒤집힙니다!

#### 🔹 한눈에 정리

| 양변에 한 연산 | 부등호 방향 |
|---------------|-------------|
| 같은 수 더하기/빼기 | 그대로 ✅ |
| **양수** 곱하기/나누기 | 그대로 ✅ |
| **음수** 곱하기/나누기 | **반대로!** 🔄 |

### 1-3. 일차부등식의 풀이

#### 🔹 일차부등식이란?

부등식의 **모든 항을 좌변으로 이항**하여 정리했을 때

$$(\text{일차식}) > 0, \ < 0, \ \geq 0, \ \leq 0$$

꼴이 되는 부등식

**예)** $2x + 3 > 7$, $5 - x \leq 2x$

#### 🔹 풀이 순서

1. **괄호** 풀기
2. **계수**가 분수나 소수면 정수로 만들기
3. $x$가 있는 항은 **좌변**, 상수항은 **우변**으로 이항
4. 양변을 정리해 $ax > b$ 또는 $ax < b$ 꼴로
5. **$x$의 계수 $a$로 양변을 나누기** (이때 **$a$가 음수면 부등호 방향 바뀜!**) ⚠️

#### 🔹 기본 예제

**예제 1)** $3x - 5 > 7$

$3x > 12$ → $x > 4$

**예제 2)** $-2x + 1 \leq 9$

$-2x \leq 8$ → **$x \geq -4$** (음수로 나눠서 방향 바뀜! 🔄)

**예제 3)** $4x + 3 < 6x - 7$

$4x - 6x < -7 - 3$
$-2x < -10$
$x > 5$ (음수로 나눠서 방향 바뀜!)

#### 🔹 분수/소수 포함 부등식

**예제 4)** $\dfrac{x-1}{3} + \dfrac{x}{2} \geq 1$

양변에 분모의 최소공배수 **6을 곱하기**:
$$2(x-1) + 3x \geq 6$$
$$2x - 2 + 3x \geq 6$$
$$5x \geq 8$$
$$x \geq \dfrac{8}{5}$$

**예제 5)** $0.3x - 0.5 < 0.1x + 0.7$

양변에 **10을 곱하기**:
$$3x - 5 < x + 7$$
$$2x < 12$$
$$x < 6$$

### 1-4. 수직선 위에 해 나타내기

부등식의 해는 수직선에 표시할 수 있어요.

| 부등식 | 수직선 표현 |
|--------|------------|
| $x > a$ | $a$에 **○** (열린 점), 오른쪽 화살표 |
| $x < a$ | $a$에 **○** (열린 점), 왼쪽 화살표 |
| $x \geq a$ | $a$에 **●** (닫힌 점), 오른쪽 화살표 |
| $x \leq a$ | $a$에 **●** (닫힌 점), 왼쪽 화살표 |

💡 **포인트**: 등호가 있으면 ● (포함), 없으면 ○ (미포함)

```
x > 3:  ────────○━━━━━━▶
                3

x ≤ -1: ◀━━━━━━●────────
               -1
```

## 2. 일차부등식의 활용

### 2-1. 활용 문제 풀이 4단계

활용 문제는 **방정식과 똑같은 4단계**로 접근하면 됩니다!

#### 🔹 풀이 단계

**Step 1) 미지수 설정**: 구하려는 것을 $x$로 놓기
**Step 2) 부등식 세우기**: 문제 조건을 부등식으로 표현
**Step 3) 부등식 풀기**: 일차부등식 푸는 방법대로
**Step 4) 답 확인**: 문제 조건(자연수, 정수 등)에 맞는지 확인

⚠️ **활용 문제의 핵심**: "이상/이하/초과/미만"을 정확히 부등호로 옮기기!

| 표현 | 부등호 |
|------|--------|
| "$\sim$보다 크다 / 초과" | $>$ |
| "$\sim$보다 작다 / 미만" | $<$ |
| "$\sim$ 이상 / 적어도 / 최소" | $\geq$ |
| "$\sim$ 이하 / 많아야 / 최대" | $\leq$ |

### 2-2. 유형별 활용 문제

#### 🔹 유형 1: 수에 관한 문제

**예제)** 어떤 자연수의 3배에서 5를 뺀 수가 16보다 작다고 한다. 이러한 자연수 중 가장 큰 수는?

**풀이**:
- 자연수를 $x$라 하면: $3x - 5 < 16$
- $3x < 21$ → $x < 7$
- 자연수이면서 7보다 작은 가장 큰 수 → **6**

#### 🔹 유형 2: 도형에 관한 문제

**예제)** 밑변의 길이가 8cm인 삼각형의 넓이가 24cm² 이상이 되려면 높이는 얼마 이상이어야 할까?

**풀이**:
- 높이를 $x$cm라 하면 넓이: $\dfrac{1}{2} \times 8 \times x = 4x$
- 부등식: $4x \geq 24$ → $x \geq 6$
- **높이는 6cm 이상**

#### 🔹 유형 3: 가격 비교 (예금, 구입)

**예제)** 현재 형은 10,000원, 동생은 4,000원을 가지고 있다. 매달 형은 1,000원, 동생은 2,000원씩 저금한다면, 몇 달 후부터 동생의 저금액이 형보다 많아질까?

**풀이**:
- $x$달 후 → 형: $10000 + 1000x$, 동생: $4000 + 2000x$
- 부등식: $4000 + 2000x > 10000 + 1000x$
- $1000x > 6000$ → $x > 6$
- **7개월 후부터** (자연수 조건!)

#### 🔹 유형 4: 개수 선택 (구입 가능 개수)

**예제)** 한 개에 800원인 사과와 500원인 귤을 합해서 10개를 사고 7,000원 이하로 지불하려고 한다. 사과는 최대 몇 개까지 살 수 있을까?

**풀이**:
- 사과를 $x$개, 귤을 $(10-x)$개라 하면:
- $800x + 500(10-x) \leq 7000$
- $800x + 5000 - 500x \leq 7000$
- $300x \leq 2000$ → $x \leq \dfrac{20}{3} = 6.66\cdots$
- 자연수 조건이므로 **최대 6개**

#### 🔹 유형 5: 거리·속력·시간 ⭐

**기본 공식**:
$$(\text{거리}) = (\text{속력}) \times (\text{시간})$$
$$(\text{시간}) = \dfrac{\text{거리}}{\text{속력}}, \ \ (\text{속력}) = \dfrac{\text{거리}}{\text{시간}}$$

**예제)** 산 정상까지 갔다 오는데, 올라갈 때는 시속 2km, 내려올 때는 시속 3km로 걸었다. 전체 걸린 시간이 5시간 이내가 되도록 하려면 정상까지의 거리는 몇 km 이하여야 할까?

**풀이**:
- 정상까지의 거리를 $x$km라 하면:
- 올라갈 때 시간: $\dfrac{x}{2}$시간, 내려올 때 시간: $\dfrac{x}{3}$시간
- 부등식: $\dfrac{x}{2} + \dfrac{x}{3} \leq 5$
- 양변에 6 곱: $3x + 2x \leq 30$ → $5x \leq 30$ → $x \leq 6$
- **정상까지 6km 이하**

#### 🔹 유형 6: 농도 (소금물 문제) ⭐

**기본 공식**:
$$(\text{소금의 양}) = \dfrac{\text{농도}(\%)}{100} \times (\text{소금물의 양})$$

**예제)** 8% 소금물 200g에 물을 더 넣어 농도를 5% 이하로 만들려고 한다. 물을 최소 몇 g 더 넣어야 할까?

**풀이**:
- 소금의 양: $\dfrac{8}{100} \times 200 = 16$g (불변!)
- 더 넣는 물의 양을 $x$g이라 하면, 새 소금물의 양: $(200 + x)$g
- 부등식: $\dfrac{16}{200 + x} \times 100 \leq 5$
- $\dfrac{1600}{200+x} \leq 5$
- 양변에 $(200+x)$ 곱 (양수이므로 부등호 그대로): $1600 \leq 5(200+x)$
- $1600 \leq 1000 + 5x$ → $600 \leq 5x$ → $x \geq 120$
- **물을 최소 120g 더 넣어야 한다**

#### 🔹 유형 7: 유리한 선택 (어디가 더 싼가?)

**예제)** 동네 마트에서는 한 개에 1,500원인 음료를 박물관 매점에서는 한 개에 1,000원에 판다고 한다. 박물관까지 왕복 차비가 3,000원이라면, 음료를 몇 개 이상 살 때 박물관에서 사는 것이 유리할까?

**풀이**:
- 음료를 $x$개 산다고 하면:
- 동네: $1500x$원, 박물관: $1000x + 3000$원
- 부등식: $1000x + 3000 < 1500x$
- $-500x < -3000$ → $x > 6$
- **7개 이상**일 때 박물관이 유리

## 🎯 시험 자주 나오는 유형 BEST 5

### ✅ 1. 부등식의 성질 적용
"$-2 < x \leq 3$일 때, $-3x + 1$의 값의 범위는?"
- 모든 변에 $-3$ 곱: $6 > -3x \geq -9$ → $-9 \leq -3x < 6$
- 모든 변에 $+1$: $-8 \leq -3x + 1 < 7$

### ✅ 2. $a$ 값에 따른 해 구분 (음수 케이스 주의!)
"$ax > 2a$의 해가 $x < 2$일 때, $a$의 부호는?"
→ 부등호 방향이 바뀌었으므로 **$a < 0$**

### ✅ 3. 가장 큰/작은 자연수 해
"$2x + 5 \leq 13$을 만족하는 자연수 $x$ 중 가장 큰 값은?"
→ $x \leq 4$ → 최대 자연수 **4**

### ✅ 4. 활용 문제 (최대/최소)
"~ 최대 몇 개까지", "~ 최소 며칠 후" → 부등식 푼 후 자연수 조건 확인!

## ⚠️ 자주 하는 실수 BEST 5

1. **음수 곱/나눗셈에서 부등호 방향 안 바꿈** 🔥 (1등 실수!)
   - $-2x > 6$ → $x > -3$ ❌ → 정답: $x < -3$

2. **"이상/이하"와 "초과/미만" 혼동**
   - "5 이상" = $\geq 5$ (5 포함)
   - "5 초과" = $> 5$ (5 미포함)

3. **이항할 때 부등호 방향 잘못 바꿈**
   - 이항은 단순한 ±부호 변환! 부등호 방향은 **그대로**!
   - $3x + 2 > 5$ → $3x > 3$ ✅ (부등호 그대로)

4. **활용 문제에서 단위/조건 확인 안 함**
   - "자연수" 조건, "정수" 조건 → 답이 다름!
   - "분 → 시간" 단위 통일!

5. **분수/소수 부등식에서 부호 실수**
   - 양변에 음수를 곱해 정수로 만들면 → 방향 바뀜! 가능하면 **양수 곱하기**!

# Ⅳ. 연립일차방정식

## 📌 핵심 개념 요약

### 1단원: 연립일차방정식
1. **미지수가 2개인 일차방정식**: $ax + by + c = 0$ 꼴
2. **연립방정식**: 두 일차방정식을 한 쌍으로 묶은 것

4. **풀이법**: ① 대입법 ② 가감법
5. **특수한 해**: 해가 무수히 많거나, 없는 경우

### 2단원: 연립일차방정식의 활용
6. **활용 4단계**: 미지수 설정 → 연립방정식 세우기 → 풀기 → 확인
7. **유형별 접근**: 수, 가격, 거리·속력·시간, 농도, 일률, 도형 등

## 1. 연립일차방정식

### 1-1. 미지수가 2개인 일차방정식

#### 🔹 정의

미지수가 **두 개**(보통 $x, y$)이고, 그 차수가 모두 **1**인 방정식

$$ax + by + c = 0 \quad (a, b \neq 0)$$

**예)** $2x + 3y = 12$, $x - y = 5$

#### 🔹 해(解)

방정식을 **참**이 되게 하는 $x, y$의 값의 쌍 $(x, y)$

⚠️ **중요**: 미지수가 2개인 일차방정식 한 개만 있을 때는 **해가 무수히 많아요!**

**예)** $x + y = 5$의 해:
- $(0, 5), (1, 4), (2, 3), (3, 2), \cdots$ → 무한히 많음

→ 그래서 **방정식이 하나 더 필요**합니다. 그게 바로 **연립방정식**!

### 1-2. 연립일차방정식

#### 🔹 정의

미지수가 2개인 두 일차방정식을 **한 쌍으로 묶은 것**

$$\begin{cases} ax + by = c \\ dx + ey = f \end{cases}$$

#### 🔹 연립방정식의 해

**두 방정식을 동시에 만족시키는** $x, y$의 값의 쌍 $(x, y)$

**예)** $\begin{cases} x + y = 5 \\ x - y = 1 \end{cases}$

→ $(x, y) = (3, 2)$ 하나뿐!
- ① 검산: $3 + 2 = 5$ ✅
- ② 검산: $3 - 2 = 1$ ✅

### 1-3. 풀이법 ① 대입법

#### 🔹 원리

**한 미지수를 다른 미지수로 표현**해서 다른 식에 **대입**하는 방법

#### 🔹 풀이 순서

1. 한 방정식에서 한 미지수를 **다른 미지수의 식으로** 정리
2. 그 식을 **다른 방정식에 대입**
3. 미지수가 1개인 일차방정식을 풀기
4. 구한 값을 처음 식에 대입해 나머지 미지수 구하기

#### 🔹 예제

**예제)** $\begin{cases} y = 2x - 1 & \cdots ① \\ 3x + y = 9 & \cdots ② \end{cases}$

**Step 1)** ①을 ②에 대입:
$$3x + (2x - 1) = 9$$

**Step 2)** 정리해서 풀기:
$$5x - 1 = 9 \to 5x = 10 \to x = 2$$

**Step 3)** $x = 2$를 ①에 대입:
$$y = 2(2) - 1 = 3$$

**∴ 해는 $(x, y) = (2, 3)$**

💡 **대입법이 좋은 경우**: 한 식이 이미 $y = \cdots$ 또는 $x = \cdots$ 꼴로 정리되어 있을 때!

### 1-4. 풀이법 ② 가감법 ⭐ (자주 사용!)

#### 🔹 원리

**한 미지수의 계수의 절댓값을 같게 만든 후**, 두 식을 **더하거나 빼서** 그 미지수를 없애는 방법

#### 🔹 풀이 순서

1. 두 방정식에서 **없앨 미지수**의 계수의 **절댓값**을 같게 만들기 (적절한 수를 양변에 곱하기)
2. 부호가 같으면 **빼기**, 부호가 다르면 **더하기**
3. 미지수가 1개인 일차방정식 풀기
4. 구한 값을 한 방정식에 대입해 나머지 미지수 구하기

#### 🔹 예제 1: 빼서 없애기

**예제)** $\begin{cases} 2x + 3y = 12 & \cdots ① \\ 2x - y = 4 & \cdots ② \end{cases}$

$x$의 계수가 둘 다 $+2$로 같으므로 **빼기**:

$$① - ②: \ \ 4y = 8 \to y = 2$$

$y = 2$를 ②에 대입:
$$2x - 2 = 4 \to x = 3$$

**∴ 해는 $(x, y) = (3, 2)$**

#### 🔹 예제 2: 계수 맞춰서 없애기

**예제)** $\begin{cases} 3x + 2y = 13 & \cdots ① \\ 2x + 5y = 16 & \cdots ② \end{cases}$

$x$를 없애기 위해 ①×2, ②×3:
$$\begin{cases} 6x + 4y = 26 & \cdots ①' \\ 6x + 15y = 48 & \cdots ②' \end{cases}$$

②' − ①': $11y = 22 \to y = 2$

$y = 2$를 ①에 대입: $3x + 4 = 13 \to x = 3$

**∴ 해는 $(x, y) = (3, 2)$**

#### 🔹 예제 3: 부호가 다르면 더하기

**예제)** $\begin{cases} 2x + 3y = 7 \\ -2x + 5y = 9 \end{cases}$

$x$의 계수가 $+2, -2$로 부호가 다르므로 **더하기**:
$$8y = 16 \to y = 2$$

$y = 2$ 대입: $2x + 6 = 7 \to x = \dfrac{1}{2}$

**∴ 해는 $(x, y) = \left(\dfrac{1}{2}, 2\right)$**

💡 **가감법이 좋은 경우**: 계수가 정수로 깔끔하게 정리되어 있을 때 (대부분의 문제!)

### 1-5. 복잡한 연립방정식

#### 🔹 괄호가 있는 경우

먼저 **괄호를 풀고** 정리한 후 풀이!

**예제)** $\begin{cases} 2(x - y) + 3y = 7 \\ x + 2y = 5 \end{cases}$

①을 정리: $2x - 2y + 3y = 7 \to 2x + y = 7$
$$\begin{cases} 2x + y = 7 \\ x + 2y = 5 \end{cases}$$
이후 가감법/대입법으로 해결!

#### 🔹 분수/소수가 포함된 경우

분수면 **분모의 최소공배수**, 소수면 **10, 100**을 곱해 **정수 계수**로!

**예제)** $\begin{cases} \dfrac{x}{2} + \dfrac{y}{3} = 1 & \cdots ① \\ 0.2x - 0.3y = 0.1 & \cdots ② \end{cases}$

①에 6을 곱: $3x + 2y = 6$
②에 10을 곱: $2x - 3y = 1$
$$\begin{cases} 3x + 2y = 6 \\ 2x - 3y = 1 \end{cases}$$
이후 가감법으로 풀이!

#### 🔹 A = B = C 꼴 (삼중 등식)

세 식 중 **두 쌍을 골라** 연립방정식으로 만들기!

$$A = B = C \ \Rightarrow \ \begin{cases} A = B \\ B = C \end{cases} \ \text{또는} \ \begin{cases} A = B \\ A = C \end{cases} \ \text{또는} \ \begin{cases} A = C \\ B = C \end{cases}$$

**예제)** $2x + y = x - y = 5$

$$\begin{cases} 2x + y = 5 \\ x - y = 5 \end{cases}$$
더하면: $3x = 10 \to x = \dfrac{10}{3}$ ... (이후 동일하게)

💡 **꿀팁**: 상수 부분이 같은 식이 있으면 그것끼리 묶으면 편해요!

### 1-6. 특수한 해 ⭐

#### 🔹 해가 무수히 많은 경우

두 방정식이 **본질적으로 같은 식**일 때

$$\begin{cases} 2x + 3y = 6 \\ 4x + 6y = 12 \end{cases}$$
→ 두 번째 식은 첫 번째에 2를 곱한 것과 동일!
→ **해가 무수히 많음**

**판별법**: $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} = \dfrac{c_1}{c_2}$ (계수 비, 상수 비 모두 같음)

#### 🔹 해가 없는 경우

두 방정식이 **서로 모순**될 때

$$\begin{cases} 2x + 3y = 6 \\ 4x + 6y = 15 \end{cases}$$
→ 좌변의 비는 같은데 우변의 비가 다름 → 동시 만족 불가능
→ **해가 없음**

**판별법**: $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} \neq \dfrac{c_1}{c_2}$

#### 🔹 한눈에 정리

| 조건 | 해 |
|------|-----|
| $\dfrac{a_1}{a_2} \neq \dfrac{b_1}{b_2}$ | **한 쌍** (보통의 경우) |
| $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} = \dfrac{c_1}{c_2}$ | **무수히 많음** |
| $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} \neq \dfrac{c_1}{c_2}$ | **없음** |

## 2. 연립일차방정식의 활용

### 2-1. 활용 문제 풀이 4단계

#### 🔹 단계별 접근

**Step 1) 미지수 설정**: 구하려는 두 값을 $x, y$로 놓기
**Step 2) 연립방정식 세우기**: 문제에서 **두 가지 조건**을 찾아 각각 식으로!
**Step 3) 연립방정식 풀기**: 대입법 또는 가감법
**Step 4) 답 확인**: 자연수, 정수, 단위 등 조건 확인

💡 **핵심**: 문제에서 "조건이 두 가지" 보이면 무조건 연립방정식!

### 2-2. 유형별 활용 문제

#### 🔹 유형 1: 수에 관한 문제

**예제)** 두 자연수의 합은 30, 차는 6. 두 수를 구하시오.

- $\begin{cases} x + y = 30 \\ x - y = 6 \end{cases}$ → $x = 18, y = 12$

#### 🔹 유형 2: 자릿수 문제

**예제)** 두 자리 자연수가 있다. 십의 자리 숫자와 일의 자리 숫자의 합은 9이고, 십의 자리 숫자와 일의 자리 숫자를 바꾼 수는 처음 수보다 27이 크다. 처음 수를 구하시오.

**Tip**: 두 자리 수는 **$10a + b$** ($a$: 십의 자리, $b$: 일의 자리)

**풀이**:
- 십의 자리 $x$, 일의 자리 $y$:
- 처음 수: $10x + y$, 바꾼 수: $10y + x$
- $\begin{cases} x + y = 9 \\ 10y + x = (10x + y) + 27 \end{cases}$
- 둘째 식 정리: $9y - 9x = 27 \to y - x = 3$
- $\begin{cases} x + y = 9 \\ -x + y = 3 \end{cases}$ → 더하면 $2y = 12, y = 6, x = 3$
- **처음 수는 36** ✅ (확인: 합 3+6=9, 63-36=27)

#### 🔹 유형 3: 가격 문제

**예제)** 사과 3개와 배 2개의 값은 9,000원이고, 사과 2개와 배 4개의 값은 12,000원이다. 사과 한 개와 배 한 개의 가격은?

**풀이**:
- 사과 $x$원, 배 $y$원:
- $\begin{cases} 3x + 2y = 9000 \\ 2x + 4y = 12000 \end{cases}$
- ①×2 − ②: $4x = 6000 \to x = 1500$
- ①에 대입: $4500 + 2y = 9000 \to y = 2250$
- **사과 1,500원, 배 2,250원**

#### 🔹 유형 4: 거리·속력·시간 ⭐

**기본 공식**:
$$\text{거리} = \text{속력} \times \text{시간}, \quad \text{시간} = \dfrac{\text{거리}}{\text{속력}}$$

**예제)** A 지점에서 B 지점까지 가는데, 처음에는 시속 4km로 걷다가 도중에 시속 6km로 뛰어서 총 3시간 만에 도착했다. 총 거리가 14km라면, 걸은 거리와 뛴 거리는 각각?

**풀이**:
- 걸은 거리 $x$km, 뛴 거리 $y$km:
- $\begin{cases} x + y = 14 & (\text{거리 합}) \\ \dfrac{x}{4} + \dfrac{y}{6} = 3 & (\text{시간 합}) \end{cases}$
- 두 번째 식 ×12: $3x + 2y = 36$
- $\begin{cases} x + y = 14 \\ 3x + 2y = 36 \end{cases}$ → 첫 식 ×2 빼면 $x = 8, y = 6$
- **걸은 거리 8km, 뛴 거리 6km**

#### 🔹 유형 5: 농도(소금물) 문제 ⭐

**기본 공식**:
$$\text{소금의 양} = \dfrac{\text{농도}(\%)}{100} \times \text{소금물의 양}$$

**예제)** 5% 소금물과 10% 소금물을 섞어 8% 소금물 500g을 만들려고 한다. 각각 몇 g씩 섞어야 할까?

**풀이**:
- 5% 소금물 $x$g, 10% 소금물 $y$g:
- $\begin{cases} x + y = 500 & (\text{소금물의 양 합}) \\ \dfrac{5}{100}x + \dfrac{10}{100}y = \dfrac{8}{100} \times 500 & (\text{소금의 양 합}) \end{cases}$
- 둘째 식 ×100: $5x + 10y = 4000 \to x + 2y = 800$
- $\begin{cases} x + y = 500 \\ x + 2y = 800 \end{cases}$ → 빼면 $y = 300, x = 200$
- **5% 소금물 200g, 10% 소금물 300g**

#### 🔹 유형 6: 증가·감소(비율) 문제

**예제)** 어느 학교의 작년 학생 수는 700명이었다. 올해는 작년에 비해 남학생이 5% 증가하고, 여학생이 10% 감소하여 전체 학생 수가 5명 늘었다. 작년 남학생 수와 여학생 수를 각각 구하시오.

**풀이**:
- 작년 남학생 $x$, 여학생 $y$:
- $\begin{cases} x + y = 700 \\ \dfrac{5}{100}x - \dfrac{10}{100}y = 5 \end{cases}$
- 둘째 식 ×100: $5x - 10y = 500 \to x - 2y = 100$
- $\begin{cases} x + y = 700 \\ x - 2y = 100 \end{cases}$ → $3y = 600, y = 200, x = 500$
- **작년 남학생 500명, 여학생 200명**

💡 **유의**: 답이 "작년 학생 수"인지 "올해 학생 수"인지 정확히 읽기!

#### 🔹 유형 7: 도형 문제

**예제)** 둘레가 30cm인 직사각형이 있다. 가로의 길이가 세로의 길이보다 3cm 더 길다면, 가로와 세로의 길이는?

**풀이**:
- 가로 $x$, 세로 $y$:
- $\begin{cases} 2(x + y) = 30 \\ x = y + 3 \end{cases}$
- ①: $x + y = 15$
- 대입: $(y + 3) + y = 15 \to 2y = 12 \to y = 6, x = 9$
- **가로 9cm, 세로 6cm**

## 🎯 시험 자주 나오는 유형 BEST 5

### ✅ 1. 한 미지수의 값으로 다른 값 구하기
"$x = 3$이 $2x - y = 4$의 해일 때, $y = ?$" → $6 - y = 4, y = 2$

### ✅ 2. 해가 같은 두 연립방정식
$\begin{cases} 2x + y = 8 \\ x - y = 1 \end{cases}$의 해와 $\begin{cases} ax + y = 5 \\ x + by = 4 \end{cases}$의 해가 같다.
→ 먼저 첫 연립 풀어 해 $(3, 2)$ 구하기 → 둘째 식에 대입해 $a, b$ 구하기

### ✅ 3. A = B = C 꼴
$x + 2y = 2x - y = 7$ → $\begin{cases} x + 2y = 7 \\ 2x - y = 7 \end{cases}$

### ✅ 4. 활용 (특히 거리·속력·시간, 농도)
시험 단골! 표 그려서 정리하면 식 세우기 쉬워요.

## ⚠️ 자주 하는 실수 BEST 5

1. **계수 맞출 때 한쪽 변만 곱함**
   - ① 식 양변 모두에 곱해야 함! 한쪽만 곱하면 등식 깨짐!

2. **부호 실수 (가감법에서)**
   - 부호가 같으면 빼기, 다르면 더하기. 헷갈리면 천천히!

3. **대입 후 괄호 안 침**
   - $y = 2x - 1$을 대입할 때 $3(2x - 1)$처럼 **괄호** 꼭!

4. **활용 문제에서 미지수 정의 모호**
   - "남학생 수가 5% 증가" → "증가량"인지 "총량"인지 명확히!

5. **단위 통일 안 함**
   - 시간(분 vs 시), 거리(m vs km) 단위 통일 필수!

# Ⅴ. 일차함수

## 📌 핵심 개념 요약

### 1단원: 일차함수와 그 그래프
1. **함수**: $x$ 값 하나에 $y$ 값 하나가 대응되는 관계
2. **일차함수**: $y = ax + b$ ($a \neq 0$) 꼴
3. **그래프**: 좌표평면 위의 **직선**
4. **기울기, $x$절편, $y$절편**: 직선을 그리는 3가지 정보
5. **평행이동**: $y = ax$를 $y$축 방향으로 $b$만큼 평행이동 = $y = ax + b$
6. **기울기와 절편의 부호**: 직선의 모양 판단

### 2단원: 일차함수와 일차방정식의 관계
7. **일차방정식 $ax + by + c = 0$의 그래프** = 일차함수의 그래프
8. **연립방정식의 해 = 두 그래프의 교점**
9. **해의 개수**: 한 점, 무수히 많음, 없음

## 1. 일차함수와 그 그래프

### 1-1. 함수의 뜻

#### 🔹 함수란?

두 변수 $x, y$에 대해 $x$의 값이 정해지면 $y$의 값이 **오직 하나** 정해지는 대응 관계

$$y = f(x)$$

⚠️ 핵심: "$x$ 하나에 $y$도 하나"여야 함수!

**예시**:
- $y = 2x + 1$ → $x = 3$이면 $y = 7$ 하나 → **함수 ⭕**
- $y$는 $x$의 약수 → $x = 6$이면 $y = 1, 2, 3, 6$ → **함수 ❌**

#### 🔹 함숫값

$x = a$일 때의 $y$의 값을 **함숫값**이라 하고 $f(a)$로 표시

**예)** $f(x) = 3x - 2$일 때:
- $f(1) = 3(1) - 2 = 1$
- $f(-2) = 3(-2) - 2 = -8$
- $f(0) = -2$

### 1-2. 일차함수의 뜻

#### 🔹 정의

$y$를 $x$에 관한 식으로 나타냈을 때

$$y = ax + b \quad (a \neq 0)$$

꼴이면, $y$는 $x$의 **일차함수**라고 해요.

⚠️ $a = 0$이면 $y = b$ (상수함수, 일차함수 ❌)

**예시**:
- $y = 2x + 3$ ⭕
- $y = -\dfrac{1}{2}x$ ⭕ ($b = 0$도 OK)
- $y = 5$ ❌ ($a = 0$, 상수함수)
- $y = x^2 + 1$ ❌ (이차함수)
- $y = \dfrac{3}{x}$ ❌ (반비례)

### 1-3. 일차함수의 그래프

#### 🔹 $y = ax$의 그래프

- **원점을 지나는 직선** (정비례 관계)
- $a > 0$: 오른쪽 위로 (1, 3사분면)
- $a < 0$: 오른쪽 아래로 (2, 4사분면)
- $|a|$가 클수록 직선이 가팔라짐

#### 🔹 $y = ax + b$의 그래프 (평행이동) ⭐

$$y = ax + b \text{의 그래프} = y = ax \text{의 그래프를 } y\text{축 방향으로 } b \text{만큼 평행이동}$$

**예시**: $y = 2x + 3$은 $y = 2x$를 $y$축으로 3만큼 위로 이동한 직선

| $b > 0$ | 위로 평행이동 |
|---------|---------------|
| $b < 0$ | 아래로 평행이동 |
| $b = 0$ | 원점을 지남 (이동 없음) |

### 1-4. $x$절편과 $y$절편 ⭐

#### 🔹 정의

- **$x$절편**: 그래프가 $x$축과 만나는 점의 $x$좌표 → **$y = 0$일 때의 $x$ 값**
- **$y$절편**: 그래프가 $y$축과 만나는 점의 $y$좌표 → **$x = 0$일 때의 $y$ 값**

#### 🔹 $y = ax + b$의 절편

**$y$절편**: $x = 0$ 대입 → $y = b$
$$\boxed{y\text{절편} = b}$$

**$x$절편**: $y = 0$ 대입 → $0 = ax + b$ → $x = -\dfrac{b}{a}$
$$\boxed{x\text{절편} = -\dfrac{b}{a}}$$

#### 🔹 예시

$y = 2x - 6$의 절편 구하기:
- $y$절편: $b = -6$
- $x$절편: $0 = 2x - 6 \to x = 3$

→ 두 점 $(3, 0)$, $(0, -6)$을 지나는 직선!

#### 🔹 절편으로 그래프 그리기 ⭐

**가장 빠른 방법**: $x$절편과 $y$절편 두 점을 좌표평면에 찍고 직선으로 연결!

### 1-5. 기울기 ⭐⭐⭐

#### 🔹 정의

직선이 **얼마나 가파른지**를 나타내는 값

$$\text{기울기} = \dfrac{y\text{의 증가량}}{x\text{의 증가량}} = \dfrac{\Delta y}{\Delta x}$$

#### 🔹 $y = ax + b$의 기울기

$$\boxed{\text{기울기} = a}$$

즉, $x$ 앞의 계수가 그대로 기울기!

#### 🔹 두 점이 주어졌을 때

두 점 $(x_1, y_1), (x_2, y_2)$을 지나는 직선의 기울기:

$$a = \dfrac{y_2 - y_1}{x_2 - x_1}$$

**예시)** 두 점 $(1, 2), (4, 8)$을 지나는 직선의 기울기:
$$a = \dfrac{8 - 2}{4 - 1} = \dfrac{6}{3} = 2$$

#### 🔹 기울기의 의미

- **$a > 0$**: 오른쪽 위로 (상승) ↗
- **$a < 0$**: 오른쪽 아래로 (하강) ↘
- **$|a|$가 클수록 가파름**
- **$a = 0$**: 수평선 (일차함수 ❌)

### 1-6. 일차함수의 그래프 그리는 3가지 방법

#### 🔹 방법 1: $x$절편 & $y$절편 이용 (가장 빠름!)

두 절편을 좌표평면에 찍고 직선으로!

#### 🔹 방법 2: $y$절편 & 기울기 이용

1. $y$절편 점 찍기
2. 그 점에서 **오른쪽으로 1, 위로 $a$**만큼 이동한 점 찍기 (단, $a$가 음수면 아래로)
3. 두 점 연결

**예시)** $y = 2x + 1$
- $y$절편 $(0, 1)$ 찍기
- 기울기가 2이므로 → 오른쪽 1, 위로 2 → $(1, 3)$
- 두 점 연결!

#### 🔹 방법 3: 두 점 대입

$x$에 임의의 값 2개를 넣어 $y$ 구한 후 두 점 연결

### 1-7. 일차함수 식 구하기 ⭐

#### 🔹 ① 기울기와 $y$절편을 알 때

$$y = ax + b$$
에 그대로 대입!

**예)** 기울기 $-3$, $y$절편 $5$ → $y = -3x + 5$

#### 🔹 ② 기울기와 한 점이 주어질 때

$y = ax + b$에 기울기 $a$를 대입한 후, 점의 좌표를 대입해 $b$ 구하기

**예)** 기울기 2, 점 $(1, 5)$ 지남
- $y = 2x + b$에 $(1, 5)$ 대입: $5 = 2 + b \to b = 3$
- ∴ $y = 2x + 3$

#### 🔹 ③ 두 점이 주어질 때

1. 두 점으로 기울기 구하기
2. 한 점을 대입해 $b$ 구하기

**예)** 두 점 $(1, 3), (3, 7)$ 지남
- 기울기: $a = \dfrac{7-3}{3-1} = 2$
- $y = 2x + b$에 $(1, 3)$ 대입: $3 = 2 + b \to b = 1$
- ∴ $y = 2x + 1$

#### 🔹 ④ $x$절편 $m$, $y$절편 $n$이 주어질 때

두 점 $(m, 0), (0, n)$을 지나므로 기울기는 $-\dfrac{n}{m}$, $y$절편은 $n$

$$y = -\dfrac{n}{m}x + n$$

**예)** $x$절편 4, $y$절편 −2
- $y = -\dfrac{-2}{4}x + (-2) = \dfrac{1}{2}x - 2$

### 1-8. 그래프의 위치와 $a, b$의 부호 ⭐

이 부분 시험에 자주 출제돼요!

#### 🔹 기울기 $a$의 부호

- **$a > 0$**: 그래프가 **오른쪽 위로** 향함 (↗) → 제1, 3사분면 방향
- **$a < 0$**: 그래프가 **오른쪽 아래로** 향함 (↘) → 제2, 4사분면 방향

#### 🔹 $y$절편 $b$의 부호

- **$b > 0$**: 그래프가 $y$축과 **양의 부분**에서 만남 → 원점 위쪽
- **$b < 0$**: 그래프가 $y$축과 **음의 부분**에서 만남 → 원점 아래쪽
- **$b = 0$**: 원점 통과

#### 🔹 사분면 통과 정리

| $a$의 부호 | $b$의 부호 | 지나는 사분면 |
|------------|------------|----------------|
| $a > 0$ | $b > 0$ | 1, 2, 3사분면 |
| $a > 0$ | $b < 0$ | 1, 3, 4사분면 |
| $a < 0$ | $b > 0$ | 1, 2, 4사분면 |
| $a < 0$ | $b < 0$ | 2, 3, 4사분면 |

💡 **외우는 팁**: 직선의 모양을 머릿속에 그려보면 자연스럽게 알 수 있어요!

### 1-9. 두 일차함수 그래프의 위치 관계

#### 🔹 평행

두 직선이 **만나지 않음**

$$y = a_1 x + b_1 \ \text{과} \ y = a_2 x + b_2 \ \text{평행} \Leftrightarrow a_1 = a_2, \ b_1 \neq b_2$$

**기울기가 같고 $y$절편이 다르면 평행!**

#### 🔹 일치

두 직선이 **완전히 같음**

$$a_1 = a_2, \ b_1 = b_2$$

#### 🔹 한 점에서 만남 (교점)

기울기가 다를 때

$$a_1 \neq a_2$$

→ 만나는 점은 **연립방정식**으로 구함!

### 1-10. 일차함수의 활용

#### 🔹 변화하는 양 관계 식으로 표현

**예제)** 빈 통에 매분 3L씩 물이 채워지고 있다. 처음에 통에 물이 5L 있었다면, $x$분 후 통의 물의 양 $y$ L를 $x$의 식으로 나타내시오.

- 시작: 5L
- 1분당 3L 증가
- $y = 3x + 5$

**예제 2)** 길이가 30cm인 양초에 불을 붙이면 매시간 2cm씩 짧아진다. $x$시간 후 양초의 길이 $y$cm는?

- $y = 30 - 2x = -2x + 30$
- (5시간 후: $y = -10 + 30 = 20$cm)

#### 🔹 그래프로 해석

문제를 풀 때:
1. 변수 $x, y$ 정하기
2. **변화율(기울기)**과 **초깃값($y$절편)** 찾기
3. $y = ax + b$로 표현
4. 필요한 값 계산

## 2. 일차함수와 일차방정식의 관계

### 2-1. 일차방정식 $ax + by + c = 0$의 그래프

#### 🔹 핵심 발견!

미지수가 2개인 일차방정식

$$ax + by + c = 0 \quad (a, b \neq 0)$$

을 $y$에 관해 정리하면:

$$y = -\dfrac{a}{b}x - \dfrac{c}{b}$$

→ **일차함수와 똑같은 모양!**

즉, **일차방정식의 그래프 = 일차함수의 그래프 = 직선**

#### 🔹 예시

$2x + 3y - 6 = 0$을 그래프로?
- $y$에 관해 정리: $3y = -2x + 6 \to y = -\dfrac{2}{3}x + 2$
- 기울기 $-\dfrac{2}{3}$, $y$절편 $2$인 직선

### 2-2. 좌표축에 평행한 직선

#### 🔹 $x$축에 평행한 직선 ($y = k$ 꼴)

- $y = k$ (상수)
- 모든 점의 $y$좌표가 $k$
- $x$축에 평행한 수평선
- 기울기 $= 0$
- (엄밀히 말하면 일차함수는 아니지만 그래프로 다룸)

**예)** $y = 3$, $y = -2$

#### 🔹 $y$축에 평행한 직선 ($x = k$ 꼴)

- $x = k$ (상수)
- 모든 점의 $x$좌표가 $k$
- $y$축에 평행한 수직선
- 기울기 정의 불가 (분모 = 0)
- (함수가 ❌ → 한 $x$에 $y$가 무수히 많음)

**예)** $x = 4$, $x = -1$

#### 🔹 한 점에서 출발해 식 만들기

**예)** 점 $(3, 5)$를 지나고 $x$축에 평행한 직선 → $y = 5$
점 $(3, 5)$를 지나고 $y$축에 평행한 직선 → $x = 3$

### 2-3. 연립방정식의 해와 그래프 ⭐⭐⭐

#### 🔹 매우 중요한 관계

$$\boxed{\begin{cases} a_1 x + b_1 y = c_1 \\ a_2 x + b_2 y = c_2 \end{cases} \text{의 해} = \text{두 직선의 교점의 좌표}}$$

즉, 연립방정식을 푸는 것은 **두 직선이 만나는 점**을 찾는 것!

#### 🔹 예시

$\begin{cases} x + y = 5 \\ 2x - y = 1 \end{cases}$의 해 = $(2, 3)$

→ 직선 $y = -x + 5$와 직선 $y = 2x - 1$이 점 $(2, 3)$에서 만남!

#### 🔹 해의 개수와 그래프 위치 관계 ⭐

| 그래프 위치 | 연립방정식의 해 | 조건 |
|------------|-----------------|------|
| 한 점에서 만남 (교점 1개) | **해가 1개** | 기울기 다름 ($a_1 \neq a_2$) |
| 평행 (만나지 않음) | **해 없음** | 기울기 같고 $y$절편 다름 |
| 일치 (완전히 같음) | **해 무수히 많음** | 기울기, $y$절편 모두 같음 |

#### 🔹 비율로 판별

두 방정식: $a_1 x + b_1 y = c_1$, $a_2 x + b_2 y = c_2$

| 조건 | 위치 관계 | 해 |
|------|----------|-----|
| $\dfrac{a_1}{a_2} \neq \dfrac{b_1}{b_2}$ | 한 점에서 만남 | 1개 |
| $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} \neq \dfrac{c_1}{c_2}$ | 평행 | 없음 |
| $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} = \dfrac{c_1}{c_2}$ | 일치 | 무수히 많음 |

## 🎯 시험 자주 나오는 유형 BEST 7

### ✅ 1. 함숫값 구하기
$f(x) = -2x + 3$일 때 $f(-1) + f(2)$의 값?
→ $f(-1) = 5, f(2) = -1$ → 합 = $4$

### ✅ 2. 일차함수 식 구하기
"기울기가 $-2$이고 점 $(3, 1)$을 지나는 일차함수의 식은?"
→ $y = -2x + b$에 $(3, 1)$ 대입 → $1 = -6 + b \to b = 7$ → **$y = -2x + 7$**

### ✅ 3. 평행 조건 (기울기 비교)
"$y = (2a - 1)x + 3$과 $y = -3x + 5$가 평행하려면 $a$는?"
→ $2a - 1 = -3 \to a = -1$

### ✅ 4. 그래프와 사분면
"$y = ax + b$의 그래프가 제1, 2, 4사분면을 지날 때 $a, b$의 부호는?"
→ 1, 2, 4사분면이면 우하향 ($a < 0$)이고 $y$절편 양수 ($b > 0$) → **$a < 0, b > 0$**

### ✅ 5. 두 직선의 교점
"두 직선 $y = x + 1$과 $y = -x + 5$의 교점의 좌표는?"
→ 연립: $x + 1 = -x + 5 \to x = 2, y = 3$ → **$(2, 3)$**

### ✅ 6. 삼각형의 넓이
"직선 $y = -2x + 6$과 $x$축, $y$축으로 둘러싸인 도형의 넓이는?"
→ $x$절편 3, $y$절편 6 → 두 점 $(3, 0), (0, 6)$과 원점
→ 직각삼각형의 넓이 = $\dfrac{1}{2} \times 3 \times 6 = 9$

### ✅ 7. 연립방정식 해의 개수
"$\begin{cases} 2x + 3y = 6 \\ 4x + 6y = a \end{cases}$가 해를 가지지 않으려면 $a$의 조건은?"
→ 평행 조건: $\dfrac{2}{4} = \dfrac{3}{6} \neq \dfrac{6}{a}$ → $\dfrac{1}{2} \neq \dfrac{6}{a}$ → **$a \neq 12$**

## ⚠️ 자주 하는 실수 BEST 5

1. **기울기 분자, 분모 헷갈림**
   - 기울기 = **$\dfrac{y \text{ 증가량}}{x \text{ 증가량}}$**! 분자/분모 위치 절대 잊지 말기!

2. **$x$절편과 $y$절편 헷갈림**
   - $x$절편: $y = 0$일 때의 $x$ 값 → $x$축 위의 점
   - $y$절편: $x = 0$일 때의 $y$ 값 → $y$축 위의 점

3. **$y$축에 평행한 직선을 함수로 착각**
   - $x = 3$은 함수가 아님 (한 $x$에 무수한 $y$)

4. **평행이동 방향 헷갈림**
   - $y = ax + b$는 $y = ax$를 **$y$축 방향**으로 $b$만큼!
   - ($x$축 방향이 아님!)

5. **두 점으로 기울기 구할 때 부호 실수**
   - $(x_2 - x_1)$, $(y_2 - y_1)$ 순서를 맞춰서!
   - 분자, 분모 모두 같은 순서로!
