# Ⅰ. 실수와 그 연산

## 1. 제곱근과 실수

### 📌 핵심 개념 요약

**① 제곱근의 뜻**
어떤 수 $x$를 제곱하여 $a$가 될 때, 즉 $x^2 = a$일 때 $x$를 $a$의 **제곱근**이라고 한다.

**② 제곱근의 개수**
- 양수 $a$의 제곱근은 **2개** (양수, 음수 각 1개)
- 0의 제곱근은 **1개** (0 자신)
- 음수의 제곱근은 **없음** (실수 범위에서)

**③ 근호($\sqrt{\phantom{a}}$)와 표기**
양수 $a$의 두 제곱근은 $\sqrt{a}$ (양의 제곱근), $-\sqrt{a}$ (음의 제곱근)

**④ 제곱근의 성질**
- $(\sqrt{a})^2 = a$, $(-\sqrt{a})^2 = a$
- $\sqrt{a^2} = |a|$ → $a \geq 0$이면 $a$, $a < 0$이면 $-a$

**⑤ 무리수와 실수**
- **유리수**: 분수 $\dfrac{b}{a}$ 꼴로 나타낼 수 있는 수
- **무리수**: 유리수가 아닌 수 (순환하지 않는 무한소수)
- **실수** = 유리수 + 무리수

### 🔍 상세 설명

**제곱근이 뭔가요?**

"제곱하면 9가 되는 수가 뭐지?" 라고 물어보면 $3$과 $-3$이 떠오른다. 왜냐하면 $3^2 = 9$이고 $(-3)^2 = 9$이기 때문. 이때 $3$과 $-3$을 **9의 제곱근**이라고 부른다.

핵심은 **"제곱해서 그 수가 되는 모든 수"**라는 것! 그래서 양수는 항상 제곱근이 2개씩 짝을 이룬다.

**왜 음수의 제곱근은 없을까?**

어떤 실수든 제곱하면 0 또는 양수가 된다. $(+) \times (+) = (+)$이고 $(-) \times (-) = (+)$이니까. 따라서 제곱해서 $-4$가 되는 실수는 존재하지 않는다.

**$\sqrt{a^2}$의 값이 헷갈리는 이유**

$\sqrt{a^2} = a$라고 외우면 함정에 빠진다. 예를 들어 $a = -3$이라면?
- $\sqrt{(-3)^2} = \sqrt{9} = 3$
- 그런데 $a = -3$이니까 $\sqrt{a^2} = a$라고 하면 $-3$이 되어버림 ❌

그래서 정확하게는 $\sqrt{a^2} = |a|$이다.

> 💡 **시험 단골 함정**: $\sqrt{(a-b)^2}$ 같은 문제에서 $a-b$가 양수인지 음수인지 따져서 부호를 결정해야 한다!

**제곱근의 대소 관계**

$a > 0$, $b > 0$일 때:
- $a < b$이면 $\sqrt{a} < \sqrt{b}$
- $\sqrt{a} < \sqrt{b}$이면 $a < b$

**무리수란?**

$\sqrt{2}$는 분수로 나타낼 수 없는 수. 계산기로 두드려보면 $1.41421356\cdots$ 처럼 끝도 없이 이어지면서 순환하지도 않는다.

대표적인 무리수: $\sqrt{2},\ \sqrt{3},\ \sqrt{5},\ \pi$ 등

> ⚠️ 주의: $\sqrt{4}$는 무리수가 아니다! $\sqrt{4} = 2$니까 유리수.

## 2. 근호를 포함한 식의 계산

### 📌 핵심 개념 요약

**① 제곱근의 곱셈과 나눗셈** ($a > 0$, $b > 0$)
- $\sqrt{a} \times \sqrt{b} = \sqrt{ab}$
- $\dfrac{\sqrt{a}}{\sqrt{b}} = \sqrt{\dfrac{a}{b}}$
- $m\sqrt{a} \times n\sqrt{b} = mn\sqrt{ab}$

**② 근호 안과 밖으로 수 이동**
- $\sqrt{a^2 b} = a\sqrt{b}$ ($a > 0$)
- $a\sqrt{b} = \sqrt{a^2 b}$

**③ 분모의 유리화**
- $\dfrac{1}{\sqrt{a}} = \dfrac{\sqrt{a}}{a}$
- $\dfrac{b}{\sqrt{a}} = \dfrac{b\sqrt{a}}{a}$

**④ 제곱근의 덧셈과 뺄셈**
근호 안의 수가 **같은 것끼리만** 계산 가능!
- $m\sqrt{a} + n\sqrt{a} = (m+n)\sqrt{a}$
- $m\sqrt{a} - n\sqrt{a} = (m-n)\sqrt{a}$

**⑤ 분배법칙 활용**
- $\sqrt{a}(\sqrt{b} + \sqrt{c}) = \sqrt{ab} + \sqrt{ac}$

### 🔍 상세 설명

**근호 밖으로 빼는 기술**

$\sqrt{12}$를 봤을 때 그냥 두면 안 된다. **소인수분해**로 제곱인 수를 찾아 밖으로 빼야 한다.

$$\sqrt{12} = \sqrt{4 \times 3} = \sqrt{4} \times \sqrt{3} = 2\sqrt{3}$$

**분모의 유리화, 왜 하나?**

$\dfrac{1}{\sqrt{2}}$ 이 상태로는 분모가 무리수라서 값을 가늠하기 어렵다. 분모, 분자에 똑같이 $\sqrt{2}$를 곱하면:

$$\dfrac{1}{\sqrt{2}} = \dfrac{1 \times \sqrt{2}}{\sqrt{2} \times \sqrt{2}} = \dfrac{\sqrt{2}}{2}$$

**덧셈과 뺄셈은 동류항처럼!**

$\sqrt{2} + \sqrt{3}$을 $\sqrt{5}$로 쓰면 ❌ 절대 안 됨!

근호 안의 수가 다르면 더해지지 않는다. 반면 근호 안이 같으면:

$$3\sqrt{2} + 5\sqrt{2} = (3+5)\sqrt{2} = 8\sqrt{2}$$

**복잡한 계산 순서**

$\sqrt{8} + \sqrt{18}$ 같은 문제:

$$\sqrt{8} + \sqrt{18} = 2\sqrt{2} + 3\sqrt{2} = 5\sqrt{2}$$

**순서가 핵심:**
1. 모든 근호를 간단히 정리 (밖으로 뺄 거 빼기)
2. 분모가 무리수면 유리화하기
3. 같은 근호끼리 동류항 묶듯 정리

### 🎯 자주 나오는 함정 정리

| 잘못된 계산 ❌ | 올바른 계산 ✅ |
|---|---|
| $\sqrt{2} + \sqrt{3} = \sqrt{5}$ | $\sqrt{2} + \sqrt{3}$ (그대로) |
| $\sqrt{4 + 9} = 2 + 3$ | $\sqrt{4+9} = \sqrt{13}$ |
| $\sqrt{a^2} = a$ | $\sqrt{a^2} = \|a\|$ |
| $\sqrt{(-3)^2} = -3$ | $\sqrt{(-3)^2} = 3$ |

# Ⅱ. 식의 계산과 이차방정식

## 3. 다항식의 곱셈

### 📌 핵심 개념 요약

**① 다항식의 곱셈 기본**

$$(a+b)(c+d) = ac + ad + bc + bd$$

**② 곱셈 공식 (반드시 암기!)**

$$\boxed{(a+b)^2 = a^2 + 2ab + b^2}$$

$$\boxed{(a-b)^2 = a^2 - 2ab + b^2}$$

$$\boxed{(a+b)(a-b) = a^2 - b^2}$$

$$\boxed{(x+a)(x+b) = x^2 + (a+b)x + ab}$$

$$\boxed{(ax+b)(cx+d) = acx^2 + (ad+bc)x + bd}$$

**③ 곱셈 공식의 변형**
- $a^2 + b^2 = (a+b)^2 - 2ab = (a-b)^2 + 2ab$
- $(a+b)^2 = (a-b)^2 + 4ab$
- $(a-b)^2 = (a+b)^2 - 4ab$

### 🔍 상세 설명

**완전제곱식의 비밀**

$(a+b)^2$을 그냥 $a^2 + b^2$이라고 쓰면? ❌ 큰일 난다!

$$(a+b)^2 = (a+b)(a+b) = a^2 + ab + ba + b^2 = a^2 + 2ab + b^2$$

**중간의 $2ab$를 절대 빠뜨리지 말 것!** 시험에서 가장 흔한 실수 1위.

**합차 공식 활용**

$$(a+b)(a-b) = a^2 - b^2$$

활용 예시: $103 \times 97 = (100+3)(100-3) = 10000 - 9 = 9991$

이런 식으로 **암산 신공**도 가능!

**$(x+a)(x+b)$ 공식의 패턴**

$$(x+a)(x+b) = x^2 + (a+b)x + ab$$

- $x^2$의 계수: 그대로 1
- $x$의 계수: $a$와 $b$를 **더한 값**
- 상수항: $a$와 $b$를 **곱한 값**

예시: $(x+3)(x+5) = x^2 + 8x + 15$ ($3+5=8$, $3 \times 5=15$)

**공식의 변형 활용**

$a + b = 5$, $ab = 6$일 때 $a^2 + b^2$의 값은?

$$a^2 + b^2 = (a+b)^2 - 2ab = 5^2 - 2 \times 6 = 25 - 12 = 13$$

**두 수의 합과 곱만 알아도 제곱의 합, 차이 등을 다 구할 수 있다!**

## 4. 인수분해

### 📌 핵심 개념 요약

**① 인수분해란?**
하나의 다항식을 **두 개 이상의 다항식의 곱**으로 나타내는 것. 곱셈 공식의 정반대 작업.

$$\text{곱셈: } (x+2)(x+3) \xrightarrow{\text{전개}} x^2 + 5x + 6$$

$$\text{인수분해: } x^2 + 5x + 6 \xrightarrow{\text{인수분해}} (x+2)(x+3)$$

**② 인수분해 공식 (곱셈 공식의 역방향)**

$$\boxed{a^2 + 2ab + b^2 = (a+b)^2}$$

$$\boxed{a^2 - 2ab + b^2 = (a-b)^2}$$

$$\boxed{a^2 - b^2 = (a+b)(a-b)}$$

$$\boxed{x^2 + (a+b)x + ab = (x+a)(x+b)}$$

$$\boxed{acx^2 + (ad+bc)x + bd = (ax+b)(cx+d)}$$

**③ 인수분해 순서**
1. **공통인수**부터 묶어내기 → $ma + mb = m(a+b)$
2. 공식 적용 가능한지 확인
3. 안 되면 **항의 그룹화** 시도

### 🔍 상세 설명

**Step 1: 공통인수 묶기 (가장 먼저!)**

$3x^2 + 6x = 3x(x + 2)$

모든 항에 공통으로 들어있는 $3x$를 밖으로 빼는 것. 어떤 문제든 일단 공통인수가 있는지부터 확인!

**완전제곱식 알아보기**

$x^2 + 6x + 9$ → $(x+3)^2$

확인 방법:
- 양 끝 항이 어떤 수의 제곱인가? ($x^2 = x \cdot x$, $9 = 3^2$) ✅
- 중간 항이 양 끝 제곱근의 2배 곱인가? ($2 \times x \times 3 = 6x$) ✅

**제곱의 차: $a^2 - b^2$ 패턴**

$$x^2 - 25 = (x+5)(x-5)$$
$$4x^2 - 9 = (2x+3)(2x-3)$$
$$x^4 - 1 = (x^2+1)(x^2-1) = (x^2+1)(x+1)(x-1)$$

**한 번 더 인수분해 가능한지 끝까지 확인!**

**$x^2 + (a+b)x + ab$ 패턴: 합과 곱 찾기**

$x^2 + 7x + 12$를 인수분해하려면?

**곱이 12, 합이 7인 두 수**를 찾는다.
- $12 = 1 \times 12$ → 합 13 ❌
- $12 = 2 \times 6$ → 합 8 ❌
- $12 = 3 \times 4$ → 합 7 ✅

따라서 $x^2 + 7x + 12 = (x+3)(x+4)$

**부호별 정리:**
- $x^2 - 7x + 12$ → 둘 다 음수 → $(x-3)(x-4)$
- $x^2 + x - 12$ → 부호 다름 → $(x+4)(x-3)$
- $x^2 - x - 12$ → $(x-4)(x+3)$

**십자 곱셈법**

$2x^2 + 7x + 3$ 인수분해:

```
   2x       1     →  1x
     \    /
       X
     /    \
   1x       3     →  6x
                    ────
                     7x  ✅
```

→ $2x^2 + 7x + 3 = (2x+1)(x+3)$

**항이 4개 이상일 때: 그룹화**

$$x^3 + x^2 + x + 1 = x^2(x+1) + 1(x+1) = (x+1)(x^2+1)$$

### 🎯 인수분해 전략 흐름도

```
다항식 받음
   ↓
① 공통인수 있나? → 있으면 묶기
   ↓
② 항의 개수 확인
   ↓
2개항: a² - b² 형태인지? → 합차 공식
3개항: 완전제곱식? or (x+a)(x+b)? or 십자곱셈?
4개항: 두 개씩 묶어 그룹화
   ↓
③ 더 인수분해 안 되나? 끝까지 확인!
```

## 5. 이차방정식

### 📌 핵심 개념 요약

**① 이차방정식의 정의**
$$ax^2 + bx + c = 0 \quad (a \neq 0)$$

**② 이차방정식의 풀이 방법 (4가지)**

**(1) 인수분해 이용**
$(x-p)(x-q) = 0$이면 $x = p$ 또는 $x = q$

**(2) 제곱근 이용**
- $x^2 = k$ ($k \geq 0$) → $x = \pm\sqrt{k}$
- $(x-p)^2 = k$ → $x = p \pm \sqrt{k}$

**(3) 완전제곱식으로 고치기**
$ax^2 + bx + c = 0$ → $(x-p)^2 = q$ 꼴로 변형

**(4) 근의 공식 (꼭 외우기!)**
$$\boxed{x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}}$$

**③ 판별식 $D = b^2 - 4ac$**
- $D > 0$ → 서로 다른 두 실근
- $D = 0$ → 중근 (한 개의 근)
- $D < 0$ → 실근 없음

### 🔍 상세 설명

**방법 1: 인수분해로 풀기 (가장 빠른 길!)**

$x^2 - 5x + 6 = 0$

좌변을 인수분해하면 $(x-2)(x-3) = 0$

핵심 원리: **두 수의 곱이 0이면, 둘 중 하나는 반드시 0**

따라서 $x = 2$ 또는 $x = 3$

**방법 2: 제곱근 이용**

$(x-2)^2 = 7$
$$x - 2 = \pm\sqrt{7}$$
$$x = 2 \pm \sqrt{7}$$

**$\pm$ 표시를 절대 빠뜨리지 말 것!**

**방법 3: 완전제곱식으로 변형**

$x^2 + 6x + 2 = 0$

1. 상수항을 우변으로: $x^2 + 6x = -2$
2. 일차항 계수의 절반을 제곱한 값 더하기: $x^2 + 6x + 9 = 7$
3. 좌변을 완전제곱식으로: $(x+3)^2 = 7$
4. 제곱근 이용: $x = -3 \pm \sqrt{7}$

**방법 4: 근의 공식 (만능 열쇠 🔑)**

$$x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

예시: $2x^2 + 3x - 1 = 0$ ($a=2$, $b=3$, $c=-1$)

$$x = \dfrac{-3 \pm \sqrt{9 - 4 \times 2 \times (-1)}}{2 \times 2} = \dfrac{-3 \pm \sqrt{17}}{4}$$

**❗ 주의사항**:
- 분모 $2a$의 $2$를 빠뜨리지 말기
- $-b$의 마이너스 부호 주의
- $b^2 - 4ac$에서 $c$의 부호 잘 확인

**판별식 $D$로 근의 개수 파악**

| $D$의 값 | 근의 상태 | 예시 |
|---|---|---|
| $D > 0$ | 서로 다른 두 실근 | $x^2 - 5x + 6 = 0$ ($D = 1$) |
| $D = 0$ | 중근 (한 개) | $x^2 - 4x + 4 = 0$ ($D = 0$) |
| $D < 0$ | 실근 없음 | $x^2 + x + 1 = 0$ ($D = -3$) |

**이차방정식의 활용**

**예시**: 가로가 세로보다 3 큰 직사각형의 넓이가 28일 때, 가로의 길이는?

세로를 $x$라 하면 가로는 $x+3$, 넓이 $x(x+3) = 28$
$$x^2 + 3x - 28 = 0$$
$$(x+7)(x-4) = 0$$
$$x = -7 \text{ 또는 } x = 4$$

세로는 양수여야 하므로 $x = 4$, 가로는 $7$.

> ⚠️ **함정**: 길이, 개수, 시간은 항상 **양수**! 음수 해는 버려야 함.

### 🎯 이차방정식 풀이 순서

```
이차방정식을 봤다!
   ↓
① 모든 항을 좌변으로 → ax² + bx + c = 0 꼴
   ↓
② 인수분해 가능한가?
    Yes → 인수분해로 풀기 (빠름!)
    No  → ③으로
   ↓
③ x² = k 또는 (x-p)² = k 꼴인가?
    Yes → 제곱근 이용
    No  → ④로
   ↓
④ 근의 공식 적용
```

# Ⅲ. 이차함수

## 6. 이차함수와 그 그래프

### 📌 핵심 개념 요약

**① 이차함수의 정의**
$$y = ax^2 + bx + c \quad (a \neq 0)$$

**② 이차함수의 그래프 = 포물선**
- 축에 대칭인 곡선
- **꼭짓점**: 포물선의 가장 뾰족한 점 (최댓값 또는 최솟값)
- **축**: 꼭짓점을 지나는 대칭축

**③ 그래프의 4가지 표준형**

| 형태 | 꼭짓점 | 축 |
|---|---|---|
| $y = ax^2$ | $(0, 0)$ | $x = 0$ (y축) |
| $y = ax^2 + q$ | $(0, q)$ | $x = 0$ |
| $y = a(x-p)^2$ | $(p, 0)$ | $x = p$ |
| $y = a(x-p)^2 + q$ | $(p, q)$ | $x = p$ |

**④ $a$의 부호와 그래프 모양**
- $a > 0$: **아래로 볼록** (∪ 모양) → 꼭짓점에서 **최솟값**
- $a < 0$: **위로 볼록** (∩ 모양) → 꼭짓점에서 **최댓값**
- $|a|$가 클수록 폭이 **좁음**

**⑤ 일반형 → 표준형 변환**

꼭짓점 공식:
$$p = -\dfrac{b}{2a}, \quad q = -\dfrac{b^2 - 4ac}{4a}$$

### 🔍 상세 설명

### 🎯 단계별 그래프 마스터하기

**1단계: $y = ax^2$ (가장 기본형)**

원점 $(0, 0)$을 꼭짓점으로 하는 포물선.

- $y = x^2$: 기본 포물선
- $y = 2x^2$: 폭이 좁아짐
- $y = \dfrac{1}{2}x^2$: 폭이 넓어짐
- $y = -x^2$: 위아래 뒤집힘 (∩ 모양)

> 💡 **$a$의 역할 정리**:
> - 부호 → 볼록 방향 결정
> - 절댓값 크기 → 폭 결정

**2단계: $y = ax^2 + q$ (위아래 평행이동)**

$y = ax^2$ 그래프를 **y축 방향으로 $q$만큼** 평행이동.

- $y = x^2 + 3$: 위로 3만큼 이동 → 꼭짓점 $(0, 3)$
- $y = x^2 - 2$: 아래로 2만큼 이동 → 꼭짓점 $(0, -2)$

**3단계: $y = a(x-p)^2$ (좌우 평행이동)**

- $y = (x-3)^2$: 오른쪽으로 3만큼 → 꼭짓점 $(3, 0)$
- $y = (x+2)^2$: 왼쪽으로 2만큼 → 꼭짓점 $(-2, 0)$

> ⚠️ **함정 주의!** 괄호 안의 부호와 이동 방향이 **반대**! $(x-3)^2$은 오른쪽으로 3 이동!

**4단계: $y = a(x-p)^2 + q$ (표준형, 완전체)**

**꼭짓점: $(p, q)$, 축: $x = p$**

예시: $y = 2(x-1)^2 + 3$
- 꼭짓점: $(1, 3)$
- 축: $x = 1$
- 아래로 볼록 ($a = 2 > 0$)
- 최솟값: $3$

### 🔧 일반형 → 표준형 변환

**예시**: $y = x^2 - 6x + 11$을 표준형으로

$$y = x^2 - 6x + 11$$
$$= (x^2 - 6x + 9) - 9 + 11$$
$$= (x-3)^2 + 2$$

→ 꼭짓점 $(3, 2)$, 축 $x = 3$, 최솟값 $2$

**$a \neq 1$인 경우**: $y = 2x^2 + 8x + 5$

1. 이차항과 일차항을 $a$로 묶기:
$$y = 2(x^2 + 4x) + 5$$

2. 괄호 안에서 완전제곱식 만들기:
$$y = 2(x^2 + 4x + 4 - 4) + 5$$
$$= 2(x+2)^2 - 8 + 5$$
$$= 2(x+2)^2 - 3$$

→ 꼭짓점 $(-2, -3)$, 최솟값 $-3$

### 🎯 그래프와 축의 교점

**y축과의 교점**: $x = 0$ 대입 → $(0, c)$
일반형의 y절편은 그냥 **상수항 $c$**!

**x축과의 교점**: $y = 0$ 대입 → 이차방정식 $ax^2 + bx + c = 0$의 해

즉, **이차방정식의 근 = 이차함수 그래프와 x축의 교점의 x좌표**

**판별식 $D$로 x축 교점 개수 판단**

| $D = b^2 - 4ac$ | x축과의 교점 | 그래프 위치 |
|---|---|---|
| $D > 0$ | 2개 (서로 다른 두 점) | 그래프가 x축을 가로지름 |
| $D = 0$ | 1개 (접함) | 그래프가 x축에 살짝 닿음 |
| $D < 0$ | 없음 | 그래프가 x축에서 완전히 떨어짐 |

### 📊 이차함수의 최댓값과 최솟값

**전제: $x$가 실수 전체 범위($-\infty < x < \infty$)에서 움직일 때**

$y = a(x-p)^2 + q$에서:

- $a > 0$ (아래로 볼록): $x = p$일 때 **최솟값 $q$**, 최댓값 없음 (위로 무한히 커짐)
- $a < 0$ (위로 볼록): $x = p$일 때 **최댓값 $q$**, 최솟값 없음 (아래로 무한히 작아짐)

> 🔮 **한 걸음 더 (고등 과정 예고편)**
> 
> "최댓값 없음 / 최솟값 없음"이라는 결론은 **$x$의 범위가 실수 전체일 때만** 성립해요. 고등학교에서는 $x$의 범위를 제한하는 **'정의역이 제한된 이차함수'**를 배우게 되는데, 이때는 상황이 달라져요!
> 
> 예를 들어 $y = x^2$에서 $x$가 실수 전체라면 최댓값은 없지만, **$0 \leq x \leq 2$로 제한**되면:
> - 꼭짓점 $x = 0$에서 최솟값 $0$
> - 경계 $x = 2$에서 **최댓값 $4$**
> 
> 즉, 정의역이 제한되면 **꼭짓점뿐만 아니라 경계값(양 끝점)도 후보**가 되어 최댓값과 최솟값 모두 존재할 수 있어요. 중3에서는 "범위 제한 없음" → "꼭짓점이 곧 답"이라고 외워두되, 이 전제를 잊지 말기!

**활용 예시**: 가로 + 세로 = 10인 직사각형 중 넓이가 최대인 것은?

가로를 $x$라 하면:
$$\text{넓이} = x(10-x) = -x^2 + 10x = -(x-5)^2 + 25$$

→ $x = 5$일 때 최댓값 25. 즉 정사각형(5×5)일 때 넓이 최대!

> 💡 사실 이 문제도 **$0 < x < 10$**이라는 숨은 정의역 제한이 있어요(가로 길이는 양수여야 하니까). 위로 볼록 포물선이고 꼭짓점 $x=5$가 이 범위 안에 들어가서 최댓값이 자연스럽게 꼭짓점에서 결정된 것!

### 🎨 그래프 그리기 체크리스트

1. **볼록 방향** ($a$의 부호로)
2. **꼭짓점** (표준형으로 변환)
3. **축의 방정식** ($x = p$)
4. **y축과의 교점** ($x = 0$ 대입)
5. **x축과의 교점** (이차방정식의 해)

### 🎯 자주 나오는 함정과 실수

| 헷갈리는 부분 ❌ | 올바른 이해 ✅ |
|---|---|
| $y=(x-3)^2$ → 왼쪽으로 3 이동 | 오른쪽으로 3 이동 (부호 반대!) |
| 모든 이차함수는 최댓값과 최솟값을 둘 다 가진다 | **정의역이 실수 전체**일 때는 $a$의 부호에 따라 하나만 존재 (정의역이 제한되면 다를 수 있음 → 고등 과정) |
| 이차함수와 이차방정식은 다른 것 | $y=0$일 때가 곧 이차방정식의 해 |
| $y$절편을 따로 계산 | 일반형의 상수항 $c$가 곧 y절편 |

### 📐 이차함수 식 구하기 (역방향 문제)

**유형 1: 꼭짓점이 주어진 경우**
꼭짓점 $(p, q)$ → $y = a(x-p)^2 + q$로 놓고 다른 점 대입

**유형 2: x축과의 두 교점이 주어진 경우**
교점이 $(\alpha, 0)$, $(\beta, 0)$ → $y = a(x-\alpha)(x-\beta)$

**유형 3: 세 점이 주어진 경우**
$y = ax^2 + bx + c$로 놓고 연립방정식

## 이차식 3종 세트의 연결

이 학기 전체 내용이 어떻게 하나로 이어지는지!

```
[다항식의 곱셈]        [인수분해]
(x+2)(x+3)    ⇌    x² + 5x + 6
       ↓                    ↓
       ↓     [이차방정식]   ↓
       ↓     x² + 5x + 6 = 0
       ↓        해: x = -2, -3
       ↓             ↓
[이차함수의 그래프]
y = x² + 5x + 6
   x축 교점: (-2, 0), (-3, 0)
   꼭짓점: (-5/2, -1/4)
```

**같은 식, 다른 표현!**
- 곱셈공식과 인수분해로 식을 자유자재로 변환
- 그걸로 방정식을 풀고
- 결과를 그래프로 시각화

모든 게 연결되어 있다!
