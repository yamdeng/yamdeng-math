## 1-1. 미분방정식 개론

### ✅ 핵심 개념 요약

미분방정식(ODE/PDE)은 **"어떤 함수와 그 도함수 사이의 관계식"** 입니다.
자연/공학의 거의 모든 변화 현상을 수식으로 표현하는 언어.

```
일반 방정식 : x² + 3x = 5       → 미지수가 "숫자"
미분방정식  : y'' + 3y' = 5x    → 미지수가 "함수"
```

### 📌 분류 체계

```
미분방정식
├── ODE (상미분방정식) — 독립변수 1개
│   ├── 계(Order)   : 가장 높은 도함수의 차수
│   │                  y'  → 1계  |  y'' → 2계
│   ├── 차수(Degree): 최고계 도함수의 지수
│   └── 선형 / 비선형
│       선형  : y와 y', y''... 가 1차식으로만 등장
│       비선형: (y')² , y·y'' 같은 항이 있으면 비선형
│
└── PDE (편미분방정식) — 독립변수 2개 이상
    예) 열방정식, 파동방정식
```

### 📌 선형 ODE 표준형

$$a_n(x)y^{(n)} + a_{n-1}(x)y^{(n-1)} + \cdots + a_1(x)y' + a_0(x)y = f(x)$$

- $f(x) = 0$ → **동차(Homogeneous)**
- $f(x) \neq 0$ → **비동차(Non-homogeneous)**

### 📌 해(Solution)의 종류

| 종류 | 설명 |
|------|------|
| **일반해** | 임의 상수 C를 포함한 해 (전체 해의 패밀리) |
| **특수해** | 초기조건으로 C를 결정한 해 |
| **특이해** | 일반해에서 얻을 수 없는 해 (비선형에서 등장) |

### 💡 직관적 이해

> 미분방정식 = 규칙, 해 = 그 규칙을 따르는 실제 함수
>
> "지금 속도가 현재 위치에 비례한다" → $y' = ky$ → 해: $y = Ce^{kx}$
>
> (코로나 초기 확산, 인구 성장 모두 이 형태!)

## 1-2. 1계 미분방정식

### ✅ 핵심 개념 요약

$y' = f(x, y)$ 형태. 풀이법을 **상황에 따라 선택**하는 것이 핵심!

### 📌 풀이법 총정리

#### ① 변수분리법 (Separable Equations)

$$\frac{dy}{dx} = g(x) \cdot h(y) \quad \Rightarrow \quad \frac{dy}{h(y)} = g(x)\,dx$$

양변을 각각 적분하면 끝!

**예시:**

$$y' = xy \quad \Rightarrow \quad \frac{dy}{y} = x\,dx \quad \Rightarrow \quad \ln|y| = \frac{x^2}{2} + C$$

$$\therefore\; y = Ae^{x^2/2}$$

---

#### ② 완전미분방정식 (Exact Equations)

$$M(x,y)\,dx + N(x,y)\,dy = 0$$

**완전 조건:** $\dfrac{\partial M}{\partial y} = \dfrac{\partial N}{\partial x}$

조건이 성립하면 퍼텐셜 함수 $F(x,y)$를 찾아서 $F = C$ 가 해!

---

#### ③ 적분인수법 (Integrating Factor)

완전 조건이 안 맞을 때, 적분인수 $\mu$를 곱해서 완전방정식으로 변환.

**선형 1계 표준형:**

$$y' + P(x)y = Q(x)$$

$$\boxed{y = \frac{1}{\mu}\left(\int \mu Q\,dx + C\right), \quad \mu = e^{\int P\,dx}}$$

---

#### ④ 베르누이 방정식 (Bernoulli Equation)

$$y' + P(x)y = Q(x)y^n \quad (n \neq 0, 1)$$

치환: $v = y^{1-n}$ → 선형방정식으로 변환!

---

#### ⑤ 동차방정식 (Homogeneous Type)

$$y' = f\!\left(\frac{y}{x}\right)$$

치환: $v = \dfrac{y}{x}$, 즉 $y = vx$ → 변수분리 가능 형태로 변환

---

### 📌 풀이법 선택 순서도

```
y' = f(x,y) 주어짐
       │
       ▼
  변수분리 가능? ──Yes──▶ 변수분리법
       │No
       ▼
  y/x 꼴?  ────────Yes──▶ 동차방정식 (v=y/x 치환)
       │No
       ▼
  선형? y'+P(x)y=Q(x) ──Yes──▶ 적분인수법
       │No
       ▼
  베르누이? y'+Py=Qy^n ──Yes──▶ v=y^(1-n) 치환
       │No
       ▼
  완전방정식 검토 (My=Nx?)
```

---

### 💡 응용 예시

| 현상 | 방정식 | 풀이법 |
|------|--------|--------|
| 방사성 붕괴 | $N' = -\lambda N$ | 변수분리 |
| RC 회로 충전 | $I' + \frac{1}{RC}I = 0$ | 적분인수 |
| 인구 모델(로지스틱) | $P' = rP(1-P/K)$ | 변수분리 |

## 1-3. 2계 미분방정식

### ✅ 핵심 개념 요약

$$a\,y'' + b\,y' + c\,y = f(x)$$

**스프링-질량 계, 전기 회로(RLC), 진동 해석**의 수학적 뼈대!

### 📌 풀이 구조

$$\boxed{y = y_h + y_p}$$

| 부분 | 이름 | 구하는 방법 |
|------|------|-------------|
| $y_h$ | 동차해 (여함수) | 특성방정식 풀기 |
| $y_p$ | 특수해 (특해) | 미정계수법 or 매개변수변환법 |

---

### 📌 Step 1: 동차해 $y_h$ — 특성방정식

$$ay'' + by' + cy = 0 \quad \Rightarrow \quad ar^2 + br + c = 0$$

판별식 $D = b^2 - 4ac$ 에 따라:

| 경우 | 특성근 | 동차해 $y_h$ |
|------|--------|--------------|
| $D > 0$ | 서로 다른 실근 $r_1, r_2$ | $C_1 e^{r_1 x} + C_2 e^{r_2 x}$ |
| $D = 0$ | 중근 $r$ | $(C_1 + C_2 x)e^{rx}$ |
| $D < 0$ | 복소근 $\alpha \pm \beta i$ | $e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$ |

---

### 📌 Step 2: 특수해 $y_p$ — 미정계수법

$f(x)$의 형태에 따라 $y_p$를 **추측**해서 대입!

| $f(x)$ 형태 | 추측하는 $y_p$ |
|-------------|----------------|
| $ke^{ax}$ | $Ae^{ax}$ |
| $k\sin(bx)$ 또는 $k\cos(bx)$ | $A\sin(bx) + B\cos(bx)$ |
| $k x^n$ (다항식) | $A_n x^n + \cdots + A_1 x + A_0$ |
| 위의 곱 | 각각을 곱한 형태 |

> ⚠️ $y_p$ 추측값이 $y_h$와 겹치면 → $x$를 곱해서 수정!

---

### 📌 물리적 의미 (진동계)

$$m\ddot{x} + c\dot{x} + kx = F(t)$$

| 항 | 의미 |
|----|------|
| $m\ddot{x}$ | 관성력 |
| $c\dot{x}$ | 감쇠력 (저항) |
| $kx$ | 복원력 (스프링) |
| $F(t)$ | 외력 |

**감쇠 비율에 따른 분류:**

```
c² - 4mk > 0 : 과감쇠   (진동 없이 천천히 복귀)
c² - 4mk = 0 : 임계감쇠 (가장 빠르게 복귀)
c² - 4mk < 0 : 부족감쇠 (진동하며 복귀) ← 가장 흔한 경우
c = 0        : 비감쇠   (영원히 진동)
```

## 1-4. 연립미분방정식

### ✅ 핵심 개념 요약

여러 변수가 **서로 영향**을 주고받는 시스템!

$$\begin{cases} x' = ax + by \\ y' = cx + dy \end{cases}$$

→ 행렬로 표현: $\mathbf{X'} = A\mathbf{X}$

### 📌 풀이법: 고유값(Eigenvalue) 방법

**Step 1.** 특성방정식: $\det(A - \lambda I) = 0$

**Step 2.** 고유값 $\lambda$ 에 대한 고유벡터 $\mathbf{v}$ 계산

**Step 3.** 해 조합:

$$\mathbf{X} = C_1 \mathbf{v}_1 e^{\lambda_1 t} + C_2 \mathbf{v}_2 e^{\lambda_2 t}$$

### 📌 고유값 종류별 해의 형태

| 고유값 | 해의 형태 |
|--------|-----------|
| 서로 다른 실수 | $C_1\mathbf{v}_1 e^{\lambda_1 t} + C_2\mathbf{v}_2 e^{\lambda_2 t}$ |
| 중복 실수 | $(C_1\mathbf{v} + C_2(\mathbf{v}t + \mathbf{w}))e^{\lambda t}$ |
| 복소수 $\alpha \pm \beta i$ | $e^{\alpha t}$ 와 $\cos/\sin$ 조합 |

### 💡 위상평면 & 안정성

고유값의 부호로 시스템의 **장기 거동** 판단:

```
모두 음수 → 안정   (원점으로 수렴)
모두 양수 → 불안정 (원점에서 발산)
부호 혼합 → 안장점 (saddle point)
순허수   → 중심   (주기 운동)
```

## 1-5. 변수계수를 갖는 미분방정식

### ✅ 핵심 개념 요약

계수가 **상수가 아닌 함수**인 경우:

$$y'' + P(x)y' + Q(x)y = R(x)$$

특성방정식이 없으므로 → **급수해** 또는 특별한 방정식 이용!

### 📌 오일러-코시 방정식 (Euler-Cauchy)

$$x^2 y'' + axy' + by = 0$$

치환: $x = e^t$ (또는 $y = x^m$ 대입)

$$m(m-1) + am + b = 0 \quad \leftarrow \text{특성방정식처럼 풀기}$$

---

### 📌 급수해법 (Power Series Method)

해를 멱급수로 가정:

$$y = \sum_{n=0}^{\infty} a_n x^n$$

미분방정식에 대입 → 점화식(recurrence relation) 도출 → 계수 $a_n$ 결정

---

### 📌 프로베니우스 방법 (Frobenius Method)

정규 특이점(regular singular point) 근방에서:

$$y = x^r \sum_{n=0}^{\infty} a_n x^n$$

**지표 방정식(indicial equation)**으로 $r$ 결정 후 급수 전개

---

### 📌 중요 특수함수

#### 베셀 방정식 (Bessel Equation)

$$x^2 y'' + xy' + (x^2 - \nu^2)y = 0$$

해: **베셀 함수** $J_\nu(x)$, $Y_\nu(x)$

> → 원통형 파동, 열전도, 전자기파 해석에 필수!

#### 르장드르 방정식 (Legendre Equation)

$$(1-x^2)y'' - 2xy' + n(n+1)y = 0$$

해: **르장드르 다항식** $P_n(x)$

> → 구면 좌표계 문제, 전위 해석에 필수!

# PART II. 라플라스변환과 푸리에 급수

## 2-1. 라플라스 변환 (Laplace Transform)

### ✅ 핵심 개념 요약

미분방정식을 **대수방정식**으로 바꿔서 푸는 강력한 도구!

$$\mathcal{L}\{f(t)\} = F(s) = \int_0^{\infty} e^{-st} f(t)\,dt$$

### 📌 핵심 변환 공식표

| $f(t)$ | $F(s) = \mathcal{L}\{f\}$ |
|--------|---------------------------|
| $1$ | $\dfrac{1}{s}$ |
| $t^n$ | $\dfrac{n!}{s^{n+1}}$ |
| $e^{at}$ | $\dfrac{1}{s-a}$ |
| $\sin(at)$ | $\dfrac{a}{s^2+a^2}$ |
| $\cos(at)$ | $\dfrac{s}{s^2+a^2}$ |
| $t\cdot f(t)$ | $-F'(s)$ |
| $f'(t)$ | $sF(s) - f(0)$ |
| $f''(t)$ | $s^2F(s) - sf(0) - f'(0)$ |

### 📌 풀이 흐름

```
[미분방정식]
     │  ℒ 변환 (초기조건 동시 처리!)
     ▼
[대수방정식] → F(s) 에 대해 풀기
     │  ℒ⁻¹ 역변환 (부분분수 분해 활용)
     ▼
[해 y(t)]
```

### 📌 중요 성질

| 성질 | 공식 |
|------|------|
| 선형성 | $\mathcal{L}\{af+bg\} = aF+bG$ |
| 이동 (s-이동) | $\mathcal{L}\{e^{at}f(t)\} = F(s-a)$ |
| 이동 (t-이동) | $\mathcal{L}\{u(t-a)f(t-a)\} = e^{-as}F(s)$ |
| 합성곱 | $\mathcal{L}\{f*g\} = F(s)\cdot G(s)$ |
| 델타함수 | $\mathcal{L}\{\delta(t-a)\} = e^{-as}$ |

---

## 2-2. 푸리에 급수 (Fourier Series)

### ✅ 핵심 개념 요약

**주기함수**를 sin, cos의 무한 합으로 분해!

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\left(a_n \cos\frac{n\pi x}{L} + b_n \sin\frac{n\pi x}{L}\right)$$

### 📌 계수 공식

$$a_0 = \frac{1}{L}\int_{-L}^{L} f(x)\,dx$$

$$a_n = \frac{1}{L}\int_{-L}^{L} f(x)\cos\frac{n\pi x}{L}\,dx$$

$$b_n = \frac{1}{L}\int_{-L}^{L} f(x)\sin\frac{n\pi x}{L}\,dx$$

### 📌 우함수 / 기함수 활용

| 함수 특성 | 결과 |
|-----------|------|
| 우함수 $f(-x)=f(x)$ | $b_n = 0$ → **코사인 급수만** |
| 기함수 $f(-x)=-f(x)$ | $a_n = 0$ → **사인 급수만** |

### 💡 웹 개발 연결고리

> 푸리에 변환은 음악 앱의 **이퀄라이저**, 이미지 압축(JPEG), 신호처리의 근간!
> 주파수 도메인 ↔ 시간 도메인 변환 = FFT 알고리즘

# 부록. 복소해석학 (Complex Analysis)

## 부록 1-1. 복소수와 복소평면

### ✅ 핵심 개념

$$z = x + iy, \quad i^2 = -1$$

| 표현 | 공식 |
|------|------|
| 직교형 | $z = x + iy$ |
| 극형식 | $z = r(\cos\theta + i\sin\theta) = re^{i\theta}$ |
| 켤레복소수 | $\bar{z} = x - iy$ |
| 절댓값 | $|z| = \sqrt{x^2 + y^2}$ |

**오일러 공식 (가장 아름다운 수식):**

$$\boxed{e^{i\theta} = \cos\theta + i\sin\theta}$$

$$e^{i\pi} + 1 = 0 \quad \leftarrow \text{오일러 항등식}$$

---

## 부록 1-2. 복소함수

### ✅ 코시-리만 방정식 (미분가능 조건)

$f(z) = u(x,y) + iv(x,y)$ 가 **해석적(analytic)**이려면:

$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$

이 조건을 만족 → **정칙함수(holomorphic)**

---

## 부록 1-3. 복소적분

### ✅ 코시 적분 공식

$$\oint_C f(z)\,dz = 0 \quad \text{(}f\text{가 }C\text{ 내부에서 해석적이면)}$$

$$\oint_C \frac{f(z)}{z - z_0}\,dz = 2\pi i\, f(z_0)$$

---

## 부록 1-4. 복소급수

### ✅ 로랑 급수 & 유수

$$f(z) = \sum_{n=-\infty}^{\infty} c_n (z-z_0)^n$$

- $n < 0$ 인 항들 = **주부(principal part)**
- $c_{-1}$ = **유수(Residue)**

**유수 정리:**

$$\oint_C f(z)\,dz = 2\pi i \sum \text{Res}[f, z_k]$$

## 부록 1-5. 실함수의 정적분

### ✅ 유수 정리로 실적분 계산!

$$\int_{-\infty}^{\infty} \frac{P(x)}{Q(x)}\,dx = 2\pi i \sum_{\text{상반평면}} \text{Res}$$

복잡한 실수 적분을 복소 경로 적분으로 우회해서 계산하는 강력한 기법!
