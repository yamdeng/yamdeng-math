## PART 1. 극 좌표계

### 핵심 한 줄
> 거리 r + 각도 θ 로 점을 표현, 넓이 공식 `A = ½∫r²dθ`

---

### 1-1. 극좌표계

점을 `(r, θ)` 로 표현한다.

- `r` : 원점(극)에서의 거리 (r ≥ 0)
- `θ` : 극축(양의 x축)에서 반시계 방향 각도

#### 좌표 변환 공식

```
극 → 직교:   x = r·cosθ,   y = r·sinθ
직교 → 극:   r = √(x²+y²),  tanθ = y/x
```

#### 주의사항

같은 점의 다중 표현:
```
(r, θ) = (r, θ + 2nπ) = (-r, θ + π)
```
표준 표현: `r ≥ 0`, `0 ≤ θ < 2π`

---

### 1-2. 극방정식

`r = f(θ)` 형태로 나타내는 곡선.

| 곡선 | 방정식 | 특징 |
|---|---|---|
| 원 | `r = a` | 원점 중심, 반지름 a |
| 카디오이드 | `r = a(1 ± cosθ)` | 하트 모양 |
| 장미 곡선 | `r = cos(nθ)` | n 홀수 → n개 꽃잎, n 짝수 → 2n개 꽃잎 |
| 아르키메데스 나선 | `r = aθ` | 일정 간격 나선 |
| 렘니스케이트 | `r² = a²cos(2θ)` | ∞ 모양 |

#### 넓이 공식 (시험 핵심!)

```
A = (1/2) ∫[α→β] r² dθ
```

두 극곡선 사이 넓이 (r₁ ≤ r₂):
```
A = (1/2) ∫[α→β] (r₂² - r₁²) dθ
```

#### 호의 길이

```
L = ∫[α→β] √(r² + (dr/dθ)²) dθ
```

#### 예제: 카디오이드 r = 1 + cosθ 전체 넓이

```
A = (1/2)∫₀²π (1+cosθ)² dθ
  = (1/2)∫₀²π (1 + 2cosθ + cos²θ) dθ
  = (1/2)(2π + π) = 3π/2
```

## PART 2. 급수와 함수의 전개

### 핵심 한 줄
> 수렴판정 → 멱급수(수렴반경) → 테일러·맥클로린 급수

---

### 2-1. 무한급수의 수렴/발산

무한급수: `Σaₙ = a₁ + a₂ + a₃ + ···`

부분합 `Sₙ`이 수렴하면 급수 수렴, 아니면 발산.

#### 판정법 총정리

| 판정법 | 조건 | 결론 | 사용 시점 |
|---|---|---|---|
| 기본 발산 | `lim aₙ ≠ 0` | 발산 | 가장 먼저 확인 |
| 기하급수 | `Σarⁿ` | `|r|<1` → 수렴, 합 = a/(1-r) | arⁿ 형태 |
| p-급수 | `Σ1/nᵖ` | `p>1` → 수렴, `p≤1` → 발산 | 비교 기준 |
| 비율 판정 | `L = lim|aₙ₊₁/aₙ|` | `L<1` 수렴, `L>1` 발산, `L=1` 불명확 | n!, aⁿ 포함 |
| 근 판정 | `L = lim ⁿ√|aₙ|` | `L<1` 수렴, `L>1` 발산, `L=1` 불명확 | aₙ 자체가 n제곱 |
| 비교 판정 | `0 < aₙ ≤ bₙ` | `Σbₙ` 수렴 → `Σaₙ` 수렴 | p-급수와 비교 |
| 적분 판정 | f 양·연속·감소 | `∫f dx` 수렴 ↔ `Σaₙ` 수렴 | f(n) = aₙ 설정 |

> **주의**: 비율·근 판정에서 L=1이면 판정 불가! 다른 방법 사용.

---

### 2-2. 교대급수와 절대수렴

교대급수: `Σ(-1)ⁿ⁺¹aₙ = a₁ - a₂ + a₃ - ···`

#### 라이프니츠 판정법

다음 두 조건 만족 시 수렴:
1. `aₙ ≥ aₙ₊₁` (단조감소)
2. `lim aₙ = 0`

#### 오차 추정

```
|S - Sₙ| ≤ aₙ₊₁
```

#### 절대수렴 vs 조건수렴

```
절대수렴: Σ|aₙ| 수렴  →  Σaₙ도 수렴 (역은 불성립!)
조건수렴: Σaₙ 수렴  but  Σ|aₙ| 발산
```

대표 예:
- `Σ(-1)ⁿ/n²` → 절대수렴 (∵ Σ1/n² 수렴)
- `Σ(-1)ⁿ/n` → 조건수렴 (∵ Σ1/n 발산)

---

### 2-3. 무한급수의 전개 (멱급수)

멱급수: `Σcₙ(x-a)ⁿ = c₀ + c₁(x-a) + c₂(x-a)² + ···`

#### 수렴반경 R

```
1/R = lim|cₙ₊₁/cₙ|   또는   1/R = lim ⁿ√|cₙ|
```

| R 값 | 수렴 범위 |
|---|---|
| R = 0 | x = a 에서만 수렴 |
| 0 < R < ∞ | (a-R, a+R) 내부에서 수렴 |
| R = ∞ | 모든 실수에서 수렴 |

> 끝점 x = a ± R 은 반드시 대입해서 별도 확인!

#### 멱급수 연산 (수렴구간 내)

```
미분: d/dx Σcₙxⁿ = Σ n·cₙxⁿ⁻¹
적분: ∫Σcₙxⁿ dx = Σ cₙ/(n+1) · xⁿ⁺¹ + C
```

---

### 2-4. 함수의 전개 (테일러·맥클로린)

#### 테일러 급수 (중심: x = a)

```
f(x) = Σ f⁽ⁿ⁾(a)/n! · (x-a)ⁿ
     = f(a) + f'(a)(x-a) + f''(a)/2!(x-a)² + ···
```

a = 0 일 때 → **맥클로린 급수**

#### 주요 맥클로린 급수 (필수 암기!)

| 함수 | 급수 전개 | 수렴구간 |
|---|---|---|
| `eˣ` | `1 + x + x²/2! + x³/3! + ···` | (-∞, ∞) |
| `sin x` | `x - x³/3! + x⁵/5! - ···` | (-∞, ∞) |
| `cos x` | `1 - x²/2! + x⁴/4! - ···` | (-∞, ∞) |
| `1/(1-x)` | `1 + x + x² + x³ + ···` | (-1, 1) |
| `ln(1+x)` | `x - x²/2 + x³/3 - ···` | (-1, 1] |
| `arctan x` | `x - x³/3 + x⁵/5 - ···` | [-1, 1] |
| `(1+x)ᵏ` | `1 + kx + k(k-1)x²/2! + ···` | (-1, 1) |

#### 테일러 나머지 (오차 추정)

```
|Rₙ(x)| ≤ M/(n+1)! · |x-a|ⁿ⁺¹
```
M = |f⁽ⁿ⁺¹⁾| 의 최댓값

## PART 3. 다변수 함수

### 핵심 한 줄
> 경로법으로 극한 판정, 편미분은 나머지 변수 고정 후 미분

---

### 3-1. 공간좌표계

#### 두 점 사이 거리

```
d = √((x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²)
```

#### 구의 방정식

```
표준형: (x-a)² + (y-b)² + (z-c)² = r²
        중심 (a,b,c), 반지름 r
```

전개된 형태가 주어지면 **완전제곱식**으로 변환해서 중심·반지름을 읽는다.

#### 좌표계 변환

```
원통좌표계: x = rcosθ,  y = rsinθ,  z = z
구면좌표계: x = ρsinφcosθ,  y = ρsinφsinθ,  z = ρcosφ
```

---

### 3-2. 다변수 함수

`z = f(x, y)` — 입력 2개, 출력 1개 (3D 곡면)

- **정의역**: f(x,y)가 정의되는 (x,y) 집합. √(·) ≥ 0, 분모 ≠ 0 조건 확인.
- **등위곡선**: `f(x,y) = c` 를 만족하는 곡선 (지형도 등고선)

#### 대표 곡면

| 곡면 | 방정식 | 단면 |
|---|---|---|
| 포물면 | `z = x² + y²` | 동심원 |
| 안장면 | `z = x² - y²` | 쌍곡선 |
| 구면 | `x²+y²+z² = r²` | 원 |
| 타원면 | `x²/a²+y²/b²+z²/c² = 1` | 타원 |

---

### 3-3. 다변수 함수의 극한/연속

#### 극한이 존재하지 않음 → 경로법

두 경로로 접근했을 때 값이 다르면 극한 없음.

자주 쓰는 경로:
```
y = 0,  y = x,  y = x²,  y = mx
```

대표 예제: `f(x,y) = 2xy/(x²+y²)`
```
y=0 경로: f(x,0) = 0  →  극한 = 0
y=x 경로: f(x,x) = 1  →  극한 = 1
0 ≠ 1  ∴ 극한 존재하지 않음
```

#### 극한이 존재함 → 스퀴즈 정리

```
0 ≤ |f(x,y) - L| ≤ g(x,y) → 0  ⟹  lim f = L
```

유용한 부등식: `|xy| ≤ (x²+y²)/2`

#### 꿀팁: 극좌표 대입

`x = rcosθ`, `y = rsinθ` → `(x,y)→(0,0)` 이 `r→0` 으로 변환

#### 연속의 정의

```
lim(x,y)→(a,b) f(x,y) = f(a,b)
```

---

### 3-4. 편도함수

다른 변수를 상수로 고정하고 하나의 변수로만 미분.

```
∂f/∂x = fₓ = lim[h→0] (f(x+h,y) - f(x,y)) / h
∂f/∂y = f_y = lim[h→0] (f(x,y+h) - f(x,y)) / h
```

#### 고계 편도함수

```
fₓₓ = ∂²f/∂x²,   f_yy = ∂²f/∂y²
fₓ_y = ∂²f/∂y∂x,  f_yx = ∂²f/∂x∂y
```

**클레로의 정리**: f가 연속이면 `fₓ_y = f_yx`

#### 연쇄 법칙

z = f(x,y), x = x(t), y = y(t) 이면:
```
dz/dt = (∂f/∂x)(dx/dt) + (∂f/∂y)(dy/dt)
```

#### 음함수 미분

```
F(x,y) = 0  →  dy/dx = -Fₓ/F_y
F(x,y,z) = 0  →  ∂z/∂x = -Fₓ/F_z
```

#### 전미분

```
dz = (∂f/∂x)dx + (∂f/∂y)dy
Δz ≈ fₓ(a,b)Δx + f_y(a,b)Δy  (근사 계산)
```

## PART 4. 벡터와 공간 기하

### 핵심 한 줄
> 외적=법선벡터·넓이·부피, ∇f⊥등위면, 판별식 D로 극값 분류

---

### 4-1. 공간도형

3D에서 두 직선의 관계 4가지:
- 일치 / 평행 / 교차 / **꼬인 위치** ← 3D에만 존재!

꼬인 위치: 같은 평면 위에 없으면서 만나지 않는 두 직선.

---

### 4-2. 정사영

벡터 a를 벡터 b 방향으로 투영:

```
proj_b(a) = (a·b / |b|²) · b       (벡터 투영)
comp_b(a) = a·b / |b|              (스칼라 투영)
```

---

### 4-3. 벡터

#### 내적 (Dot Product) → 스칼라

```
a · b = a₁b₁ + a₂b₂ + a₃b₃ = |a||b|cosθ
```
- 용도: 각도 계산, 수직 판별 (`a⊥b ⟺ a·b=0`)

#### 외적 (Cross Product) → 벡터

```
a × b = |i  j  k |
        |a₁ a₂ a₃|
        |b₁ b₂ b₃|

|a × b| = |a||b|sinθ = 평행사변형 넓이
```
- 용도: 법선벡터, 넓이·부피 계산

#### 스칼라 삼중적

```
a · (b × c) = |a₁ a₂ a₃|
               |b₁ b₂ b₃|  = 평행육면체 부피
               |c₁ c₂ c₃|
```

---

### 4-4. 평면의 방정식

법선벡터 **n** = (a,b,c), 점 (x₀,y₀,z₀) 지남:

```
a(x-x₀) + b(y-y₀) + c(z-z₀) = 0
```

법선벡터 구하는 법: 평면 위 두 벡터를 **외적**

#### 두 평면이 이루는 각

```
cosθ = |n₁·n₂| / (|n₁||n₂|)
```

#### 점-평면 거리

```
D = |ax₁ + by₁ + cz₁ - d| / √(a²+b²+c²)
```

---

### 4-5. 곡면의 방정식

| 곡면 | 방정식 | 특징 |
|---|---|---|
| 타원면 | `x²/a²+y²/b²+z²/c²=1` | 모든 단면 타원 |
| 원뿔면 | `x²/a²+y²/b²=z²` | 꼭짓점에서 벌어짐 |
| 타원 포물면 | `z=x²/a²+y²/b²` | z=k 단면이 타원 |
| 쌍곡 포물면 | `z=x²/a²-y²/b²` | 안장 모양 |
| 단엽 쌍곡면 | `x²/a²+y²/b²-z²/c²=1` | 허리가 있는 곡면 |
| 이엽 쌍곡면 | `-x²/a²-y²/b²+z²/c²=1` | 두 개로 분리 |

---

### 4-6. 공간선의 해석

점 (x₀,y₀,z₀), 방향벡터 v = (a,b,c) 인 직선:

```
매개변수: x=x₀+at, y=y₀+bt, z=z₀+ct
대칭형:   (x-x₀)/a = (y-y₀)/b = (z-z₀)/c
```

#### 꼬인 두 직선 사이 거리

```
d = |(r₂-r₁)·(v₁×v₂)| / |v₁×v₂|
```

---

### 4-7. 방향도함수와 기울기벡터

단위벡터 u = (cosα, sinα) 방향의 변화율:

```
D_u f = ∇f · u = fₓcosα + f_ysinα
```

기울기벡터(Gradient):

```
∇f = (∂f/∂x,  ∂f/∂y,  ∂f/∂z)
```

#### 핵심 성질 3가지 (시험 단골!)

1. `∇f` 방향 = f가 **가장 빠르게 증가**하는 방향
2. `|∇f|` = 그 방향의 **최대 변화율**
3. `∇f` ⊥ **등위곡면** (법선벡터!)

```
D_u f 최대 = |∇f|   (u ∥ ∇f 일 때)
D_u f 최소 = -|∇f|  (u 반대방향일 때)
```

---

### 4-8. 극대·극소 / 최대·최소

#### 임계점

`fₓ = 0` 이고 `f_y = 0` 인 점.

#### 이계 편도함수 판정법

판별식: `D = fₓₓ·f_yy - (fₓ_y)²`

| D | fₓₓ | 판정 |
|---|---|---|
| D > 0 | > 0 | **극솟값** |
| D > 0 | < 0 | **극댓값** |
| D < 0 | — | **안장점** |
| D = 0 | — | 판정 불가 |

#### 라그랑주 승수법

제약 `g(x,y)=0` 에서 `f(x,y)` 극값:

```
∇f = λ∇g

연립방정식:
  fₓ = λgₓ
  f_y = λg_y
  g(x,y) = 0
```

직관: f의 등위곡선과 제약 곡선이 **접할 때** 극값 발생.

## PART 5. 중적분

### 핵심 한 줄
> 좌표계 선택 + 야코비안이 전부 (극: r, 원통: r, 구면: ρ²sinφ)

---

### 5-1. 이중적분

```
∬_D f(x,y) dA = 곡면 z=f(x,y) 아래 부피
```

#### 푸비니 정리

Type I (x 고정, y 범위가 x에 의존):
```
∬_D f dA = ∫_a^b ∫_{g₁(x)}^{g₂(x)} f(x,y) dy dx
```

Type II (y 고정, x 범위가 y에 의존):
```
∬_D f dA = ∫_c^d ∫_{h₁(y)}^{h₂(y)} f(x,y) dx dy
```

#### 적분 순서 교환

직접 적분이 불가능할 때 사용.

```
예: ∫₀¹∫_x^1 e^(y²) dy dx
    → ∫₀¹∫₀^y e^(y²) dx dy = ∫₀¹ y·e^(y²) dy = (e-1)/2
```
방법: 영역 D를 그린 후 두 방향으로 다시 부등식 표현.

#### 극좌표 이중적분

```
x = rcosθ,  y = rsinθ
dA = r dr dθ  ← 야코비안 r 필수!

∬_D f dA = ∫_α^β ∫_{r₁(θ)}^{r₂(θ)} f(rcosθ, rsinθ) · r dr dθ
```

사용 시점: 원, 원판, 부채꼴 모양 영역

#### 이중적분 응용

```
넓이:  A = ∬_D 1 dA
부피:  V = ∬_D f(x,y) dA   (f ≥ 0)
두 곡면 사이 부피:  V = ∬_D [f_위 - f_아래] dA
```

---

### 5-2. 삼중적분

```
∭_E f(x,y,z) dV
f = 1 → 부피,   f = δ(밀도함수) → 질량
```

#### 좌표계별 부피 요소

| 좌표계 | 변환 | dV |
|---|---|---|
| 직교 | — | `dx dy dz` |
| 원통 | `x=rcosθ, y=rsinθ, z=z` | `r dr dθ dz` |
| 구면 | `x=ρsinφcosθ, y=ρsinφsinθ, z=ρcosφ` | `ρ²sinφ dρ dφ dθ` |

#### 좌표계 선택 가이드

| 영역 모양 | 선택 좌표계 |
|---|---|
| 직사각형, 일반 다각형 | 직교 |
| 원, 원판, 부채꼴 | 극좌표 (2D) |
| 원기둥, 원뿔, z축 대칭 | 원통 |
| 구, 반구, 구 껍데기 | 구면 |

#### 구의 부피 유도 (구면좌표)

```
∫₀²π ∫₀π ∫₀ᵃ ρ²sinφ dρ dφ dθ
= ∫₀²π ∫₀π (a³/3)sinφ dφ dθ
= ∫₀²π (a³/3)(2) dθ
= (4/3)πa³  ✓
```

---

### 5-3. 영역의 무게중심

밀도함수 δ(x,y) 를 가진 2D 물체:

```
질량:    m = ∬_D δ dA
모멘트:  Mₓ = ∬_D y·δ dA,   M_y = ∬_D x·δ dA
무게중심: x̄ = M_y/m,   ȳ = Mₓ/m
```

3D 물체 (밀도 δ(x,y,z)):

```
m = ∭_E δ dV
x̄ = (1/m)∭_E x·δ dV,   ȳ = (1/m)∭_E y·δ dV,   z̄ = (1/m)∭_E z·δ dV
```

균일 밀도 (δ=1) → 기하학적 중심(도심, Centroid)

관성모멘트:

```
Iₓ = ∬_D y²·δ dA,   I_y = ∬_D x²·δ dA
I_O = Iₓ + I_y = ∬_D (x²+y²)·δ dA
```

## PART 6. 벡터 해석

### 핵심 한 줄
> 3대 정리의 공통 구조: **경계의 적분 = 내부의 미분의 적분**

---

### 6-1. 장 (Field)

- **스칼라 장**: 각 점 → 스칼라. 예) 온도 분포 T(x,y,z)
- **벡터 장**: 각 점 → 벡터. `F(x,y,z) = Pi + Qj + Rk`

**보존장**: `F = ∇f` 인 벡터장 (f = 퍼텐셜 함수)
- 보존장이면 선적분이 경로에 무관!

---

### 6-2. 발산과 회전

#### 발산 (Divergence) → 스칼라

```
div F = ∇·F = ∂P/∂x + ∂Q/∂y + ∂R/∂z
```

직관: 각 점에서 유체가 **퍼져나가는 정도** (>0: 소스, <0: 싱크)

#### 회전 (Curl) → 벡터

```
curl F = ∇×F = |i      j      k    |
               |∂/∂x  ∂/∂y  ∂/∂z |
               |P      Q      R    |
```

직관: 각 점에서 유체가 **회전하는 정도**

#### 핵심 항등식 (시험 단골!)

```
curl(∇f) = ∇×∇f = 0        (기울기의 회전 = 0)
div(∇×F) = ∇·(∇×F) = 0    (회전의 발산 = 0)
∇×F = 0  →  F 는 보존장 (단순연결 영역에서)
```

---

### 6-3. 선적분 (Line Integral)

#### 스칼라 함수의 선적분

```
∫_C f ds = ∫_a^b f(r(t)) |r'(t)| dt
```

#### 벡터 함수의 선적분 (일)

```
∫_C F·dr = ∫_a^b F(r(t))·r'(t) dt = ∫_C P dx + Q dy + R dz
```

물리적 의미: 힘 F가 경로 C를 따라 한 **일(Work)**

#### 경로 독립 (보존장!)

`F = ∇f` 이면:
```
∫_C F·dr = f(끝점) - f(시작점)
```

경로 무관, 양 끝점의 퍼텐셜 차이로만 계산!

#### 퍼텐셜 함수 구하는 순서

```
① curl F = 0 확인 (∂Q/∂x = ∂P/∂y 등)
② F = ∇f 라 놓고 fₓ = P 로 x 적분 → f(x,y) + g(y)
③ f_y = Q 로 g'(y) 결정
④ f(x,y,z) 완성
```

---

### 6-4. 그린 정리 (Green's Theorem)

단순폐곡선 C (반시계 방향), 내부 D:

```
∮_C P dx + Q dy = ∬_D (∂Q/∂x - ∂P/∂y) dA
```

직관: **경계(선적분) = 내부 회전 성분의 합(이중적분)**

넓이 계산:
```
A = (1/2) ∮_C (x dy - y dx)
```

사용 전략:
- 선적분이 복잡 → 이중적분으로 변환
- 이중적분이 복잡 → 선적분으로 변환
- 폐곡선 안에 특이점 → 작은 원으로 구멍 뚫기

---

### 6-5. 면적분 (Surface Integral)

#### 스칼라 함수의 면적분

```
∬_S f dS = ∬_D f(x,y,g(x,y)) √(gₓ²+g_y²+1) dA
```

dS = √(gₓ²+g_y²+1) dA → **면적 요소** (기울어진 면 보정)

#### 벡터 함수의 면적분 (플럭스)

```
∬_S F·dS = ∬_S F·n dS = ∬_D F·(-gₓi - g_yj + k) dA
```

물리적 의미: 단위 시간 동안 곡면을 통과하는 **유량(Flux)**

---

### 6-6. 가우스 발산 정리 (Gauss's Divergence Theorem)

닫힌 곡면 S (바깥 방향), 내부 E:

```
∯_S F·dS = ∭_E div F dV = ∭_E ∇·F dV
```

직관: **총 유출량 = 내부 발산의 합**

사용 전략:
- 닫힌 면(구, 원기둥, 박스)이면 발산 정리 먼저 고려
- div F 가 단순하면 삼중적분이 훨씬 쉬움

예제: F = (x,y,z), S = 단위구 표면
```
div F = 1+1+1 = 3
∯ F·dS = ∭ 3 dV = 3 × (4π/3) = 4π
```

---

### 6-7. 스톡스 정리 (Stokes' Theorem)

곡면 S의 경계 C (오른손 법칙 방향):

```
∮_C F·dr = ∬_S curl F·dS = ∬_S (∇×F)·dS
```

직관: **경계 순환(선적분) = 곡면 위 회전의 합(면적분)**

그린 정리 = 스톡스 정리의 특수한 경우 (곡면이 xy 평면)

사용 전략:
- 3D 폐곡선 선적분이 복잡 → 곡면 S 선택해서 면적분으로
- 곡면 S가 복잡 → 같은 경계를 가진 더 단순한 곡면으로 교체 가능!

예제: F = (-y, x, z²), C = x²+y²=1, z=0 인 원
```
curl F = (0, 0, 2)
S = 원판, n = k
∬ curl F·k dA = ∬ 2 dA = 2π
```

---

### 세 정리 비교 요약

| 정리 | 차원 | 변환 | 공식 |
|---|---|---|---|
| 그린 | 2D | 선적분 ↔ 이중적분 | `∮_C = ∬_D (∂Q/∂x - ∂P/∂y) dA` |
| 가우스 | 3D | 면적분 ↔ 삼중적분 | `∯_S F·dS = ∭_E ∇·F dV` |
| 스톡스 | 3D | 선적분 ↔ 면적분 | `∮_C F·dr = ∬_S (∇×F)·dS` |

> 셋 다 공통 구조: **경계의 적분 = 내부의 미분의 적분**

## 부록. 무한급수 명제 참/거짓 판단

> 핵심 전략: 반례 찾기 → 조화급수 `Σ1/n`, 교대조화급수 `Σ(-1)ⁿ/n`, 바젤 `Σ1/n²` 를 항상 머릿속에!

| 명제 | 참/거짓 | 근거 |
|---|---|---|
| `Σaₙ 수렴 ⟹ aₙ→0` | **참** | 수렴의 필요조건 |
| `aₙ→0 ⟹ Σaₙ 수렴` | **거짓** | 반례: Σ1/n (조화급수) |
| `Σaₙ, Σbₙ 발산 ⟹ Σ(aₙ+bₙ) 발산` | **거짓** | 반례: aₙ=1, bₙ=-1 |
| `Σaₙ 절대수렴 ⟹ Σaₙ 수렴` | **참** | 절대수렴 ⊂ 수렴 |
| `비율판정 L=1 ⟹ 수렴` | **거짓** | L=1은 판정 불가 (Σ1/n, Σ1/n² 모두 L=1) |
| `Σaₙ 수렴 ⟹ Σaₙ² 수렴` | **거짓** | 반례: aₙ=(-1)ⁿ/√n |
| `Σaₙ 절대수렴, Σbₙ 절대수렴 ⟹ Σaₙbₙ 절대수렴` | **참** | |
