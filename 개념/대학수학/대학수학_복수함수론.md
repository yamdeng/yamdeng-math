## 1장. 복소수 (Complex Numbers)

### 핵심 개념

| 항목 | 정의 |
|------|------|
| 허수 단위 | `i² = −1` |
| 복소수 표준형 | `z = a + bi` (a = Re(z), b = Im(z)) |
| 켤레복소수 | `z̄ = a − bi` |
| 절댓값 | `|z| = √(a²+b²)` |

### 극형식 & 오일러 공식

```
z = r(cos θ + i sin θ) = r·e^{iθ}
e^{iπ} + 1 = 0          ← 오일러의 항등식
드 모아브르: (cos θ + i sin θ)ⁿ = cos(nθ) + i sin(nθ)
```

### 기본 연산

| 연산 | 직교형식 (a+bi) | 극형식 (re^{iθ}) |
|------|-----------------|-----------------|
| 덧셈 | (a+c) + (b+d)i | 성분별 합산 |
| 곱셈 | (ac−bd) + (ad+bc)i | r₁r₂ · e^{i(θ₁+θ₂)} |
| 나눗셈 | 분자·켤레 / |z₂|² | (r₁/r₂) · e^{i(θ₁−θ₂)} |
| n제곱근 | 풀기 복잡 | r^{1/n} · e^{i(θ+2πk)/n}, k=0..n−1 |

### 포인트

- 덧셈·뺄셈 → 직교형식, 곱셈·나눗셈·거듭제곱 → 극형식
- 주편각 `Arg(z)`: 범위 `(−π, π]`로 고정한 유일한 편각
- `z·z̄ = |z|²` → 나눗셈의 핵심
- n제곱근은 정확히 n개, 복소평면 원 위에 등간격 배열

## 2장. 해석 함수 (Analytic Functions)

### 코시-리만 방정식 (C-R 방정식)

`f(z) = u(x,y) + i·v(x,y)` 가 해석적 ⟺

```
∂u/∂x = ∂v/∂y    (제1 C-R 방정식)
∂u/∂y = −∂v/∂x   (제2 C-R 방정식)
```

극형식: `∂u/∂r = (1/r)·∂v/∂θ`,  `(1/r)·∂u/∂θ = −∂v/∂r`

### 해석 vs 비해석 예시

| 해석 함수 (C-R 성립) | 비해석 함수 (C-R 불성립) |
|----------------------|--------------------------|
| `zⁿ`, `eᶻ`, `sin z`, `cos z` | `z̄`, `|z|²`, `Re(z)`, `Im(z)` |

### 조화함수

- 해석함수 f = u + iv의 실수부·허수부는 모두 조화함수
- `∇²u = 0` (라플라스 방정식) 만족
- u가 주어지면 C-R로 켤레 조화함수 v 복원 가능

### 포인트

- 복소 미분가능 = 모든 방향에서 극한값이 동일 → 매우 강한 조건
- C-R은 필요충분조건 (단, 편미분 연속 조건 추가 필요)
- 응용: 유체역학(속도포텐셜), 전자기학(전위), 열전도

## 3장. 초등 함수 (Elementary Functions)

### 복소 지수함수

```
e^z = e^x · (cos y + i sin y)
|e^z| = e^x,    arg(e^z) = y + 2πk
주기성: e^{z+2πi} = e^z   ← 주기 2πi
```

| z | e^z |
|---|-----|
| 0 | 1 |
| iπ | −1 (오일러 항등식) |
| iπ/2 | i |

### 복소 로그함수 (다중값)

```
log z = ln|z| + i·(Arg z + 2πk),   k = 0, ±1, ±2, ...
주값: Ln z = ln|z| + i·Arg z   (−π < Arg z ≤ π)
```

- **분지 절단선**: 음의 실수축 → 이 선을 넘으면 Arg z 불연속
- `log(z₁z₂) = log z₁ + log z₂` (단, 주값에서는 ±2πi 오차 가능)

### 복소 삼각함수

```
sin z = (e^{iz} − e^{−iz}) / 2i
cos z = (e^{iz} + e^{−iz}) / 2
sin(x+iy) = sin x·cosh y + i·cos x·sinh y
```

- `sin(iy) = i·sinh y`,  `cos(iy) = cosh y` (삼각 ↔ 쌍곡 연결)
- **주의**: `|sin z|`, `|cos z|` → ∞ 가능 (유계 아님!)

### 일반 거듭제곱

```
z^α = e^{α·log z}   ← log z의 다중값 → z^α도 다중값
```

## 4장. 적분 (Integration)

### 복소 선적분

```
∫_C f(z) dz   (경로 C 위에서 매개변수화로 계산)
```

### 코시 정리

**단순연결 영역에서 f 해석적** → 모든 폐곡선 C에 대해

```
∮_C f(z) dz = 0
```

해석성 = 경로 독립성 = 폐곡선 적분 0 (세 가지는 동치)

### 코시 적분 공식

```
f(z₀) = (1/2πi) ∮_C f(z)/(z−z₀) dz          (n=0)
f^(n)(z₀) = n!/(2πi) ∮_C f(z)/(z−z₀)^{n+1} dz
```

- 경계값으로 내부값 완전 결정
- 해석함수는 무한번 미분 가능 (C^∞)

### 핵심 공식들

```
ML 부등식: |∫_C f(z) dz| ≤ M · L   (M=최댓값, L=경로 길이)
코시 부등식: |f^(n)(z₀)| ≤ n!·M / r^n
```

### 중요 정리

| 정리 | 내용 |
|------|------|
| 리우빌 정리 | 유계 + 전해석 → 상수 |
| 대수학 기본정리 | n차 다항식 → 정확히 n개의 근 (리우빌로 증명) |
| 모레라 정리 | ∮f dz = 0 → 해석적 (코시 정리의 역) |

## 5장. 급수 (Series)

### 테일러 급수

```
f(z) = Σ aₙ(z−z₀)ⁿ,   aₙ = f^(n)(z₀)/n!
```

- 해석점 z₀ 주변, 음수 차수 없음
- 수렴 반지름 R = z₀에서 가장 가까운 특이점까지의 거리

### 로랑 급수

```
f(z) = Σ cₙ(z−z₀)ⁿ   (n = −∞ ~ +∞)
```

- 특이점 포함 고리 영역 `r < |z−z₀| < R` 에서 수렴
- 주요부(principal part): 음수 차수 항들 `c₋₁/(z−z₀) + c₋₂/(z−z₀)² + ...`

### 주요 테일러 급수

| 함수 | 급수 (z₀=0) | 수렴 반지름 |
|------|-------------|------------|
| `eᶻ` | `1 + z + z²/2! + z³/3! + ···` | R = ∞ |
| `sin z` | `z − z³/3! + z⁵/5! − ···` | R = ∞ |
| `cos z` | `1 − z²/2! + z⁴/4! − ···` | R = ∞ |
| `1/(1−z)` | `1 + z + z² + z³ + ···` | R = 1 |
| `Ln(1+z)` | `z − z²/2 + z³/3 − ···` | R = 1 |

### 특이점 분류 (로랑 급수로 판별)

| 종류 | 주요부 | 예시 |
|------|--------|------|
| 제거 가능 특이점 | = 0 (주요부 없음) | `sin z / z` at z=0 |
| m차 극점 | 유한개 (c₋m ≠ 0) | `1/z²` at z=0 (2차) |
| 진성 특이점 | 무한개 | `e^{1/z}` at z=0 |

- **피카르 정리**: 진성 특이점 근방에서 f(z)는 (최대 1개 제외) 모든 복소수 값을 취함

## 6장. 유수와 극점 (Residues & Poles)

### 유수 정의

```
Res[f, z₀] = c₋₁   (로랑 급수에서 (z−z₀)^{−1}의 계수)
```

### 극점 차수별 유수 공식

| 극점 종류 | 유수 공식 |
|-----------|-----------|
| 단순 극점 (1차) | `lim_{z→z₀} (z−z₀)·f(z)` |
| p(z)/q(z) 단순극 | `p(z₀) / q'(z₀)` |
| m차 극점 | `1/(m−1)! · lim d^{m−1}/dz^{m−1} [(z−z₀)^m f(z)]` |

### 유수 정리

```
∮_C f(z) dz = 2πi · Σ Res[f, zₖ]   (zₖ: C 내부 특이점들)
```

### 주요 계산 예시

```
∮ (1/z) dz   = 2πi   (단순 극점, 유수=1)
∮ (1/z²) dz  = 0     (2차 극점, 유수=0)
∮ 1/(z²+1) dz (|z|=2): 극점 z=±i, 유수합=0 → 적분=0
```

### 편각 원리

```
(1/2πi) ∮ f'/f dz = Z − P   (Z: 영점수, P: 극점수)
```

## 7장. 유수의 응용 (Applications of Residues)

### 적분 유형별 전략

| 유형 | 형태 | 방법 |
|------|------|------|
| 삼각함수 | `∫₀²π R(cos θ, sin θ) dθ` | `z=e^{iθ}` 치환 → 단위원 유수 |
| 유리함수 | `∫_{−∞}^{∞} P(x)/Q(x) dx` | 반원 경로 + 조르당 보조정리 |
| 푸리에형 | `∫_{−∞}^{∞} f(x)e^{iax} dx` | a>0: 상반, a<0: 하반 반원 |
| 무한급수 | `Σ f(n)` | `π·cot(πz)` 극점 활용 |

### 조르당 보조정리

`f(z) → 0` uniformly (|z|→∞) 이면 반원 호의 기여 → 0

```
∫_{-∞}^{∞} 1/(x²+a²) dx = π/a   (a>0)
∫_{-∞}^{∞} cos(ax)/(x²+1) dx = π·e^{-a}   (a>0)
∫_{-∞}^{∞} sin(x)/x dx = π
```

### 무한급수 합산

```
Σ 1/n²  = π²/6    (바젤 문제)
Σ 1/n⁴  = π⁴/90
Σ (−1)ⁿ/n² = π²/12
```

### 루셰 정리

`|f−g| < |g|` on C → f와 g의 경로 안 영점 수 동일

## 8장. 초등 함수에 의한 사상 (Mappings by Elementary Functions)

### 등각 사상

- `f'(z₀) ≠ 0`인 해석함수 → z₀에서 **각도 보존**
- 확대율: `|f'(z₀)|`, 회전각: `arg(f'(z₀))`
- 임계점 `f'(z₀) = 0` → 각도 보존 실패

### 주요 사상

| 함수 | 변환 성질 | 응용 |
|------|-----------|------|
| `w = z²` | r→r², θ→2θ. 상반평면→전체 | 쐐기 영역→반평면 |
| `w = zⁿ` | 각도 n배, 1/n 쐐기→반평면 | n각 쐐기 변환 |
| `w = e^z` | 수직선→원, 수평선→방사선 | 무한 띠→반평면 |
| `w = 1/z` | 원↔직선 (반전 변환) | 원/직선→원/직선 |
| `w = sin z` | 무한 띠→전체 평면 | 반무한 띠 변환 |

### w = 1/z 반전 변환

```
z = r·e^{iθ} → w = (1/r)·e^{−iθ}
```

- 원점 통과하지 않는 원 → 원
- 원점 통과하는 원 → 직선
- 직선 → 원점 통과 원 또는 직선

## 9장. 한꼴 사상 (Möbius Transformation)

### 정의

```
w = (az+b)/(cz+d),   ad − bc ≠ 0
역변환: z = (−dw+b)/(cw−a)
```

### 핵심 성질

- **원·직선 보존**: 원과 직선을 원과 직선으로 변환
- **복비 불변**: `(z₁,z₂;z₃,z₄) = (w₁,w₂;w₃,w₄)`
- 세 점의 상이 결정되면 변환이 유일하게 결정

### 복비 (Cross-ratio)

```
(z, z₁; z₂, z₃) = [(z−z₁)(z₂−z₃)] / [(z−z₃)(z₂−z₁)]
```

4점 공원(공선) 조건: 복비가 실수

### 기본 구성요소

모든 한꼴 변환 = ①평행이동 + ②회전 + ③신축 + ④반전(`1/z`) 합성

### 중요한 표준 변환

| 변환 | 의미 |
|------|------|
| `w = (z−i)/(z+i)` | 상반평면 → 단위원판 |
| `w = e^{iθ}(z−z₀)/(1−z̄₀z)` | 단위원판 자기동형 |
| a,b,c,d ∈ ℝ, ad−bc>0 | 상반평면 → 상반평면 |

---

## 10장. 한꼴 사상의 활용 (Applications of Möbius Transformation)

### 핵심 전략

```
복잡한 영역 D의 디리클레 문제
→ 한꼴 사상으로 단순 영역 D'으로 변환
→ D'에서 해 구하기
→ 역변환으로 D의 해 복원
```

**등각 사상은 라플라스 방정식을 보존** → 변환된 영역에서 풀어도 됨

### 상반평면 기본 해

```
Im(z) > 0, 경계: u(x,0) = u₁ (x<0), u₂ (x>0)
해: u(x,y) = u₁ + (u₂−u₁)/π · arctan(y/x)
복소 포텐셜: F(z) = (u₂−u₁)/(πi) · log z + u₁
```

### 복소 포텐셜

```
F(z) = φ + iψ
φ: 속도포텐셜 (전위)
ψ: 유선함수 (등전위선)
```

### 응용 분야

| 분야 | φ (실수부) | ψ (허수부) |
|------|-----------|-----------|
| 유체역학 | 속도 포텐셜 | 유선 함수 |
| 정전기학 | 전기 전위 | 전기력선 |
| 열전도 | 온도 분포 | 열류선 |
| 탄성론 | 응력 함수 | 켤레 응력 |

### 쥬코프스키 변환

```
w = z + 1/z   ← 원 → 익형(airfoil)
원 주위 유동 → 역변환 → 날개 주위 유동 (양력 계산)
```

### 슈바르츠 반사 원리

f가 실수축에서 실수값 → `f*(z) = f̄(z̄)`로 해석적 연속 가능

## 11장. 슈바르츠·크리스토펠 변환 (Schwarz-Christoffel Transformation)

### 공식

```
dw/dz = A · ∏(z−xₖ)^{αₖ−1}
w = A ∫ ∏(z−xₖ)^{αₖ−1} dz + B
```

- `xₖ`: 실수축 위 점 (꼭짓점 전상)
- `αₖπ`: 다각형 꼭짓점 내각
- `Σ αₖ = n − 2` (n각형 조건)

### 핵심 아이디어

z가 실수축 xₖ를 지날 때 `arg(dw/dz)`가 `(1−αₖ)π` 만큼 점프 → 꼭짓점 형성

### 주요 변환 공식

| 영역 | 내각 조건 |
|------|-----------|
| 반무한 띠 | 꼭짓점 2개, 각 π/2 |
| 직사각형 | 꼭짓점 4개, 각 π/2 → **타원 적분** 등장 |
| 정삼각형 | 꼭짓점 3개, 각 π/3 |
| 슬릿(절개) | 꼭짓점 각도 0 |

### 직사각형과 타원 적분

```
직사각형 변환: w = ∫₀^z dt / √[(1−t²)(1−k²t²)]
= 제1종 완전 타원 적분 K(k)
직사각형 가로:세로 = K(k) : K(k'),   k' = √(1−k²)
```

### 꼭짓점이 ∞인 경우

꼭짓점 하나를 `z = ∞`으로 보내면 해당 인수 생략 → 반무한 띠 등

## 12장. 푸아송 형태의 적분 공식 (Poisson Integral Formula)

### 단위원판 푸아송 공식

```
u(r,θ) = (1/2π) ∫₀²π P(r, φ−θ) · u(1,φ) dφ
푸아송 커널: P(r,θ) = (1−r²) / (1−2r cosθ + r²)
```

### 상반평면 푸아송 공식

```
u(x,y) = (y/π) ∫_{−∞}^{∞} u(t,0) / ((x−t)² + y²) dt
```

### 슈바르츠 적분 공식

```
단위원판: F(z) = (1/2πi) ∮ (ζ+z)/(ζ−z) · u(ζ)/ζ dζ + iC
상반평면: F(z) = (1/πi) ∫_{−∞}^{∞} u(t)/(t−z) dt + iC
```

u(실수부)가 주어지면 v(허수부)는 **힐베르트 변환**으로 결정

### 푸아송 커널의 성질

```
P > 0
(1/2π) ∫ P dθ = 1   → 가중 평균!
r→0: P→1   → u(0) = 경계 평균 (평균값 정리)
r→1: P→디랙 델타   → 경계값으로 수렴
```

### 단위원판 vs 상반평면 비교

| 항목 | 단위원판 | 상반평면 |
|------|---------|---------|
| 영역 | `|z| < 1` | `Im(z) > 0` |
| 커널 | `(1−r²)/(1−2r cosθ+r²)` | `y/π · 1/((x−t)²+y²)` |
| r→1 또는 y→0 | 경계값으로 수렴 | 경계값으로 수렴 |
| 중심값 | 경계 평균 | — |
| 상호 관계 | `w=(z−i)/(z+i)` 한꼬 변환으로 연결 | |

### 평균값 정리 & 최댓값 원리

```
평균값 정리: u(z₀) = (1/2π) ∫₀²π u(z₀ + re^{iθ}) dθ
최댓값 원리: 조화함수의 최댓값·최솟값은 반드시 경계에 위치
유일성 정리: 경계값이 같으면 내부 해도 동일
```

## 전체 커리큘럼 흐름

```
1장 복소수         → 수 체계 기초
2장 해석 함수      → 미분 가능성 (C-R 방정식)
3장 초등 함수      → eᶻ, log z, sin z 복소 확장
4장 적분           → 코시 정리, 코시 적분 공식 ★
5장 급수           → 테일러·로랑, 특이점 분류
6장 유수와 극점    → Res[f, z₀] = c₋₁, 유수 정리 ★
7장 유수의 응용    → 실수 적분, 무한급수 합산 ★
8장 초등함수 사상  → 등각 사상, 기하학적 변환
9장 한꼴 사상      → 뫼비우스 변환, 복비 불변
10장 한꼴 사상 활용 → 경계값 문제, 유체·열·전기
11장 S-C 변환      → 다각형 영역, 타원 적분
12장 푸아송 공식   → 경계→내부 조화함수 완전 결정 ★
```

> ★ 표시는 전체에서 가장 핵심적인 장들
