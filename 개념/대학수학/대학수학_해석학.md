## 제1부: 수의 체계와 계산의 기초

### 1.1 실수의 구조와 완비성

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 실수의 완비성 | 상한(sup) 존재 | 유리수와 달리 실수엔 "구멍"이 없다 |
| √2 무리수 | 귀류법 | 유리수로 표현 불가능, 수학적 증명 가능 |
| 데데킨트 절단 | 유리수 → 실수 구성 | 유리수만으로 무리수를 정의할 수 있다 |

**√2가 무리수인 이유 (귀류법)**

√2 = p/q (기약분수) 가정 → p² = 2q² → p가 짝수 → p = 2k → q² = 2k² → q도 짝수 → 기약분수에 모순 → √2는 무리수 ■

**완비성 공리:** 위로 유계인 공집합이 아닌 집합은 반드시 최소 상계(supremum)를 가진다.

**수 체계 포함 관계:** ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ

### 1.2 수학적 기초 및 오차 분석

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 부동소수점 | IEEE 754, 32/64비트 | 컴퓨터의 실수 = 근사값, 오차 필연적 |
| 소거 오차 | 비슷한 수 뺄셈 | 유효 자릿수가 갑자기 줄어드는 현상 |
| 조건수 κ | 오차 증폭률 | κ ≫ 1이면 수치 계산 신뢰 불가 |

**IEEE 754 구조:** `값 = (-1)^s × 1.m × 2^(e−127)`

- s: 부호 (1비트), e: 지수부 (8비트), m: 가수부 (23비트)

**조건수:** κ = 출력 상대 오차 / 입력 상대 오차

### 1.3 집합과 기수

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 가산/비가산 | 전단사 함수 | ℕ, ℤ, ℚ는 같은 크기, ℝ은 더 크다 |
| 칸토어 정리 | 대각선 논법 | 무한에도 크기의 계층이 존재한다 |

**기수 계층:**

| 집합 | 기수 | 종류 |
|---|---|---|
| 자연수 ℕ | ℵ₀ | 가산 무한 |
| 정수 ℤ, 유리수 ℚ | ℵ₀ | 가산 무한 |
| 실수 ℝ | 𝔠 = 2^ℵ₀ | 비가산 무한 |
| ℝ의 멱집합 P(ℝ) | 2^𝔠 | 더 큰 무한 |

**칸토어 대각선 논법:** 목록의 대각선 원소를 모두 바꿔 만든 새 수는 어떤 원소와도 다름 → [0,1]은 비가산

## 제2부: 수열, 급수 및 선형 시스템

### 2.1 수열과 급수의 이론

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| ε-N 논법 | 극한의 엄밀한 정의 | "아무리 작은 오차도, N 이후엔 항상 안에 든다" |
| 단조수렴정리 | 단조 + 유계 → 수렴 | 극한값 몰라도 수렴 자체를 보장 |
| 코시 판정법 | 항끼리의 거리 | 극한값 없이도 수렴 판정 가능 |

**ε-N 정의:** lim a_n = L ⟺ ∀ε>0, ∃N, n>N ⟹ |a_n − L| < ε

**단조수렴정리:** 단조증가 + 위로 유계 → 반드시 수렴

**코시 수열:** m, n > N ⟹ |a_m − a_n| < ε

### 2.2 선형 시스템의 수치 해법

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 가우스 소거 | 행 연산 → 상삼각 | O(n³), 피벗팅으로 수치 안정성 확보 |
| 3중 대각 시스템 | 토마스 알고리즘 | O(n)으로 극도로 빠른 특수 구조 |
| LU 분해 | A = LU | 한 번 분해 → 여러 b에 O(n²) 재활용 |

**LU 분해 풀이 절차:**
1. A = LU 분해 (O(n³))
2. Ly = b 전방 대입 (O(n²))
3. Ux = y 역방 대입 (O(n²))

**피벗팅:** 나눗셈 시 수치 오차 방지 → 절댓값이 가장 큰 원소를 피벗으로 행 교환

### 2.3 고윳값 문제와 반복법

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 고윳값·고유벡터 | Av = λv | 변환해도 방향이 안 바뀌는 특별한 벡터 |
| 누승법 | 반복 정규화 | 지배 고윳값 수렴, 페이지랭크에 활용 |
| 야코비/가우스-자이델 | 반복적 해법 | 대각 우세 행렬에서 수렴 보장 |

**누승법:** v ← Av / ‖Av‖ 반복 → 지배 고윳값의 고유벡터로 수렴

**수렴 속도:** |λ₂/λ₁| 비율에 비례

## 제3부: 실수의 위상과 함수의 극한

### 3.1 실수의 위상적 성질

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 열린 집합 | 내부 모든 점에 근방 존재 | 끝점 없는 구간 — 경계가 "바깥" |
| 닫힌 집합 | 극한점 포함 | 수렴하는 수열의 극한도 안에 |
| 콤팩트 집합 | 닫힘 + 유계 | 최대·최솟값 존재 보장 |
| 연결 집합 | 쪼갤 수 없음 | ℝ에서 연결 = 구간 |
| 베르 범주 정리 | 완비 공간의 크기 | 가산 개 얇은 집합으로 전체를 못 덮음 |

**하이네-보렐 정리:** ℝ에서 콤팩트 ↔ 닫혀 있고 유계

**최대최소 정리:** 콤팩트 집합 위의 연속함수 → 최댓값·최솟값 달성 보장

### 3.2 함수의 극한과 연속

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| ε-δ 논법 | 함수 극한의 엄밀한 정의 | "x가 a에 가까울수록 f(x)도 L에 가깝다" |
| 디리클레/토메 함수 | 연속성의 극단 사례 | 모든 점 불연속 / 무리수에서만 연속 |
| 사잇값 정리 | 연결 집합 + 연속함수 | 이분법의 수학적 근거 |

**ε-δ 정의:** lim_{x→a} f(x) = L ⟺ ∀ε>0, ∃δ>0, 0<|x−a|<δ ⟹ |f(x)−L|<ε

**디리클레 함수:** D(x) = 1 (x∈ℚ), 0 (x∉ℚ) → 모든 점에서 불연속

**토메 함수(팝콘 함수):** T(x) = 1/q (x=p/q 기약), 0 (x∉ℚ) → 무리수에서만 연속

### 3.3 비선형 방정식의 근사

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 이분법 | 구간 반씩 줄이기 | 1차 수렴, 느리지만 반드시 수렴 |
| 뉴턴법 | 접선 이용 | 2차 수렴, 빠르지만 초기값 민감 |
| 할선법 | 두 점 기울기로 근사 | 1.618차 수렴, f′ 없이도 동작 |

**수렴 속도 비교:** 이분법(1차) < 할선법(≈1.618차) < 뉴턴법(2차)

**뉴턴법 점화식:** x_{n+1} = x_n − f(x_n)/f′(x_n)

**할선법 점화식:** x_{n+1} = x_n − f(x_n)·(x_n − x_{n-1}) / (f(x_n) − f(x_{n-1}))

## 제4부: 미분학 — 이론과 근사

### 4.1 도함수의 성질

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 평균값 정리 | f′(c) = (f(b)−f(a))/(b−a) | 평균 변화율 = 순간 변화율인 점이 반드시 존재 |
| Darboux 정리 | 도함수의 사잇값 성질 | 도함수는 불연속 가능하나 1종 불연속 불가 |

**MVT 주요 따름 정리:**
- f′(x) = 0 → f는 상수
- f′(x) > 0 → f는 순증가
- |f′(x)| ≤ M → Lipschitz 연속 (알고리즘 안정성의 토대)

### 4.2 보간법과 수치 미분

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 라그랑주 보간 | L_k(x) 선택자 다항식 | n+1개 점을 정확히 지나는 유일한 최소 차수 다항식 |
| 룽게 현상 | 고차 보간의 끝점 진동 | 등간격 + 고차 = 오히려 오차 증가 |
| 리처드슨 보외법 | 두 스텝 값 조합 | O(h²) 오차 → O(h⁴)로 향상 |
| 3차 스플라인 | 구간마다 3차 다항식 | C² 연속 — 3중 대각 시스템으로 풀기 |

**라그랑주 보간:** P(x) = Σ y_k · L_k(x), L_k(x) = Π_{j≠k} (x−x_j)/(x_k−x_j)

**스플라인 연속성:**

| 종류 | 차수 | 연속성 |
|---|---|---|
| 1차 스플라인 | 1차 | C⁰ |
| 2차 스플라인 | 2차 | C¹ |
| 3차 스플라인 | 3차 | C² |

### 4.3 최적화 기초

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 1·2계 조건 | f′=0, f″ 부호 | 극값 후보 → 극대/극소 판정 |
| 경사하강법 | x ← x − αf′(x) | 머신러닝의 핵심, 학습률이 수렴 결정 |
| 황금분할 탐색 | 황금비 φ = 1.618 | 도함수 없이 단봉함수 최솟값 탐색 |

**수렴 조건:** f가 Lipschitz 연속 기울기를 가지면 α < 2/L에서 경사하강법 수렴 보장

## 제5부: 적분학 — 리만 적분에서 수치 적분까지

### 5.1 리만 적분론

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 리만 적분 | 상합·하합의 수렴 | L = U가 되는 분할의 극한 = 적분 |
| FTC 1부 | d/dx ∫_a^x f = f(x) | 적분의 도함수 = 피적분함수 |
| FTC 2부 | ∫_a^b f = F(b)−F(a) | 미분과 적분은 역연산 |
| 적분 가능 조건 | 불연속점 가산 개 | 토메 함수 가능, 디리클레 불가 |

**리만 적분 가능성:**
- 연속함수 → 가능 ✓
- 단조함수 → 가능 ✓
- 토메 함수 → 가능 ✓ (불연속점이 가산개)
- 디리클레 함수 → 불가능 ✗ (불연속점이 조밀)

### 5.2 수치 적분 알고리즘

| 방법 | 오차 차수 | 특징 |
|---|---|---|
| 사다리꼴 | O(h²) | 단순, 빠른 구현 |
| 심프슨 | O(h⁴) | 균형 잡힌 정확도 |
| 롬베르크 | O(h^{2k}) | 반복 오차 소거 |
| 가우스 구적 | O(h^{2n}) | 최소 점수로 최고 정확도 |

**사다리꼴 공식:** h/2 · [f(x₀) + 2f(x₁) + ⋯ + 2f(x_{n-1}) + f(x_n)]

**심프슨 공식:** h/3 · [f(x₀) + 4f(x₁) + 2f(x₂) + 4f(x₃) + ⋯ + f(x_n)]

**가우스 구적:** n개 점으로 최대 2n−1차 다항식 정확 적분

### 5.3 몬테카를로법

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 몬테카를로 | O(1/√N) | 차원에 무관 — 고차원의 구원자 |

**핵심 아이디어:** ∫_a^b f(x)dx ≈ (b−a) · (1/N) Σ f(x_i), x_i ~ Uniform(a,b)

**차원별 필요 점 수 비교:**

| 차원 | 격자법 점 수 (오차 0.01) | 몬테카를로 점 수 |
|---|---|---|
| 1D | ~100 | ~10,000 |
| 5D | ~10¹⁰ | ~10,000 |
| 10D | ~10²⁰ | ~10,000 |

## 제6부: 함수열과 급수의 전개

### 6.1 함수열의 수렴

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 점별 수렴 | 각 x마다 독립 수렴 | 극한이 불연속일 수 있음 — 성질 보존 안 됨 |
| 고른 수렴 | 전체에서 동시에 수렴 | 연속성·적분·미분 극한 교환 가능 |
| 바이어슈트라스 정리 | 연속 → 다항식 근사 | 신경망 보편 근사 정리의 수학적 선조 |

**점별 수렴 예:** f_n(x) = xⁿ on [0,1] → 극한 f는 x=1에서 불연속

**고른 수렴의 강력한 성질:**
- f_n 연속 + 고른 수렴 → f 연속
- 고른 수렴 → lim ∫f_n = ∫(lim f_n) (극한과 적분 교환)
- 고른 수렴 → (lim f_n)′ = lim f_n′ (미분 교환)

### 6.2 멱급수와 테일러 전개

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 수렴 반경 R | 코시-아다마르 공식 | 멱급수가 수렴하는 범위 |
| 테일러 급수 | f^(n)(c)/n! 계수 | 함수를 무한 다항식으로 전개 |
| 나머지 정리 | O((x−c)^{n+1}) | 오차의 명시적 상한 |

**핵심 테일러 급수:**

| 함수 | 전개식 | 수렴 반경 |
|---|---|---|
| eˣ | 1 + x + x²/2! + x³/3! + ⋯ | ∞ |
| sin x | x − x³/3! + x⁵/5! − ⋯ | ∞ |
| cos x | 1 − x²/2! + x⁴/4! − ⋯ | ∞ |
| ln(1+x) | x − x²/2 + x³/3 − ⋯ | 1 |

**나머지 항:** R_n(x) = f^{(n+1)}(ξ) / (n+1)! · (x−c)^{n+1}

### 6.3 최소제곱법과 푸리에 분석

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 최소제곱법 | 정규방정식 AᵀAx̂ = Aᵀb | 과결정 시스템의 최선 근사 |
| 체비쇼프 다항식 | 직교 다항식, 최적 절점 | 룽게 현상 방지하는 보간 절점 |
| 푸리에 급수 | 삼각함수 직교 분해 | 함수를 주파수 성분으로 분해 |
| 파르세발 등식 | ‖f‖² = Σ(aₙ²+bₙ²) | 시간 ↔ 주파수 영역 에너지 보존 |
| 깁스 현상 | 불연속점 9% 오버슈트 | 항 수 늘려도 사라지지 않음 |

**푸리에 급수:** f(x) = a₀/2 + Σ [aₙcos(nx) + bₙsin(nx)]

**계수 공식:**
- aₙ = (1/π) ∫_{-π}^{π} f(x)cos(nx) dx
- bₙ = (1/π) ∫_{-π}^{π} f(x)sin(nx) dx

**체비쇼프 절점 (룽게 현상 방지):** x_k = cos((2k−1)π / 2n)

## 제7부: 미분방정식의 수치적 해법

### 7.1 상미분방정식 초깃값 문제 (IVP)

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 오일러법 | y_{n+1} = y_n + hf | O(h) — 직관적이지만 너무 조악 |
| RK4 | 4번 평가 가중 평균 | O(h⁴) — 실용 IVP의 표준 |
| ABM 다단계법 | 예측-수정 (PC) | 함수 평가 절감, O(h⁴) |
| 강성 시스템 | 빠름+느린 성분 공존 | 암시적 방법 필수 |

**RK4 공식:**
```
k₁ = f(tₙ, yₙ)
k₂ = f(tₙ + h/2, yₙ + h/2·k₁)
k₃ = f(tₙ + h/2, yₙ + h/2·k₂)
k₄ = f(tₙ + h,   yₙ + h·k₃)
yₙ₊₁ = yₙ + h/6·(k₁ + 2k₂ + 2k₃ + k₄)
```

**직관:** k₁은 시작, k₂·k₃는 중간 보정, k₄는 끝점 기울기 — 심프슨 공식의 ODE 버전

**강성 시스템 해결:** 역방향 오일러법 (암시적) — 매 스텝마다 비선형 방정식 풀기, 큰 스텝 허용

### 7.2 경계값 문제 (BVP)

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 사격법 | IVP + 뉴턴법 | BVP → 초기 기울기 반복 탐색 |
| 유한차분법 (BVP) | 차분 → 3중 대각 | O(n) 풀이 가능 |

**사격법:** F(s) = y(b; s) − β = 0 → 뉴턴법으로 초기 기울기 s* 탐색

**유한차분 공식:** y″(xᵢ) ≈ (yᵢ₋₁ − 2yᵢ + yᵢ₊₁) / h²

### 7.3 편미분방정식 입문 (PDE)

| 유형 | 방정식 | 특성 | 응용 |
|---|---|---|---|
| 포물형 | uₜ = α uₓₓ | 시간 전진, 확산 | 열전도, 금융공학 |
| 쌍곡형 | uₜₜ = c² uₓₓ | 파동 전파 | 음파, 지진파 |
| 타원형 | uₓₓ + uyy = f | 정상 상태 | 정전기장, 유체역학 |

**수치 해법 핵심:**

| 주제 | 핵심 개념 | 한 줄 요약 |
|---|---|---|
| 열방정식 (포물형) | 시간 전진 확산 | CFL: r ≤ 1/2 위반하면 폭발 |
| 파동방정식 (쌍곡형) | 파동 전파 | CFL: cΔt/Δx ≤ 1 |
| 라플라스/포아송 (타원형) | 정상 상태 | 5점 스텐실 → 대형 희소 연립방정식 |
| Crank-Nicolson | 시간 평균 암시적 | 무조건 안정 — 실용 열방정식 표준 |

**CFL 안정 조건 (열방정식):** r = αΔt/Δx² ≤ 1/2 → 위반 시 수치 해 폭발

**5점 스텐실 (타원형):**
```
          uᵢ,ⱼ₊₁
            |
uᵢ₋₁,ⱼ — uᵢ,ⱼ — uᵢ₊₁,ⱼ
            |
          uᵢ,ⱼ₋₁
```

## 핵심 공식 모음

### 수렴 판정

```
ε-N:   ∀ε>0, ∃N, n>N ⟹ |aₙ − L| < ε
ε-δ:   ∀ε>0, ∃δ>0, 0<|x−a|<δ ⟹ |f(x)−L| < ε
코시:  ∀ε>0, ∃N, m,n>N ⟹ |aₘ − aₙ| < ε
```

### 주요 정리

```
MVT:       f′(c) = (f(b)−f(a)) / (b−a),  c ∈ (a,b)
FTC-1:     d/dx ∫_a^x f(t)dt = f(x)
FTC-2:     ∫_a^b f(x)dx = F(b) − F(a)
IVT:       f 연속, f(a)<c<f(b) ⟹ ∃ξ∈(a,b), f(ξ)=c
파르세발:  (1/π)∫|f|² = a₀²/2 + Σ(aₙ²+bₙ²)
```

### 수치 미분

```
전진차분:  f′(x) ≈ (f(x+h) − f(x)) / h                  O(h)
중앙차분:  f′(x) ≈ (f(x+h) − f(x−h)) / 2h               O(h²)
2계 차분:  f″(x) ≈ (f(x+h) − 2f(x) + f(x−h)) / h²      O(h²)
리처드슨:  f′(x) ≈ (4D(h/2) − D(h)) / 3                  O(h⁴)
```
