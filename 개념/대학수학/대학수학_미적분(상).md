## PART 1. 함수의 극한과 연속

> 미적분 전체의 토대. 미분·적분 모두 극한 위에 세워져 있습니다.

### 1-1. 함수의 극한

**극한의 본질**

`lim_{x→a} f(x) = L` 이란, x가 a에 한없이 가까워질 때 f(x)가 L에 한없이 가까워진다는 뜻.  
핵심: **x = a에서의 값은 무관** (f(a)가 정의 안 되거나 f(a) ≠ L이어도 극한값은 L일 수 있음)

**좌극한 · 우극한**

| 종류 | 표기 | 의미 |
|---|---|---|
| 좌극한 | `lim_{x→a⁻} f(x)` | x가 a보다 작은 쪽에서 접근 |
| 우극한 | `lim_{x→a⁺} f(x)` | x가 a보다 큰 쪽에서 접근 |

> **극한이 존재하려면** 좌극한 = 우극한이어야 함

**극한의 4가지 기본 성질** (f, g의 극한이 존재할 때)

```
lim [f(x) ± g(x)] = lim f(x) ± lim g(x)
lim [f(x) · g(x)] = lim f(x) · lim g(x)
lim [f(x) / g(x)] = lim f(x) / lim g(x)  (분모 ≠ 0)
lim c·f(x)        = c · lim f(x)
```

**자주 나오는 극한 계산 기법**

| 상황 | 기법 |
|---|---|
| 분수형 0/0 | 인수분해 → 약분 |
| 무리식 | 유리화 (켤레 곱) |
| x→∞ 다항식 | 최고차항으로 나누기 |
| 삼각함수 | `lim_{x→0} sin x / x = 1` 활용 |

---

### 1-2. 함수의 연속

**연속의 3조건** (x = a에서 연속이려면)

1. `f(a)` 가 정의되어야 함
2. `lim f(x)` 가 존재해야 함
3. `lim f(x) = f(a)` 이어야 함

> 핵심 기억법: "극한값 = 함수값" 하나로 외우면 나머지는 자동 성립

**불연속의 3가지 유형**

| 유형 | 특징 | 예시 |
|---|---|---|
| ① 제거 가능 불연속 | 극한 존재, 하지만 f(a) ≠ 극한값 | 구멍 뚫린 그래프 |
| ② 점프 불연속 | 좌극한 ≠ 우극한 | 계단 함수 |
| ③ 무한 불연속 | 극한값이 ∞ | 수직점근선 |

**중요 정리**

- **최대·최소 정리**: 닫힌 구간 [a,b]에서 연속이면 반드시 최댓값·최솟값 존재
- **사잇값 정리**: 연속 함수가 두 값 사이의 모든 값을 취함

## PART 2. 미분법

> 7절 구성. 도함수 → 고계 → 매개·역함수·음함수 → 접선 → 근사 순서로 흘러요.

### 2-1. 도함수와 미분

**도함수의 정의** (할선의 기울기를 h→0 극한으로 날카롭게)

```
f'(x) = lim_{h→0} [f(x+h) - f(x)] / h
       = x에서의 순간변화율 = 곡선 위 점의 접선 기울기
```

**미분 가능 조건**
- 좌미분 = 우미분이어야 함
- 불연속점, 뾰족점 → 미분 불가
- **미분 가능 → 반드시 연속** (역은 성립하지 않음)

**핵심 미분 공식**

| 함수 | 도함수 |
|---|---|
| `xⁿ` | `nxⁿ⁻¹` |
| `eˣ` | `eˣ` |
| `aˣ` | `aˣ · ln a` |
| `ln x` | `1/x` |
| `sin x` | `cos x` |
| `cos x` | `-sin x` |
| `tan x` | `sec²x` |
| `f·g` | `f'g + fg'` (곱의 미분) |
| `f/g` | `(f'g - fg') / g²` (몫의 미분) |

**연쇄법칙 (chain rule)**

```
[f(g(x))]' = f'(g(x)) · g'(x)
예) (sin(x²))' = cos(x²) · 2x
```

---

### 2-2. 고계도함수

**표기법**

| 차수 | 표기 | 물리 의미 |
|---|---|---|
| 1차 | `f'(x) = dy/dx` | 속도 |
| 2차 | `f''(x) = d²y/dx²` | 가속도 |
| n차 | `f⁽ⁿ⁾(x) = dⁿy/dxⁿ` | - |

**주요 패턴**

```
(xⁿ)⁽ᵏ⁾ = n(n-1)···(n-k+1)·xⁿ⁻ᵏ
(eˣ)⁽ⁿ⁾ = eˣ
(sin x)⁽⁴⁾ = sin x  ← 주기 4
```

---

### 2-3. 매개방정식의 미분

x = f(t), y = g(t) 로 주어질 때:

```
dy/dx = (dy/dt) / (dx/dt) = g'(t) / f'(t)

2차 미분:
d²y/dx² = [d(dy/dx)/dt] / (dx/dt)
```

---

### 2-4. 역함수의 미분

y = f(x)와 y = f⁻¹(x)의 기울기는 역수 관계:

```
(f⁻¹)'(b) = 1 / f'(a)     (단, b = f(a))
```

기하학적 의미: y=f(x)와 y=f⁻¹(x)는 y=x에 대해 대칭 → 접선도 기울기 역수

---

### 2-5. 음함수의 미분

F(x, y) = 0 꼴에서 y를 직접 풀기 어려울 때 사용

**절차**
1. F(x, y) = 0 양변을 x로 미분
2. y가 나올 때마다 dy/dx를 곱함 (연쇄법칙)
3. dy/dx에 대해 정리

**예) 원 x² + y² = r²**

```
2x + 2y·(dy/dx) = 0
dy/dx = -x/y
```

---

### 2-6. 접선의 방정식

```
점 (a, f(a))에서의 접선:
y - f(a) = f'(a)(x - a)

법선 (접선에 수직):
y - f(a) = -1/f'(a) · (x - a)  (f'(a) ≠ 0)
```

---

### 2-7. 근사식 (선형 근사)

```
f(x) ≈ f(a) + f'(a)(x - a)    (x가 a에 충분히 가까울 때)
```

**x ≈ 0 에서 자주 쓰는 근사식**

| 함수 | 근사 |
|---|---|
| `(1+x)ⁿ` | `1 + nx` |
| `sin x` | `x` |
| `cos x` | `1` |
| `eˣ` | `1 + x` |
| `ln(1+x)` | `x` |

## PART 3. 미분의 활용

> 9절 구성. 증감 분석 → 극값·최적화 → 방정식/부등식 → 이론 정리 → 심화 응용

### 그래프 분석 4단계 흐름 (핵심!)

```
f'(x) 구하기 → 증감표 작성 (3-1)
       ↓
극대·극소 찾기 (3-2) ←→ f''(x) 구하기 → 오목·볼록, 변곡점 (3-7)
       ↓
[a,b]에서 최대·최솟값 (3-3)
```

---

### 3-1. 함수의 증가와 감소

```
구간 (α, β)에서
  f'(x) > 0  →  순증가
  f'(x) < 0  →  순감소
  f'(x) = 0  →  정류점 (극값이 아닐 수 있음, 예: y=x³)
```

**증감표 작성 순서**
1. f'(x) = 0이 되는 x 찾기
2. 구간별 f'(x) 부호 조사
3. f(x) 증감 기입

---

### 3-2. 함수의 극대와 극소

**극값 판별법 ①  1차 도함수 검정**

| f' 부호 변화 | 판정 |
|---|---|
| `+ → -` | 극대 |
| `- → +` | 극소 |
| 부호 불변 | 극값 없음 (변곡점) |

**극값 판별법 ②  2차 도함수 검정** (f'(a) = 0일 때)

| f''(a) | 판정 |
|---|---|
| `f''(a) < 0` | 극대 (위로 볼록) |
| `f''(a) > 0` | 극소 (아래로 볼록) |
| `f''(a) = 0` | 불확정 → 1차 검정 사용 |

---

### 3-3. 함수의 최대와 최소

**닫힌 구간 [a, b]에서**
1. 내부에서 f'(x) = 0 되는 점의 함수값
2. 끝점 f(a), f(b)
3. 위 모든 값 중 최대·최솟값 선택

> 닫힌 구간 + 연속 → 최대·최소 반드시 존재 (최대·최소 정리)

---

### 3-4. 방정식 & 부등식과 미분

**핵심 전략**: f(x) = k의 실근 개수 → 그래프와 y = k의 교점 개수

```
k > 극대값       → 교점 1개
k = 극대값       → 교점 2개 (접함)
극소값 < k < 극대값 → 교점 3개
k = 극소값       → 교점 2개 (접함)
k < 극소값       → 교점 0개
```

---

### 3-5. 중간값의 정리 (IVT)

f가 [a,b]에서 **연속**이고 f(a) ≠ f(b)이면,  
f(a)와 f(b) 사이 임의의 값 k에 대해 **f(c) = k인 c ∈ (a,b)가 존재**

**핵심 응용**: `f(a)·f(b) < 0` 이면 (a, b)에 실근 존재

> 주의: 존재성만 보장, 개수·위치는 모름

---

### 3-6. 평균값의 정리 (MVT)

f가 [a,b]에서 연속, (a,b)에서 미분 가능이면:

```
f'(c) = [f(b) - f(a)] / (b - a)  인 c ∈ (a,b) 존재
```

즉, **할선과 평행한 접선이 내부에 반드시 존재**

- **롤의 정리**: f(a) = f(b)이면 f'(c) = 0인 c 존재 (평균값 정리의 특수 경우)

| | 중간값 정리 | 평균값 정리 |
|---|---|---|
| 조건 | 연속 | 연속 + 미분 가능 |
| 결론 | 함수값이 사이 값 통과 | f'(c) = 평균변화율인 점 존재 |

---

### 3-7. 곡선의 요철

```
f''(x) < 0  →  위로 볼록
f''(x) > 0  →  아래로 볼록

변곡점: f''(c) = 0이고 f'' 부호가 바뀌는 점
(f''=0이라도 변곡점 아닐 수 있음, 예: y=x⁴)
```

---

### 3-8. 변화율의 응용 (관련 변화율)

두 양이 시간 t에 따라 함께 변할 때:

```
dy/dt = f'(x) · dx/dt  (연쇄법칙)
```

**풀이 절차**
1. 관련 변수 설정
2. 기하적 관계식 수립
3. 양변을 t에 대해 미분
4. 주어진 순간의 값 대입

---

### 3-9. 평면곡선의 곡률

```
κ = |f''(x)| / (1 + f'(x)²)^(3/2)

곡률반지름: R = 1/κ
직선: κ = 0  |  원: κ = 1/R (일정)
```

## PART 4. 적분법

> 5절 구성. 부정적분 → 정적분 → 급수 연결 → 함수 표현 → 무한 구간 확장

### 4-1. 부정적분

```
∫f(x)dx = F(x) + C    (F'(x) = f(x), C는 적분상수)
```

**핵심 공식**

| 함수 | 부정적분 |
|---|---|
| `xⁿ` | `xⁿ⁺¹/(n+1) + C` |
| `eˣ` | `eˣ + C` |
| `aˣ` | `aˣ/ln a + C` |
| `1/x` | `ln\|x\| + C` |
| `sin x` | `-cos x + C` |
| `cos x` | `sin x + C` |
| `sec²x` | `tan x + C` |
| `1/√(1-x²)` | `arcsin x + C` |
| `1/(1+x²)` | `arctan x + C` |

**3대 적분 기법**

| 기법 | 공식 | 언제? |
|---|---|---|
| 치환적분 | `u = g(x)` 놓고 변수 변환 | 합성함수 꼴 |
| 부분적분 | `∫uv' = uv - ∫u'v` | 곱 형태 (LIATE 순서) |
| 부분분수 | 분모 인수분해 후 분리 | 유리함수 분모 |

> **LIATE 순서**: Logarithm → Inverse trig → Algebraic → Trig → Exponential

---

### 4-2. 정적분

**미적분학 기본정리**

```
F'(x) = f(x) 이면:
∫ᵃᵇ f(x)dx = F(b) - F(a)
```

**주요 성질**

```
∫ᵃᵃ f dx = 0
∫ᵃᵇ f dx = -∫ᵇᵃ f dx
∫ᵃᵇ f dx = ∫ᵃᶜ f dx + ∫ᶜᵇ f dx  (구간 분할)
```

**우함수·기함수 공식**

```
f(-x) = f(x)  (우함수):  ∫₋ₐᵃ f dx = 2∫₀ᵃ f dx
f(-x) = -f(x) (기함수):  ∫₋ₐᵃ f dx = 0
```

> 음의 넓이 주의: f(x) < 0인 구간에서 정적분은 음수. 실제 넓이는 |f(x)|로 적분

---

### 4-3. 무한급수와 정적분

**리만합 → 정적분 변환**

```
lim_{n→∞} Σᵢ₌₁ⁿ f(a + i·(b-a)/n) · (b-a)/n  =  ∫ᵃᵇ f(x) dx
```

**시험 포인트**: `1/n = dx`, `k/n = x`로 치환

```
예) lim(1/n) Σf(k/n)  →  ∫₀¹ f(x) dx
```

---

### 4-4. 정적분으로 표현된 함수

```
G(x) = ∫ₐˣ f(t) dt  로 정의하면

기본형:       d/dx ∫ₐˣ f(t)dt = f(x)
상한이 g(x):  d/dx ∫ₐᵍ⁽ˣ⁾ f(t)dt = f(g(x))·g'(x)
하한이 x:     d/dx ∫ₓᵃ f(t)dt = -f(x)  ← 부호 반대!
```

---

### 4-5. 특이적분

**유형 1 — 무한 구간**

```
∫ₐ^∞ f(x)dx = lim_{b→∞} ∫ₐᵇ f(x)dx
```

**유형 2 — 불연속점 포함**

```
f가 x=b에서 불연속이면:
∫ₐᵇ f(x)dx = lim_{t→b⁻} ∫ₐᵗ f(x)dx
```

**p-급수 판정 (자주 나옴)**

```
∫₁^∞ 1/xᵖ dx   →   p > 1 이면 수렴 (= 1/(p-1))
                     p ≤ 1 이면 발산
```

## PART 5. 적분의 활용

> 7절 구성. 같은 뼈대 "미소 조각 → 적분"으로 넓이·길이·부피·표면적·물리량 계산

### 핵심 공식 패밀리

| 측정 대상 | 미소 조각 | 적분 공식 |
|---|---|---|
| 넓이 | `dA = \|f-g\| dx` | `∫ₐᵇ \|f(x)-g(x)\| dx` |
| 곡선 길이 | `ds = √(1+f'²) dx` | `∫ₐᵇ √(1+f'(x)²) dx` |
| 부피 (원판) | `dV = πr² dx` | `π∫ₐᵇ f(x)² dx` |
| 표면적 | `dS = 2πr·ds` | `2π∫ₐᵇ f(x)·√(1+f'²) dx` |

---

### 5-1. 적분과 넓이

```
두 곡선 사이 넓이:
S = ∫ₐᵇ |f(x) - g(x)| dx

교차하는 경우 → 교점 먼저 구하고 구간 나눠서 계산
y방향 적분이 편한 경우:
S = ∫ₒᵈ [r(y) - l(y)] dy
```

---

### 5-2. 적분의 평균값 정리

f가 [a,b]에서 연속이면:

```
평균값  f̄ = 1/(b-a) · ∫ᵃᵇ f(x)dx

f(c) = f̄ 인 c ∈ (a,b) 반드시 존재
```

---

### 5-3. 정적분의 근사

**사다리꼴 공식** (오차 ∝ h²)

```
T = h/2 · [y₀ + 2y₁ + 2y₂ + ··· + 2yₙ₋₁ + yₙ]
h = (b-a)/n
```

**심프슨 공식** (오차 ∝ h⁴, n은 짝수여야 함)

```
S = h/3 · [y₀ + 4y₁ + 2y₂ + 4y₃ + ··· + 4yₙ₋₁ + yₙ]
```

> 심프슨이 사다리꼴보다 훨씬 정확 (수치해석 라이브러리 내부에서 실제 사용)

---

### 5-4. 곡선의 길이

```
y = f(x) 형태:
L = ∫ₐᵇ √(1 + f'(x)²) dx

매개변수 x=f(t), y=g(t):
L = ∫ₐᵇ √(x'² + y'²) dt

극좌표 r=f(θ):
L = ∫ₐᵇ √(r² + (dr/dθ)²) dθ
```

---

### 5-5. 부피와 정적분

**원판법 (Disk Method)**

```
V = π∫ₐᵇ [f(x)]² dx
(원판 넓이 πr²을 x방향으로 쌓기)
```

**껍질법 (Shell Method)**

```
V = 2π∫ₐᵇ x·f(x) dx
(원통 옆면 2πrh를 쌓기)
```

**와셔법 (구멍 뚫린 회전체)**

```
V = π∫ₐᵇ [f(x)² - g(x)²] dx
```

---

### 5-6. 회전체의 표면적

```
x축 회전 (y=f(x)):
S = 2π∫ₐᵇ f(x)·√(1+f'(x)²) dx

y축 회전 (x=g(y)):
S = 2π∫ₐᵇ x·√(1+(dx/dy)²) dy

구조: S = ∫ 2π·(회전반지름)·ds
```

> 구의 표면적 4πr²도 이 공식으로 유도 가능 (반원을 x축 회전)

---

### 5-7. 실생활 응용

**물리 — 일 (Work)**

```
W = ∫ₐᵇ F(x) dx    (F(x)는 위치에 따른 힘)
스프링: W = ∫₀ˣ kx dx = kx²/2  (훅의 법칙)
```

**유체 — 수압력**

```
수압력 = ∫ ρg·h·w(h) dh
(ρ: 유체 밀도, h: 깊이, w(h): 깊이 h에서의 폭)
```

**무게중심 (Centroid)**

```
x̄ = (1/A) ∫ₐᵇ x·f(x) dx
ȳ = (1/A) ∫ₐᵇ f(x)²/2 dx
```

**경제학 — 소비자·생산자 잉여**

```
소비자 잉여: CS = ∫₀^q* [D(q) - P*] dq
생산자 잉여: PS = ∫₀^q* [P* - S(q)] dq
```

## 부록 (심화탐구)

### 부록 1. ε-δ 논법과 함수의 극한 (객관식 시험 전용)

**엡실론-델타 정의**

```
lim_{x→a} f(x) = L 의 엄밀한 정의:

∀ε > 0, ∃δ > 0  s.t.
0 < |x - a| < δ  ⟹  |f(x) - L| < ε
```

읽는 법:
- `∀ε > 0` : "어떤 ε을 줘도 (아무리 작아도)"
- `∃δ > 0` : "그에 맞는 δ가 존재해서"
- `0<|x-a|<δ` : "x가 a의 δ-근방에 있으면 (x≠a)"
- `|f(x)-L|<ε` : "f(x)가 L의 ε-근방에 들어온다"

**시험 전략 — ε-δ 증명 3단계**

1. `|f(x)-L|`을 `|x-a|`의 식으로 정리
2. `|f(x)-L| < ε`이 되도록 δ를 ε으로 표현해 설정
3. `0<|x-a|<δ` 가정 하에 `|f(x)-L|<ε` 성립 확인

**예제: `lim_{x→2} (3x-1) = 5` 증명**

```
|f(x)-L| = |(3x-1)-5| = |3x-6| = 3|x-2|

3|x-2| < ε  이 되려면  |x-2| < ε/3

∴ δ = ε/3 으로 설정

검증: 0<|x-2|<δ=ε/3 이면
|f(x)-5| = 3|x-2| < 3·(ε/3) = ε  ✓
```

### 부록 2. 합성함수의 극한과 연속

**핵심 정리**

`lim_{x→a} f(g(x)) = f(lim_{x→a} g(x)) = f(m)` 이 성립하려면:

1. `lim_{x→a} g(x) = m` 이 존재하고
2. **f가 t = m에서 연속**이면 → 항상 성립
3. 또는 x ≠ a인 a의 근방에서 g(x) ≠ m이면 → 성립

**반례 — 성립하지 않는 경우**

```
g(x) = 0 (상수),  f(t) = { 1 (t=0), 0 (t≠0) }

lim g(x) = 0,  f(0) = 1
f(g(x)) = f(0) = 1  →  극한값 계산 불가

이유: f가 t=0에서 불연속 → 극한값 교환 불가!
```

> "연속 함수의 합성은 연속"도 이 정리에서 바로 도출됩니다.

### 부록 3. 미적분학 명제탐구

#### 로피탈 정리 (L'Hôpital)

0/0 또는 ∞/∞ 꼴의 극한:

```
lim f(x)/g(x) = lim f'(x)/g'(x)
(단, lim f'/g' 이 존재할 때)
```

| 예제 | 풀이 |
|---|---|
| `lim_{x→0} sin x / x` | `lim cos x / 1 = 1` |
| `lim_{x→∞} x / eˣ` | `lim 1/eˣ = 0` |

> 주의: 0/∞ 같은 꼴은 변형 후 사용. 같은 꼴이 반복되면 반복 적용 가능.

---

#### 테일러 정리 (Taylor)

f가 n번 미분 가능할 때:

```
f(x) = Σ_{k=0}^{n} f⁽ᵏ⁾(a)/k! · (x-a)ᵏ + Rₙ
```

**매클로린 급수 (a=0) 주요 공식**

| 함수 | 급수 전개 |
|---|---|
| `eˣ` | `1 + x + x²/2! + x³/3! + ···` |
| `sin x` | `x - x³/3! + x⁵/5! - ···` |
| `cos x` | `1 - x²/2! + x⁴/4! - ···` |
| `ln(1+x)` | `x - x²/2 + x³/3 - ···` |
| `1/(1-x)` | `1 + x + x² + x³ + ···` |
| `(1+x)ⁿ` | `1 + nx + n(n-1)x²/2! + ···` |

> 테일러 급수는 PART 2-7 근사식(선형 근사)의 고차원 확장. 현대 수치해석·딥러닝 최적화 알고리즘의 핵심.
