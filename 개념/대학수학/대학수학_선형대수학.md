## PART 0. 기초상식

> 수학의 언어를 정립하는 단계. 선형대수 전체의 토대가 되는 개념들.

### 0-1. 집합과 명제

**핵심 개념:** 집합(Set), 원소(Element), 부분집합(Subset), 합집합·교집합·차집합·여집합, 명제(Proposition), 역·이·대우, 필요조건·충분조건

**요약:** 수학의 언어를 배우는 첫 걸음. 원소·부분집합·연산, 명제의 참/거짓 판별과 논리 구조.

**상세 설명**

- **집합이란?** 어떤 조건을 만족하는 대상들의 모임. 중학교 때 배웠지만 선형대수에서는 벡터공간·핵·상 같은 '집합' 개념이 핵심이므로 정확한 언어가 필요하다.

- **원소·부분집합** `a ∈ A` : 'a는 집합 A의 원소'. `A ⊆ B` : 'A의 모든 원소가 B에 속함'. 벡터공간의 부분공간(Subspace) 정의가 이 개념을 그대로 쓴다.

- **집합 연산** `A ∪ B` (합집합), `A ∩ B` (교집합), `A \ B` (차집합), `Aᶜ` (여집합). 드 모르간 법칙 : `(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ`

- **명제와 논리** 명제 `P → Q`에서 역(Q→P), 이(¬P→¬Q), 대우(¬Q→¬P). 대우는 원래 명제와 동치. 선형대수 증명에서 '대우를 이용한 증명'이 자주 등장한다.

- **필요·충분 조건** `P → Q` 이면 P는 Q의 충분조건, Q는 P의 필요조건. `P ↔ Q` 이면 필요충분조건(동치). 가역행렬의 동치조건들이 대표적 예시.

---

### 0-2. 연산

**핵심 개념:** 실수(ℝ)·복소수(ℂ), 체(Field), 교환·결합·분배 법칙, 항등원·역원, 시그마(Σ) 표기법

**요약:** 실수·복소수 체계와 사칙연산 성질. 선형대수 전체를 떠받치는 대수 구조의 토대.

**상세 설명**

- **실수와 복소수** ℝ = 실수 전체, ℂ = 복소수 전체 (a + bi 형태). 선형대수는 주로 ℝ 위에서 전개되지만, 고유치 계산 시 ℂ로 확장이 필요하다.

- **체(Field)의 개념** 덧셈·곱셈이 잘 정의되고, 결합·교환·분배·항등원·역원이 모두 성립하는 집합. ℝ과 ℂ가 대표적인 체. 벡터공간은 반드시 체 위에서 정의된다.

- **시그마 표기법** `∑ᵢ₌₁ⁿ aᵢ = a₁ + a₂ + ⋯ + aₙ`. 행렬 곱, 내적, 선형결합 등의 정의가 모두 Σ로 쓰이므로 익숙해져야 한다.

---

### 0-3. 연립방정식

**핵심 개념:** 선형방정식, 연립일차방정식, 첨가행렬(Augmented Matrix), 가우스 소거법, 해의 존재·유일성

**요약:** 여러 미지수를 동시에 구하는 방정식 시스템. 선형대수의 출발점이자 핵심 응용.

**상세 설명**

- **선형방정식이란?** `a₁x₁ + a₂x₂ + ⋯ + aₙxₙ = b` 꼴. 미지수가 1차(선형)인 방정식. 비선형(x², sin x 등)은 선형대수의 범위 밖이다.

- **연립일차방정식** m개 방정식, n개 미지수. 행렬로 쓰면 `Ax = b`. 해가 없거나(불능), 하나이거나(유일해), 무한히 많을(부정) 수 있다.

- **가우스 소거법** 첨가행렬 `[A|b]`를 행 기본 연산으로 '사다리꼴' 형태로 만들어 역대입으로 해를 구하는 방법. 선형대수에서 가장 중요한 알고리즘 중 하나.

- **해의 존재·유일성**
  - `rank(A) = rank([A|b]) = n` → 유일해
  - `rank(A) = rank([A|b]) < n` → 무한해 (자유변수 존재)
  - `rank(A) ≠ rank([A|b])` → 해 없음 (불능)

---

### 0-4. 사상

**핵심 개념:** 사상(Mapping)·함수(Function), 정의역·공역·치역, 단사(Injective), 전사(Surjective), 전단사·역사상

**요약:** 집합 간의 대응 규칙. 함수의 일반화로, 선형사상(5장)의 토대.

**상세 설명**

- **사상이란?** `f : A → B`. 집합 A의 각 원소에 B의 원소를 정확히 하나씩 대응시키는 규칙. 함수는 수→수이지만, 사상은 벡터→벡터도 된다.

- **단사(Injective)** 서로 다른 입력은 서로 다른 출력. 즉 `f(x)=f(y) ⟹ x=y`. '일대일 함수'. 선형사상에서는 핵(Kernel)이 {0}인 것과 동치.

- **전사(Surjective)** 모든 `b ∈ B`에 대해 `f(a)=b`인 a가 존재. '위로의 함수'. 선형사상에서는 상(Image)이 공역 전체인 것과 동치.

- **전단사(Bijective)** 단사 + 전사. 역사상(역함수) f⁻¹이 존재. 가역행렬이 나타내는 선형사상이 바로 전단사 선형사상이다.

## PART I. 행렬

> 선형대수의 핵심 객체. 수를 직사각형으로 배열해 연립방정식·변환·데이터를 동시에 표현한다.

### 1-1. 행렬의 뜻

**핵심 개념:** 행렬(Matrix), 성분(Entry), m×n 행렬, 행(Row)·열(Column), 정방행렬(Square Matrix)

**요약:** 수를 직사각형으로 배열한 구조. 연립방정식, 변환, 데이터를 표현하는 핵심 도구.

**상세 설명**

- **행렬이란?** m행 n열로 수를 배열한 구조. `Aᵢⱼ`는 i번째 행, j번째 열의 성분. 행렬은 선형 변환·연립방정식·데이터를 동시에 표현하는 만능 도구.

- **행렬 표기** `A = [aᵢⱼ]ₘₓₙ`. 예: 2×3 행렬은 2행 3열, 총 6개 성분. 소프트웨어에서는 2D 배열(Array)과 완전히 대응된다.

- **정방행렬** 행의 수 = 열의 수 (m = n). 역행렬·행렬식·고유치는 정방행렬에서만 정의된다. 가장 중요한 특수 케이스.

---

### 1-2. 행렬의 꼴

**핵심 개념:** 영행렬(Zero Matrix), 단위행렬(Identity Matrix), 대각행렬(Diagonal), 상/하삼각행렬(Triangular), 대칭행렬(Symmetric), 전치행렬(Transpose)

**요약:** 용도에 따라 다양한 특수 형태의 행렬들. 각각 독특한 성질과 계산 이점이 있다.

**상세 설명**

- **영행렬·단위행렬** 영행렬 O: 모든 성분이 0. 단위행렬 I: 대각성분만 1, 나머지 0. `AI = IA = A`. 단위행렬은 행렬의 '1' 역할.

- **대각행렬** 대각 이외의 성분이 모두 0. 대각행렬끼리의 곱·역행렬 계산이 매우 쉽다. 고유치 분해의 결과로 대각행렬이 나타난다.

- **전치행렬** `Aᵀ`: 행과 열을 바꾼 행렬. `(AB)ᵀ = BᵀAᵀ`. 대칭행렬: `A = Aᵀ`. 반대칭행렬: `A = -Aᵀ`. 내적 계산과 최소제곱법의 핵심.

- **삼각행렬** 상삼각(Upper Triangular): 대각 아래가 0. 하삼각(Lower Triangular): 대각 위가 0. 가우스 소거의 결과물이 상삼각행렬이다.

---

### 1-3. 행렬의 연산

**핵심 개념:** 행렬 덧셈, 스칼라 곱, 행렬 곱(Matrix Multiplication), AB ≠ BA (비교환성), 거듭제곱 Aⁿ

**요약:** 행렬 덧셈, 스칼라 곱, 행렬 곱의 규칙. 특히 행렬 곱은 교환법칙이 성립하지 않는다!

**상세 설명**

- **덧셈·스칼라 곱** 같은 크기의 행렬끼리만 덧셈 가능 (성분별 덧셈). 스칼라 곱은 모든 성분에 상수 곱하기. 교환·결합·분배 법칙 성립.

- **행렬 곱** `(AB)ᵢⱼ = ∑ₖ Aᵢₖ Bₖⱼ`. A가 m×n, B가 n×p이면 AB는 m×p. 'A의 열 수 = B의 행 수'여야 한다. 내적의 배열 버전으로 이해하면 됩니다.

- **⚠️ 비교환성 AB ≠ BA** 일반적으로 AB ≠ BA! 행렬 곱은 순서가 중요하다. 이게 선형대수를 단순 산술과 구별 짓는 핵심 차이점. 딥러닝에서 레이어 순서가 중요한 이유도 여기서 기인한다.

- **결합·분배 법칙** `(AB)C = A(BC)` (결합 법칙 성립). `A(B+C) = AB + AC` (분배 법칙 성립). 교환 법칙만 일반적으로 불성립.

---

### 1-4. 여러가지 행렬

**핵심 개념:** 멱등행렬(Idempotent) A²=A, 대합행렬 A²=I, 정규행렬(Normal), 에르미트 행렬, 유니터리 행렬

**요약:** 실용에서 자주 쓰이는 특수 행렬들. 각각 독특한 대수적 성질을 가진다.

**상세 설명**

- **멱등행렬** `A² = A`. 대표 예시: 정사영 행렬(Projection Matrix). 한번 투영하면 다시 투영해도 변하지 않는다는 기하적 의미.

- **대합행렬** `A² = I`. 즉 `A⁻¹ = A`. 두 번 적용하면 항등변환이 되는 행렬. 거울 반사 변환이 대표적 예.

- **정규행렬** `AᵀA = AAᵀ` (실수) 또는 `A*A = AA*` (복소수). 대칭행렬·직교행렬·반대칭행렬 모두 정규행렬의 특수 경우.

---

### 1-5. 대각합과 행렬식

**핵심 개념:** 대각합(Trace) tr(A), 행렬식(Determinant) det(A), 사루스 법칙, 여인수 전개(Cofactor), 행렬식의 성질

**요약:** 행렬을 하나의 숫자로 요약하는 두 가지 방법. 고유치·가역성 판별의 핵심 도구.

**상세 설명**

- **대각합(Trace)** `tr(A) = a₁₁ + a₂₂ + ⋯ + aₙₙ`. 대각성분의 합. 중요 성질: `tr(AB) = tr(BA)`. 고유치의 합 = tr(A).

- **행렬식(Determinant)** 정방행렬 A를 하나의 수로 매핑. 2×2: `det = ad-bc`. 기하적으로는 열벡터들이 만드는 평행사변형(3D: 평행육면체)의 '부피'에 해당한다.

- **사루스 법칙 (3×3)** 3×3 행렬식 계산: 대각 방향 곱의 합 - 역대각 방향 곱의 합. 4×4 이상에서는 사용 불가 — 여인수 전개 사용.

- **여인수 전개** `det(A) = ∑ⱼ aᵢⱼ Cᵢⱼ`. 여인수 `Cᵢⱼ = (-1)^(i+j) Mᵢⱼ` (소행렬식). 행이나 열 하나를 선택해 재귀적으로 계산한다.

- **행렬식의 핵심 성질** `det(AB) = det(A)det(B)`. `det(Aᵀ) = det(A)`. 행 교환 → 부호 변환. 행이 선형 종속 → det = 0. **`det(A) ≠ 0 ↔ A가 가역행렬`**.

---

### 1-6. 역행렬

**핵심 개념:** 역행렬(Inverse) A⁻¹, 가역(Invertible)·특이(Singular), 역행렬 공식 (2×2), 가우스-조르단 소거법, 역행렬의 성질

**요약:** 행렬의 '나누기'. 가역행렬의 존재 조건과 계산법. 연립방정식 풀이의 이론적 기반.

**상세 설명**

- **역행렬이란?** `AA⁻¹ = A⁻¹A = I`를 만족하는 행렬 A⁻¹. 존재 조건: `det(A) ≠ 0` (가역행렬). 역행렬이 없으면 '특이행렬(Singular)'이라 한다.

- **2×2 역행렬 공식** `A = [[a,b],[c,d]] → A⁻¹ = 1/(ad-bc) × [[d,-b],[-c,a]]`. det(A) = ad-bc가 분모에 등장 — 0이면 역행렬 없음.

- **가우스-조르단 소거법** `[A|I]`를 행 연산으로 `[I|A⁻¹]`로 변환. 대규모 행렬의 역행렬을 구하는 실용적 알고리즘.

- **역행렬의 성질** `(AB)⁻¹ = B⁻¹A⁻¹` (순서 반전!). `(Aᵀ)⁻¹ = (A⁻¹)ᵀ`. `(A⁻¹)⁻¹ = A`. `det(A⁻¹) = 1/det(A)`.

---

### 1-7. 행렬과 연립일차방정식

**핵심 개념:** Ax = b 형태, 행 기본 연산(ERO), 행사다리꼴(REF), 기약행사다리꼴(RREF), rank와 해의 관계

**요약:** 연립방정식 Ax=b를 행렬로 풀기. 행 축약을 통한 체계적 풀이법.

**상세 설명**

- **행렬 방정식 Ax = b** n개 미지수 m개 방정식 → m×n 행렬 A, n×1 벡터 x, m×1 벡터 b. 가역이면 `x = A⁻¹b`로 유일해.

- **행 기본 연산 (ERO)** ① 행 교환 ② 행에 0이 아닌 상수 곱하기 ③ 한 행의 상수배를 다른 행에 더하기. 이 연산은 해를 바꾸지 않는다.

- **REF & RREF** REF(행사다리꼴): 각 행의 첫 번째 비영 성분(피벗)이 아래로 갈수록 오른쪽에 위치. RREF(기약 행사다리꼴): 피벗이 1이고 그 열의 다른 성분이 모두 0. RREF는 해를 직접 읽을 수 있다.

- **rank와 해** `rank(A)` = 피벗의 수 = 선형 독립인 행의 수. `rank(A) < n` → 자유변수 (n - rank개)가 생겨 무한해 가능. `rank(A) = n = m` → 유일해.

---

### 1-8. 최소제곱해

**핵심 개념:** 최소제곱해(Least Squares), 정규방정식 AᵀAx = Aᵀb, 기하적 의미 (정사영), 선형 회귀(Linear Regression)

**요약:** Ax=b에 해가 없을 때의 '최선의 근사'. 데이터 피팅·회귀분석의 수학적 토대.

**상세 설명**

- **왜 최소제곱해?** 실제 데이터는 노이즈가 있어 `Ax = b`의 정확한 해가 존재하지 않는 경우가 많다. 이때 `‖Ax - b‖²`를 최소화하는 x를 구하는 것이 최소제곱법.

- **정규방정식** `AᵀAx̂ = Aᵀb`. AᵀA가 가역이면 `x̂ = (AᵀA)⁻¹Aᵀb = A†b` (유사역행렬).

- **기하적 의미** Ax̂는 b를 열공간 Col(A)에 정사영(Projection)한 것. 즉 열공간에서 b에 가장 가까운 점. 오차벡터 `b - Ax̂`는 열공간과 수직.

- **선형 회귀 연결** n개 데이터 (xᵢ, yᵢ)를 직선 `y = ax + b`로 피팅 → 이것이 최소제곱법! 머신러닝의 선형 회귀가 정확히 정규방정식을 푸는 것이다.

---

## PART II. 벡터이론

> 크기와 방향을 가진 양. 물리적 직관을 수학적으로 정밀화하는 과정.

### 2-1. 벡터

**핵심 개념:** 벡터(Vector)·스칼라(Scalar), 기하벡터·위치벡터, 벡터의 상등, 영벡터, 벡터의 덧셈·스칼라 곱

**요약:** 크기와 방향을 동시에 갖는 양. 물리에서 출발해 수학적으로 추상화된 개념.

**상세 설명**

- **벡터란?** 크기(magnitude)와 방향(direction)을 모두 갖는 수학적 객체. 물리에서는 속도·힘·전기장 등. 수학에서는 ℝⁿ의 원소 (n개 실수의 순서쌍).

- **덧셈·스칼라 곱** `u + v`: 평행사변형 법칙. `cu`: 방향 유지(c>0), 방향 반전(c<0), 크기를 |c|배. 이 두 연산이 '벡터공간'의 핵심 구조.

- **단위벡터** 크기가 1인 벡터. `û = u/‖u‖`. 방향만 나타낼 때 사용. 표준 단위벡터: ℝ³에서 `i=(1,0,0)`, `j=(0,1,0)`, `k=(0,0,1)`.

---

### 2-2. 벡터의 성분

**핵심 개념:** 성분 표현 (x, y, z), 크기(Norm) ‖v‖, 방향코사인, 표준기저벡터 i, j, k

**요약:** 벡터를 좌표계로 표현하는 방법. 기저벡터로의 분해.

**상세 설명**

- **성분 표현** `v = (v₁, v₂, v₃) = v₁i + v₂j + v₃k`. 각 성분은 각 축 방향으로의 투영량.

- **크기(Norm)** `‖v‖ = √(v₁² + v₂² + v₃²)`. 피타고라스 정리의 3D 버전. n차원: `‖v‖ = √(∑vᵢ²)`.

- **방향코사인** `cos α = v₁/‖v‖`, `cos β = v₂/‖v‖`, `cos γ = v₃/‖v‖`. `cos²α + cos²β + cos²γ = 1`.

---

### 2-3. 벡터의 내적

**핵심 개념:** 내적(Dot Product) u·v, 내적의 기하적 의미 (cosθ), 직교(Orthogonal) u·v=0, 코시-슈바르츠 부등식

**요약:** 두 벡터를 하나의 스칼라로 만드는 연산. 각도·투영·직교성의 언어.

**상세 설명**

- **내적 정의** `u·v = ∑uᵢvᵢ = u₁v₁ + u₂v₂ + u₃v₃`. 결과가 스칼라(수). 행렬로는 `uᵀv`. 대칭성: `u·v = v·u`.

- **기하적 의미** `u·v = ‖u‖‖v‖cosθ`. θ는 두 벡터 사이의 각. `cosθ = (u·v)/(‖u‖‖v‖)`으로 각도 계산 가능.

- **직교성** `u·v = 0 ↔ u ⊥ v` (두 벡터가 수직). 직교 개념은 3D 공간을 넘어 함수 공간에서도 일반화된다.

- **코시-슈바르츠 부등식** `|u·v| ≤ ‖u‖‖v‖`. 수학 전반에서 가장 중요한 부등식 중 하나. 삼각부등식 `‖u+v‖ ≤ ‖u‖+‖v‖`의 증명에 쓰인다.

---

### 2-4. 벡터의 외적

**핵심 개념:** 외적(Cross Product) u×v, 행렬식을 이용한 계산, 우수법칙, u×v ⊥ u, v, 넓이·부피 계산

**요약:** 3차원에서만 정의되는 벡터 곱. 결과가 스칼라가 아닌 벡터이며 법선벡터 계산에 필수.

**상세 설명**

- **외적 정의** `u×v = det([[i,j,k],[u₁,u₂,u₃],[v₁,v₂,v₃]])`. 결과가 벡터! 3D에서만 정의된다.

- **기하적 의미** `u×v`는 u와 v 모두에 수직인 벡터. 크기 `‖u×v‖ = ‖u‖‖v‖sinθ` = 평행사변형의 넓이. 방향은 우수법칙(오른손 법칙).

- **반교환성** `u×v = -(v×u)`. 내적(교환 가능)과 달리 외적은 순서 바꾸면 부호 반전!

- **스칼라 삼중곱** `u·(v×w) = det([u,v,w])` = 세 벡터가 만드는 평행육면체의 부피. = 0이면 세 벡터가 같은 평면에 존재 (선형 종속).

---

### 2-5. 벡터의 영역

**핵심 개념:** 선형결합(Linear Combination), 생성집합(Span), 선형 독립(Linearly Independent), 선형 종속(Linearly Dependent)

**요약:** 벡터들의 선형결합으로 도달할 수 있는 공간. Span의 개념.

**상세 설명**

- **선형결합** `c₁v₁ + c₂v₂ + ⋯ + cₖvₖ` (스칼라 cᵢ는 임의). 벡터들의 '가중 합'. 딥러닝의 완전연결층 계산이 바로 선형결합이다.

- **Span (생성)** `Span{v₁,...,vₖ}` = {모든 선형결합의 집합}. ℝ³에서 벡터 1개 → 직선, 2개 (비평행) → 평면, 3개 (선형독립) → ℝ³ 전체.

- **선형 독립** `c₁v₁+⋯+cₖvₖ=0 → 모든 cᵢ=0`. 즉 어느 벡터도 나머지들의 선형결합으로 표현 불가. 기저(Basis)가 되는 필수 조건.

- **선형 종속** 어느 하나가 나머지들의 선형결합으로 표현 가능. **행렬의 열이 선형 종속 ↔ det = 0 ↔ 역행렬 없음**. 정보의 중복이 있다는 의미.

---

### 2-6. 평면의 방정식

**핵심 개념:** 법선벡터(Normal Vector), 평면의 방정식 ax+by+cz=d, 세 점으로 평면 결정, 점과 평면의 거리

**요약:** 3차원 공간에서 평면을 결정하는 방정식. 법선벡터가 핵심.

**상세 설명**

- **법선벡터** 평면에 수직인 벡터 `n = (a,b,c)`. 평면 위의 한 점 P₀와 법선벡터 n이 있으면 평면이 유일하게 결정된다.

- **평면의 방정식** `n·(r - r₀) = 0 → ax + by + cz = d`. 법선벡터의 성분이 방정식 계수.

- **점과 평면의 거리** 점 `Q = (x₁,y₁,z₁)`에서 평면 `ax+by+cz=d`까지의 거리 = `|ax₁+by₁+cz₁-d| / √(a²+b²+c²)`.

---

### 2-7. 공간직선의 방정식

**핵심 개념:** 벡터 방정식 r = r₀+tv, 매개변수 방정식, 대칭 방정식, 두 직선의 관계

**요약:** 3차원 공간에서 직선을 표현하는 다양한 방법.

**상세 설명**

- **벡터 방정식** `r = r₀ + tv`. r₀는 직선 위의 한 점, v는 방향벡터, t는 매개변수(∈ℝ). 컴퓨터 그래픽스에서 광선(Ray)을 이 방식으로 표현한다.

- **매개변수 방정식** `x = x₀+at`, `y = y₀+bt`, `z = z₀+ct`. t 범위를 제한하면 선분이 된다.

- **두 직선의 관계** 평행(방향벡터가 평행), 교차(한 점 공유), 꼬인 위치(3D에서 만나지도 평행하지도 않음). 꼬인 위치는 3D에서만 나타난다.

---

## PART III. 벡터공간

> 덧셈과 스칼라 곱이 정의된 추상 공간. ℝⁿ을 넘어 다항식·함수·행렬도 벡터공간이 된다.

### 3-1. 벡터공간

**핵심 개념:** 벡터공간(Vector Space) 정의, 8가지 공리, 부분공간(Subspace), 부분공간 판별 조건 (3가지)

**요약:** 덧셈과 스칼라 곱이 정의된 공간. ℝⁿ을 넘어 함수·행렬·다항식도 벡터공간이 된다.

**상세 설명**

- **벡터공간 정의** 집합 V에 덧셈(+)과 스칼라 곱(·)이 정의되고 8가지 공리(닫힘, 결합, 교환, 항등원, 역원, 분배 등)를 만족하면 벡터공간. ℝⁿ뿐 아니라 다항식 집합 Pₙ, 함수 집합, 행렬 집합도 벡터공간.

- **부분공간(Subspace)** 벡터공간 V의 부분집합 W가 V의 벡터공간 구조를 물려받은 것. 판별 조건: ① 영벡터 포함 ② 덧셈에 닫힘 ③ 스칼라 곱에 닫힘. 이 3가지만 확인하면 된다.

- **중요한 부분공간** 행렬 A의 열공간 Col(A), 행공간 Row(A), 영공간 Null(A)이 대표적 부분공간. 각각 Ax=b의 해 구조를 설명한다.

---

### 3-2. 벡터공간의 기저와 차원

**핵심 개념:** 기저(Basis), 차원(Dimension), 표준기저, 좌표벡터, 기저 변환

**요약:** 공간을 최소로 생성하는 선형독립 집합. 차원은 공간의 '자유도'.

**상세 설명**

- **기저(Basis)** 벡터공간 V의 기저: ① Span이 V 전체 ② 선형 독립. 모든 `v ∈ V`는 기저의 선형결합으로 유일하게 표현된다. 좌표 시스템의 수학적 정의.

- **차원(Dimension)** `dim(V)` = 기저를 이루는 벡터의 수. 모든 기저는 같은 개수의 벡터로 구성된다. ℝⁿ의 차원은 n, Mₙ의 차원은 n².

- **좌표벡터** 기저 `B = {b₁,...,bₙ}`에 대해 `v = c₁b₁+⋯+cₙbₙ`일 때, `[v]ᵦ = (c₁,...,cₙ)`. 기저가 바뀌면 같은 벡터도 다른 좌표를 가진다.

---

### 3-3. 행렬의 공간

**핵심 개념:** 열공간(Column Space) Col(A), 행공간(Row Space) Row(A), 영공간(Null Space) Null(A), 좌영공간, Rank-Nullity 정리

**요약:** 행렬이 자연스럽게 만들어내는 부분공간들. Rank-Nullity 정리.

**상세 설명**

- **열공간 Col(A)** A의 열벡터들이 생성하는 공간. `Col(A) = {Ax | x ∈ ℝⁿ}`. Ax=b가 해를 가질 조건: `b ∈ Col(A)`. `dim(Col(A)) = rank(A)`.

- **영공간 Null(A)** `Null(A) = {x | Ax = 0}`. 동차방정식 Ax=0의 해 집합. 항상 부분공간. `dim(Null(A)) = nullity(A)` = 자유변수의 수.

- **⭐ Rank-Nullity 정리** `rank(A) + nullity(A) = n` (열의 수). '열의 수 = 피벗 수 + 자유변수 수'. 선형대수에서 가장 아름다운 정리 중 하나. 5장의 차원정리로 일반화된다.

---

### 3-4. 정사영 벡터

**핵심 개념:** 정사영(Orthogonal Projection), 그람-슈미트 과정, 직교기저·정규직교기저, QR 분해

**요약:** 한 벡터를 부분공간 위로 투영하는 연산. 최소제곱법과 그람-슈미트의 핵심.

**상세 설명**

- **정사영이란?** 벡터 v를 부분공간 W에 '수직으로 떨어뜨린' 점 `projw(v)`. 공식: `projᵤv = (u·v/u·u)u`. 오차벡터 `v - projw(v)`는 W에 수직.

- **⭐ 그람-슈미트 과정** 선형독립 벡터 집합을 정규직교기저(ONB)로 변환하는 알고리즘. 각 단계에서 이전 벡터들의 정사영 성분을 빼고, 정규화한다. QR 분해의 이론적 기반.

- **정규직교기저** ① 서로 직교: `uᵢ·uⱼ = 0` (i≠j) ② 단위벡터: `‖uᵢ‖ = 1`. 정규직교기저에서 좌표 계산 = 내적! `cᵢ = v·uᵢ`. 계산이 극도로 편리해진다.

---

## PART IV. 고유치와 고유벡터

> 행렬의 가장 내밀한 정보. 방향이 보존되는 특별한 벡터와 그 배율. 데이터 과학·물리학의 핵심.

### 4-1. 고유치

**핵심 개념:** 고유치(Eigenvalue) λ, 특성방정식 det(A-λI)=0, 특성다항식, 스펙트럼

**요약:** 행렬 변환에서 방향이 보존되는 스칼라 배율. 특성다항식으로 계산.

**상세 설명**

- **고유치(Eigenvalue)란?** `Av = λv`를 만족하는 스칼라 λ. 즉 행렬 A를 곱했을 때 방향은 그대로이고 크기만 λ배 변하는 상황. '행렬의 고유한 배율'.

- **특성방정식** `det(A - λI) = 0`. 이를 만족하는 λ가 고유치. n×n 행렬의 특성다항식은 n차 다항식 → 최대 n개 고유치 (중복 포함, 복소수 포함).

- **스펙트럼** 행렬의 모든 고유치 집합을 스펙트럼이라 한다. 스펙트럼 반지름: `max|λᵢ|`. 행렬의 '거듭제곱 거동'을 지배하는 핵심 정보.

---

### 4-2. 고유벡터

**핵심 개념:** 고유벡터(Eigenvector) v, 고유공간(Eigenspace), 기하적 중복도, 대수적 중복도

**요약:** 고유치에 대응하는 특별한 방향의 벡터. 행렬의 '자연스러운 좌표계'.

**상세 설명**

- **고유벡터(Eigenvector)란?** `Av = λv` (v ≠ 0)를 만족하는 벡터. 고유치 λ에 대응하는 고유벡터는 유일하지 않음 — 스칼라 배해도 고유벡터. 영벡터는 고유벡터에서 제외.

- **고유공간** 고유치 λ에 대한 고유공간 = `Null(A - λI)` = {Av=λv를 만족하는 모든 벡터 + 영벡터}. 항상 부분공간. 차원 = 기하적 중복도.

- **중복도** 대수적 중복도: 특성다항식에서 λ의 인수 중복 횟수. 기하적 중복도: dim(고유공간). 항상 **기하 ≤ 대수**. 같으면 대각화 가능!

---

### 4-3. 고유치와 고유벡터의 성질

**핵심 개념:** tr(A) = λ₁+⋯+λₙ, det(A) = λ₁⋯λₙ, Aⁿ의 고유치 λⁿ, 서로 다른 고유치 → 선형독립

**요약:** 고유치·고유벡터와 행렬의 기본 정보(det, tr) 사이의 연결고리.

**상세 설명**

- **대각합·행렬식과의 관계** `tr(A) = ∑λᵢ` (고유치의 합). `det(A) = ∏λᵢ` (고유치의 곱). `det(A)=0 ↔ 0이 고유치`.

- **함수 합성과 고유치** `Av = λv → A²v = λ²v → Aⁿv = λⁿv`. 즉 A의 n제곱의 고유치는 λⁿ. A의 역행렬의 고유치는 1/λ.

- **선형독립성** 서로 다른 고유치에 대응하는 고유벡터들은 선형독립! n개의 서로 다른 고유치 → n개 선형독립 고유벡터 → 대각화 가능.

---

### 4-4. 행렬의 대각화

**핵심 개념:** 대각화(Diagonalization) A=PDP⁻¹, 대각화 가능 조건, Aⁿ = PDⁿP⁻¹, 케일리-해밀턴 정리

**요약:** 행렬을 대각행렬로 변환. 거듭제곱 계산과 미분방정식 풀이가 극도로 단순해진다.

**상세 설명**

- **대각화란?** `A = PDP⁻¹`. P: 고유벡터를 열로 가지는 행렬. D: 고유치를 대각에 가지는 행렬.

- **대각화 가능 조건** n×n 행렬이 n개의 선형독립 고유벡터를 가지면 대각화 가능. 충분조건: n개의 서로 다른 고유치. 필요충분조건: 모든 고유치에서 기하적 중복도 = 대수적 중복도.

- **Aⁿ 계산** `Aⁿ = PDⁿP⁻¹`. Dⁿ는 대각성분만 n제곱. 피보나치 수열·마르코프 연쇄·연립미분방정식 풀이에 직접 활용된다.

- **케일리-해밀턴 정리** 모든 정방행렬은 자신의 특성다항식을 만족. `p(λ)=0 → p(A)=0`. 고차 행렬 거듭제곱을 저차로 줄이는 데 활용.

---

### 4-5. 직교행렬과 직교대각화

**핵심 개념:** 직교행렬(Orthogonal Matrix) QᵀQ=I, 직교대각화 A=QDQᵀ, 스펙트럼 정리, 2차 형식(Quadratic Form)

**요약:** 대칭행렬의 특수한 대각화. 고유벡터들이 항상 직교하는 아름다운 성질.

**상세 설명**

- **직교행렬** Q가 직교행렬 ↔ `QᵀQ = I` ↔ `Q⁻¹ = Qᵀ`. 열벡터들이 정규직교기저. 직교행렬이 나타내는 변환은 회전 또는 반사 — 거리 보존.

- **⭐ 스펙트럼 정리** 실수 대칭행렬 A는 ① 모든 고유치가 실수 ② 서로 다른 고유치의 고유벡터들이 직교 ③ 직교대각화 가능: `A = QDQᵀ`. 물리학의 관성모멘트, 주성분 분석(PCA)의 이론적 토대.

- **2차 형식** `Q(x) = xᵀAx` (A는 대칭). 직교대각화로 xy 교차항 없애기 (주축 변환). 양정치: 모든 고유치 > 0, 음정치: < 0, 부정치: 혼합.

---

## PART V. 선형사상

> 벡터공간 간의 구조 보존 함수. 행렬을 '변환'으로 재해석하며 전체 이론을 추상화·통합한다.

### 5-1. 선형사상

**핵심 개념:** 선형사상(Linear Map) T, 선형성 조건 (덧셈·스칼라 보존), 선형사상과 행렬의 대응, 표준행렬

**요약:** 벡터공간 사이의 구조를 보존하는 함수. 행렬이 나타내는 것이 바로 선형사상이다.

**상세 설명**

- **선형사상이란?** `T: V → W`가 선형 ↔ ① `T(u+v)=T(u)+T(v)` ② `T(cu)=cT(u)`. 즉 덧셈과 스칼라 곱을 보존. 행렬 A에 의한 변환 `T(x)=Ax`가 대표 예시.

- **선형성의 핵심** `T(0) = 0` (선형사상은 항상 영벡터를 영벡터로). `T(c₁v₁+⋯+cₖvₖ) = c₁T(v₁)+⋯+cₖT(vₖ)`. 선형성만 알면 기저에서의 값으로 전체 사상 결정!

- **표준행렬** `T: ℝⁿ→ℝᵐ`이 선형사상이면 `T(x) = Ax`인 유일한 m×n 행렬 A 존재. `A = [T(e₁)|T(e₂)|⋯|T(eₙ)]`. 표준기저 벡터들의 상(像)을 열로 나열하면 된다.

---

### 5-2. 핵과 상

**핵심 개념:** 핵(Kernel) ker(T), 상(Image) im(T), ker와 im의 부분공간 증명

**요약:** 선형사상의 두 핵심 부분공간. 사상의 단사성·전사성을 결정짓는다.

**상세 설명**

- **핵(Kernel)** `ker(T) = {v ∈ V | T(v) = 0}`. T에 의해 영벡터로 가는 모든 벡터. `T(x)=Ax`이면 `ker(T) = Null(A)`. 항상 V의 부분공간.

- **상(Image)** `im(T) = {T(v) | v ∈ V} = T(V)`. T에 의해 도달할 수 있는 모든 벡터. `T(x)=Ax`이면 `im(T) = Col(A)`. 항상 W의 부분공간.

- **직관적 이해** 핵은 'T가 뭉개는 방향들'. 상은 'T가 그릴 수 있는 공간'. 핵이 클수록 더 많은 정보를 잃고, 상이 작을수록 도달할 수 없는 곳이 많다.

---

### 5-3. 해공간과 상공간

**핵심 개념:** T(v)=w의 해, 특수해 + 동차해, 해공간의 구조 (v₀ + ker(T))

**요약:** 방정식 T(v)=w의 해 구조. 특수해와 일반해의 관계.

**상세 설명**

- **해공간의 구조** `T(v)=w`의 특수해를 v₀라 하면 일반해 = `v₀ + ker(T)`. 즉 특수해를 하나 찾고, 동차방정식 `T(v)=0`의 해공간(=ker)을 더한 것.

- **Ax=b와의 연결** 행렬 방정식 Ax=b에서: `특수해 x₀ + Null(A)`. Ax=b의 일반해는 '특정 해 + 동차해의 합'이라는 것이 바로 이 구조이다.

---

### 5-4. 핵과 치역의 차원

**핵심 개념:** 차원정리(Dimension Theorem), nullity(T) + rank(T) = dim(V), rank의 일반 정의

**요약:** 차원정리(Rank-Nullity): 선형대수의 가장 핵심적인 정리.

**상세 설명**

- **⭐⭐ 차원정리 (선형사상 버전)** `T: V → W`가 선형사상이면 `dim(ker T) + dim(im T) = dim(V)`. 즉 `nullity + rank = 정의역의 차원`. 행렬의 rank-nullity 정리가 이것의 특수 경우.

- **중요한 따름정리** `dim(V) = dim(W)`인 선형사상 T에서: **T가 단사 ↔ T가 전사 ↔ T가 전단사 ↔ rank = dim(V)**. 같은 차원의 공간에서는 단사면 자동으로 전사!

---

### 5-5. 단사, 전사, 전단사 사상

**핵심 개념:** 단사(Injective) ↔ ker={0}, 전사(Surjective) ↔ im=W, 동형(Isomorphism), 동형 공간의 성질

**요약:** 선형사상의 구조적 성질. 핵과 상의 차원으로 판별한다.

**상세 설명**

- **단사 ↔ ker={0}** T가 단사 ↔ `ker(T) = {0}` ↔ nullity = 0 ↔ rank = dim(V). 서로 다른 입력은 서로 다른 출력. '정보 손실 없음'.

- **전사 ↔ im=W** T가 전사 ↔ `im(T) = W` ↔ rank = dim(W). 모든 목표 벡터에 도달 가능.

- **동형(Isomorphism)** T가 전단사 선형사상이면 동형사상. `V ≅ W` (동형). 핵심: **같은 (유한) 차원의 두 벡터공간은 항상 동형!** `ℝⁿ ≅ Pₙ₋₁ ≅ Mₙₓ₁` 등.

---

### 5-6. 선형사상의 고유치

**핵심 개념:** 선형사상의 고유치·고유벡터, 표현행렬(Representation Matrix), 기저 변환과 닮음행렬, 닮음불변량

**요약:** 행렬 대신 선형사상으로 고유치를 정의. 기저 선택에 무관한 고유치.

**상세 설명**

- **선형사상의 고유치** `T(v) = λv`를 만족하는 λ(∈F)와 v(≠0). 행렬이 아닌 사상 자체에 귀속된 성질 — 기저 선택과 무관하다.

- **표현행렬** 기저 B를 선택하면 T에 대응하는 행렬 `[T]ᵦ`를 만들 수 있다. 기저가 바뀌면 행렬은 닮음변환 `P⁻¹AP`으로 변한다.

- **닮음불변량** 닮음 행렬들은 동일한 tr, det, 특성다항식, 고유치를 가진다. 이는 '선형사상의 고유치가 행렬 표현에 무관'함을 보장한다.

---

### 5-7. 선형사상의 기하학적 해석

**핵심 개념:** 회전(Rotation), 반사(Reflection), 투영(Projection), 전단(Shear), 확대·축소(Scaling)

**요약:** 선형사상을 기하 변환으로 이해하기. 회전·반사·투영·확대·전단.

**상세 설명**

- **회전 변환** ℝ²에서 θ만큼 회전: `[[cosθ,-sinθ],[sinθ,cosθ]]`. 직교행렬이며 det=1. 3D 회전은 오일러 각도 또는 쿼터니언으로 표현 — 컴퓨터 그래픽스의 핵심.

- **반사 변환** 직선(2D) 또는 평면(3D)에 대한 반사. 직교행렬이며 det=-1. 반사 후 반사 = 회전.

- **투영 변환** 부분공간 위로의 정사영. 멱등행렬 `P² = P`. 이미지 처리, 주성분 분석(PCA)의 핵심.

- **전단·확대·축소** 전단(Shear): `[[1,k],[0,1]]`. 확대: 대각행렬 `[[s₁,0],[0,s₂]]`. 이 변환들의 합성으로 모든 선형변환을 분해할 수 있다 (SVD).

## 부록

> 심화 주제들. 현대 응용(머신러닝·신호처리·제어공학)에서 핵심적으로 사용된다.

### 부록 1. QR 분해

**핵심 개념:** QR 분해 A=QR, 그람-슈미트와의 관계, 최소제곱법 응용, 수치 안정성

**요약:** 행렬을 직교행렬 Q와 상삼각행렬 R의 곱으로 분해. 수치 안정적 연산의 핵심.

**상세 설명**

- **QR 분해란?** `A = QR`. Q: 정규직교 열을 가진 행렬. R: 상삼각행렬. 그람-슈미트를 행렬로 표현한 것. A가 열 독립이면 항상 존재.

- **최소제곱법 응용** `Ax=b`의 최소제곱해: `A=QR` 대입 → `QRx=b` → `Rx = Qᵀb`. R이 상삼각이라 역대입으로 쉽게 풀린다.

- **수치 안정성** AᵀA를 직접 계산하면 조건수가 제곱으로 증가해 수치 오차가 커진다. QR 분해는 이를 피해 안정적으로 최소제곱해를 구한다. LAPACK, NumPy의 `lstsq`가 내부적으로 QR 분해를 쓴다.

---

### 부록 2. 특이값 분해 (SVD)

**핵심 개념:** SVD: A = UΣVᵀ, 특이값(Singular Values), 좌/우 특이벡터, 저차원 근사, 의사역행렬

**요약:** 모든 행렬에 적용되는 가장 일반적·강력한 분해. PCA·이미지 압축·추천 시스템의 핵심.

**상세 설명**

- **⭐⭐ SVD란?** `A = UΣVᵀ`. U: 좌특이벡터 (m×m 직교). Σ: 특이값 대각행렬 (σ₁≥σ₂≥⋯≥0). V: 우특이벡터 (n×n 직교). **정방·직교 불필요, 모든 m×n 행렬에 적용!**

- **기하적 의미** 모든 선형변환 = 회전(V) → 축 방향 스케일링(Σ) → 다시 회전(U). 'SVD는 행렬을 세 단순 변환의 합성으로 분해'한다.

- **저차원 근사 (PCA)** σ₁≥σ₂≥⋯로 정렬된 특이값 중 상위 k개만 사용: `Aₖ = U_kΣ_kVₖᵀ`. 이것이 rank-k 최적 근사 (Eckart-Young 정리). 이미지 압축, PCA, 추천 시스템의 핵심 원리.

- **의사역행렬 (Moore-Penrose)** `A† = VΣ†Uᵀ`. Σ†는 0이 아닌 특이값의 역수. 역행렬이 없는 행렬에 대한 '최선의 역'. 최소제곱해 `x̂ = A†b`.

---

### 부록 3. 복소행렬 [개론]

**핵심 개념:** 복소행렬, 켤레전치 A* (에르미트 전치), 에르미트 행렬 A*=A, 유니터리 행렬 U*U=I, 복소 내적

**요약:** 성분이 복소수인 행렬. 에르미트 행렬·유니터리 행렬·양자역학의 세계.

**상세 설명**

- **켤레전치 (Hermitian Transpose)** `A* = Āᵀ` (켤레 복소수 취한 후 전치). 실수 행렬에서 `Aᵀ = A*`. 복소수 영역에서 '대칭'의 올바른 일반화.

- **에르미트 행렬** `A* = A`. 실수 대칭행렬의 복소 버전. 스펙트럼 정리: 에르미트 행렬의 고유치는 항상 실수. 양자역학에서 관측 가능량(Observable)이 에르미트 연산자인 이유.

- **유니터리 행렬** `U*U = I`, 즉 `U⁻¹ = U*`. 직교행렬의 복소 버전. `|det(U)| = 1`. 유니터리 변환은 복소 내적을 보존 — 양자 상태의 확률을 보존하는 변환.

---

### 부록 4. 블록행렬 [개론]

**핵심 개념:** 블록행렬 표기, 블록 덧셈·곱셈, 블록 대각행렬, 슈어 여보수(Schur Complement)

**요약:** 큰 행렬을 작은 행렬 블록으로 나누어 다루는 기법. 계산 효율과 구조 파악에 유용.

**상세 설명**

- **블록행렬이란?** 큰 행렬을 부분 행렬(블록)들로 분할. 적절히 분할된 블록 행렬끼리의 덧셈·곱셈은 스칼라 연산과 동일한 규칙. 크기가 맞아야 한다.

- **블록 대각행렬** 비대각 블록이 모두 0인 행렬. `det = det(블록들)의 곱`. 역행렬 = 각 블록의 역행렬로 구성. 독립적인 하부 시스템의 병렬 처리에 해당.

- **슈어 여보수** `M = [[A,B],[C,D]]`에서 A가 가역이면 `S = D - CA⁻¹B`. 블록 가우스 소거의 결과물. 회귀분석·제어이론·통계에서 자주 등장한다.

### 부록 5. 멱등행렬과 멱영행렬

**핵심 개념:** 멱등행렬(Idempotent) A²=A, 멱영행렬(Nilpotent) Aᵏ=0, 조르단 표준형과의 연결, 응용

**요약:** 특별한 거듭제곱 성질을 가진 행렬. 정사영과 닐포텐트 구조의 이해.

**상세 설명**

- **멱등행렬 (Idempotent)** `A² = A`. 고유치는 0 또는 1만 가능. 정사영 행렬이 대표 예시. `I - A`도 멱등행렬 (여공간으로의 정사영). `tr(A) = rank(A)`.

- **멱영행렬 (Nilpotent)** `Aᵏ = 0`인 k > 0이 존재. 모든 고유치가 0. 상삼각행렬 중 대각이 모두 0인 경우가 전형적 예. 조르단 표준형에서 비대각 블록을 구성한다.

- **조르단 표준형과 연결** 대각화 불가능한 행렬도 조르단 표준형으로 준대각화 가능. 각 조르단 블록 = `λI + N` (N은 멱영행렬). 제어공학에서 시스템 안정성 분석의 최종 도구.

## 가역행렬의 동치조건 (Invertible Matrix Theorem)

n×n 행렬 A에 대해 다음은 모두 동치이다.

- A는 가역행렬이다
- `det(A) ≠ 0`
- `rank(A) = n`
- `Null(A) = {0}`
- A의 열벡터들이 선형 독립이다
- A의 열벡터들이 ℝⁿ을 생성한다
- `Ax = b`는 모든 b에 대해 유일한 해를 가진다
- 0은 A의 고유치가 아니다
