## 제1장 위상공간

> **핵심 질문:** 공간이란 무엇인가?

### §1.1 위상의 정의

**위상(Topology)** τ는 집합 X의 부분집합들의 모임으로, 다음 세 공리를 만족한다.

| 공리 | 조건 | 의미 |
|------|------|------|
| T1 | ∅ ∈ τ, X ∈ τ | 공집합과 전체집합은 열린집합 |
| T2 | Uᵢ ∈ τ → ⋃Uᵢ ∈ τ | 임의 합집합도 열린집합 |
| T3 | U, V ∈ τ → U ∩ V ∈ τ | 유한 교집합도 열린집합 |

**(X, τ)를 위상공간(topological space)이라 한다.**

**주요 위상의 예**

- **비이산위상:** τ = {∅, X} — 가장 거친 위상
- **이산위상:** τ = P(X) — 가장 세밀한 위상
- **유한여집합위상:** Uᶜ이 유한이거나 U = ∅

> 💡 위상은 '거리' 없이 가깝다/멀다를 추상화한 개념. τ가 클수록 점들을 더 세밀하게 구별할 수 있다.

---

### §1.2 위상의 기저와 부분기저

**기저(Basis)** ℬ ⊆ P(X)가 기저이려면:
1. X = ⋃_{B∈ℬ} B (기저원소들이 X를 덮는다)
2. B₁, B₂ ∈ ℬ, x ∈ B₁∩B₂ → ∃B₃ ∈ ℬ: x ∈ B₃ ⊆ B₁∩B₂

**부분기저(Subbasis)** S: 임의 모임. 유한 교집합들의 전체가 기저가 됨.

| 이름 | 기저 |
|------|------|
| ℝ의 표준기저 | {(a,b) \| a < b} |
| 하한위상(Sorgenfrey) | {[a,b) \| a < b} |

> 💡 기저만 지정하면 나머지는 자동으로 결정된다. 마치 벡터 기저처럼!

---

### §1.3 순서위상

전순서집합 (X, <)에서 다음을 부분기저로 생성되는 위상:
- {x | x < a} 형태
- {x | a < x} 형태

**개구간** (a,b) = {x | a < x < b}가 기저원소.

> ℝ의 표준위상 = ℝ의 순서위상

---

### §1.4 곱위상

위상공간 (X, τ_X), (Y, τ_Y)의 **곱위상**:

부분기저 = {π₁⁻¹(U) | U ∈ τ_X} ∪ {π₂⁻¹(V) | V ∈ τ_Y}

- 기저원소: U × V (U ∈ τ_X, V ∈ τ_Y)
- 정사영 π₁, π₂가 연속이 되는 **가장 거친 위상**

---

### §1.5 부분위상

(X, τ)의 부분집합 Y에서의 **부분위상(상대위상)**:

```
τ_Y = {U ∩ Y | U ∈ τ}
```

> 💡 부분공간에서 '열린집합'은 바깥 공간이 아닌 내부 관점에서 정의된다.

---

### §1.6 거리위상

**거리함수(metric)** d: X×X → ℝ의 세 조건:
1. d(x,y) ≥ 0, 등호 ⟺ x = y (양정치성)
2. d(x,y) = d(y,x) (대칭성)
3. d(x,z) ≤ d(x,y) + d(y,z) (삼각부등식)

**열린공:** B(x, ε) = {y | d(x,y) < ε} → 기저원소

| 거리 | 유도 위상 |
|------|-----------|
| 유클리드 거리 √(Σ(xᵢ-yᵢ)²) | ℝⁿ 표준위상 |
| 이산거리 d(x,y)=0 or 1 | 이산위상 |

> 💡 위상수학의 혁명: 거리 없이도 연속성을 정의할 수 있다!

## 제2장 열린집합과 닫힌집합

> **핵심 질문:** 집합의 경계는 어디인가?

### §2.1 닫힌집합

**닫힌집합:** Fᶜ = X \ F 가 열린집합인 집합 F.

| 공리 | 조건 |
|------|------|
| C1 | ∅, X는 닫힌집합 |
| C2 | 임의 교집합 ⋂Fα도 닫힌집합 |
| C3 | 유한 합집합 F₁ ∪ F₂도 닫힌집합 |

> ⚠️ 주의: **닫혀있지 않다 ≠ 열려있다!** (0,1]은 ℝ에서 둘 다 아님.

---

### §2.2 폐포와 내부

| 연산 | 정의 | 의미 |
|------|------|------|
| **폐포** cl(A) | ⋂{F \| F 닫힌집합, A ⊆ F} | A를 포함하는 가장 작은 닫힌집합 |
| **내부** Int(A) | ⋃{U \| U 열린집합, U ⊆ A} | A에 포함되는 가장 큰 열린집합 |
| **경계** ∂A | cl(A) \ Int(A) | 안도 바깥도 아닌 경계선상의 점 |

**관계:** Int(A) ⊆ A ⊆ cl(A)

**쌍대성:** Int(Aᶜ) = (cl A)ᶜ

**예시 (ℝ에서):**
- Int(0,1) = (0,1), cl(0,1) = [0,1]
- cl(ℚ) = ℝ, Int(ℚ) = ∅

---

### §2.3 극한점과 도집합

**극한점(집적점):** x ∈ X가 A의 극한점 ⟺ x의 임의의 열린 이웃 U에 대해 (U \ {x}) ∩ A ≠ ∅

**도집합 A':** A의 모든 극한점의 모임

**핵심 공식:** cl(A) = A ∪ A'

**닫힌집합 조건:** A가 닫힌집합 ⟺ A' ⊆ A

---

### §2.4 분리공리 T₀, T₁, T₂

| 공리 | 조건 | 동치조건 |
|------|------|----------|
| **T₀** (콜모고로프) | 둘 중 하나를 포함하는 열린집합 존재 | — |
| **T₁** (프레셰) | 각각을 포함하되 상대를 포함 안 하는 열린집합 | 모든 {x}가 닫힌집합 |
| **T₂** (하우스도르프) | 서로소인 열린 이웃으로 분리 | 수열의 극한 유일 |

**계층:** T₂ ⟹ T₁ ⟹ T₀ (역 불성립)

## 제3장 연속함수

> **핵심 질문:** 공간들은 어떻게 연결되는가?

### §3.1 연속함수의 정의

**연속(continuous):** f: X → Y가 연속 ⟺

```
Y의 임의의 열린집합 V에 대해 f⁻¹(V) ∈ τ_X
```

**동치 조건들:**
- 닫힌집합의 역상이 닫힌집합
- 임의의 A ⊆ X에 대해 f(cl A) ⊆ cl(f(A))
- 기저원소의 역상이 열린집합

> 💡 핵심은 역상(f⁻¹)! '열린집합을 당겨오면 열린집합' — 이것이 위상적 연속의 본질.

---

### §3.2 연속함수의 예

**주요 보존 성질:**

- **합성:** f, g 연속 → g∘f 연속
- **제한:** f 연속 → f|_A 연속
- **공역 축소:** f: X→f(X) 연속

**붙임 보조정리:** X = A ∪ B (A, B 닫힌집합), f|_A, f|_B 연속 → f 연속

---

### §3.3 위상동형사상

**위상동형사상(homeomorphism)** f: X → Y:
1. f가 전단사
2. f가 연속
3. f⁻¹도 연속

이때 **X ≅ Y** (위상동형)

| 동형 | 설명 |
|------|------|
| (0,1) ≅ ℝ | f(x) = tan(π(x-½)) |
| 열린원반 ≅ ℝ² | f(x) = x/(1-\|x\|) |
| [0,1] ≇ (0,1) | 컴팩트성 불일치 |

> 💡 위상수학에서 '같은 공간'의 기준이 위상동형. (0,1)과 ℝ이 같다!

---

## 제4장 곱위상공간

> **핵심 질문:** 무한 곱에 올바른 위상은?

### §4.1 상자위상과 곱위상

∏_{α∈J} Xα 위에 두 위상:

| | 상자위상 | 곱위상 |
|--|---------|--------|
| 기저 | ∏Uα (모든 성분 제한) | ∏Uα (유한 개만 제한) |
| 유한 J | 동일 | 동일 |
| 무한 J | 더 세밀 | 더 거침 |
| 정사영 연속 | ✓ | ✓ |
| 보편성질 | ✗ | ✓ |

> 💡 곱위상 = 정사영이 모두 연속이 되는 가장 거친 위상

---

### §4.2 곱위상과 고른거리함수

**고른거리(uniform metric):** ρ̄(x, y) = sup_{n} min(|xn − yn|, 1)

**ℝω에서 위상의 세밀도 순서:**

```
상자위상 ⊋ 고른위상 ⊋ 곱위상
```

| 위상 | 수렴 개념 |
|------|-----------|
| 곱위상 | 점별수렴 |
| 고른위상 | 고른수렴 |

---

### §4.3 상자위상과 거리화가능성

| 공간 | 거리화가능? |
|------|------------|
| ℝω (곱위상) | ✓ |
| ℝω (고른위상) | ✓ |
| ℝω (상자위상) | ✗ (제1가산공리 실패) |
| ℝᴵ (I 비가산, 곱위상) | ✗ |

> 💡 거리화가능 → 수열로 위상적 성질을 기술할 수 있다.

## 제5장 상사상과 상위상

> **핵심 질문:** 동일시로 무엇을 만들 수 있나?

### §5.1 토러스, 클라인병, 구, 실사영평면

단위 정사각형 [0,1]² 의 변을 붙여 만드는 곡면들:

| 곡면 | 붙이기 규칙 | 오일러 지표 χ | 향 | 3D 실현 |
|------|-----------|:---:|:---:|:---:|
| 토러스 T² | 위아래 →→, 좌우 ↑↑ | 0 | ✓ | ✓ |
| 클라인병 | 위아래 →→, 좌우 ↑↓ | 0 | ✗ | ✗ |
| 구 S² | 모든 변 수축 | 2 | ✓ | ✓ |
| 실사영평면 RP² | 대척점 동일시 | 1 | ✗ | ✗ |

---

### §5.2 상사상과 상위상

**상사상(quotient map)** p: X → Y:

```
V ⊆ Y 열린집합 ⟺ p⁻¹(V)가 X에서 열린집합
```

**상공간 X/~:** 동치관계로 만든 동치류들의 집합에 상위상 부여.

**보편성질:** f: X/~ → Z 연속 ⟺ f∘p: X → Z 연속

| 구성 | 결과 |
|------|------|
| [0,1] / {0~1} | ≅ S¹ |
| D² / S¹ → 점 | ≅ S² |
| ℝ / ℤ | ≅ S¹ |

## 제6장 연결공간

> **핵심 질문:** 공간이 한 덩어리인가?

### §6.1 연결공간

**연결(connected):** X = U ∪ V, U ∩ V = ∅, U·V 열린집합을 만족하는 공집합이 아닌 U, V가 존재하지 않는 것.

**동치 조건:** X에서 열린집합이면서 닫힌집합인 것이 ∅와 X뿐.

**핵심 성질:**
- f: X→Y 연속, X 연결 → f(X) 연결 (연결성은 위상불변량)
- A ⊆ B ⊆ cl(A), A 연결 → B 연결
- X, Y 연결 → X×Y 연결

---

### §6.2 ℝ의 연결 부분공간

> **정리:** ℝ의 부분집합 C가 연결 ⟺ C가 구간(interval)

**중간값 정리:** f: [a,b]→ℝ 연속, f(a) < c < f(b) → ∃t: f(t) = c

*[a,b] 연결 + 연속상 보존 = 중간값 정리*

---

### §6.3 길연결공간

**길(path):** 연속함수 γ: [0,1] → X (γ(0) = x, γ(1) = y)

**길연결(path-connected):** 임의의 두 점 사이에 길이 존재.

**관계:** 길연결 ⟹ 연결 (역 불성립)

**반례:** 토폴로지스트의 사인 곡선 — 연결이지만 길연결 아님

---

### §6.4 연결성분과 길연결성분

| | 연결성분 C(x) | 길연결성분 PC(x) |
|--|:---:|:---:|
| 정의 | x 포함하는 최대 연결 부분집합 | x 포함하는 최대 길연결 부분집합 |
| 닫힌집합? | ✓ | — |
| 포함 관계 | C(x) ⊇ PC(x) | |

---

### §6.5 국소연결성과 국소길연결성

**국소연결:** 각 x와 임의 열린 이웃 U에 대해 x를 포함하는 연결 열린집합 V ⊆ U 존재.

**동치조건:** X 국소연결 ⟺ 연결 열린집합들이 위상의 기저

**중요 정리:** 연결 + 국소길연결 → 길연결

---

## 제7장 컴팩트공간

> **핵심 질문:** 무한을 유한으로 길들일 수 있나?

### §7.1 컴팩트공간

**컴팩트(compact):** X의 임의의 열린 덮개가 유한 부분 덮개를 가짐.

**핵심 성질:**
- f: X→Y 연속, X 컴팩트 → f(X) 컴팩트
- 컴팩트 공간의 닫힌 부분집합 → 컴팩트
- T₂에서 컴팩트 부분집합 → 닫힌집합
- 컴팩트에서 연속함수 → 최댓값·최솟값 존재

---

### §7.2 컴팩트 곱공간

> **티호노프 정리(Tychonoff):** 컴팩트 공간들의 임의의 곱공간은 곱위상에 대해 컴팩트.

*J가 비가산이어도 성립! 선택공리와 동치.*

**튜브 보조정리:** 유한 곱 컴팩트성 증명의 핵심 도구.

---

### §7.3 ℝⁿ의 컴팩트 부분공간

> **하이네-보렐 정리(Heine-Borel):** ℝⁿ의 부분집합 A가 컴팩트 ⟺ A는 유계이고 닫힌집합

| 집합 | 유계 | 닫힘 | 컴팩트 |
|------|:---:|:---:|:---:|
| [a,b] | ✓ | ✓ | ✓ |
| (0,1) | ✓ | ✗ | ✗ |
| [0,∞) | ✗ | ✓ | ✗ |
| ℝ | ✗ | ✗ | ✗ |

> ⚠️ 하이네-보렐은 ℝⁿ에만 적용. 무한차원에서는 깨진다.

---

### §7.4 극한점컴팩트와 수열컴팩트

| 개념 | 정의 |
|------|------|
| **컴팩트** | 임의 열린 덮개 → 유한 부분 덮개 |
| **극한점컴팩트** | 무한 부분집합 → 극한점 존재 |
| **수열컴팩트** | 임의 수열 → 수렴하는 부분수열 |

**거리공간에서:** 세 개념 모두 동치!

```
컴팩트 ⟺ 극한점컴팩트 ⟺ 수열컴팩트 (거리공간)
```

---

### §7.5 완비거리공간

**완비(complete):** 모든 코시 수열이 수렴하는 거리공간.

**코시 수열:** ∀ε>0, ∃N: m,n>N → d(xm, xn) < ε

| 공간 | 완비? |
|------|:---:|
| ℝ | ✓ |
| ℚ | ✗ (구멍 있음) |
| C[a,b] (균등수렴 거리) | ✓ |

**베르 범주 정리:** 완비거리공간은 어디에도 조밀하지 않은 닫힌집합들의 가산 합집합으로 표현될 수 없다.

**완비화:** 모든 거리공간 X는 완비거리공간 X̂ 로 확장 가능. (ℚ → ℝ의 추상화)

---

### §7.6 국소컴팩트와 컴팩트화

**국소컴팩트:** 각 x ∈ X에 대해 컴팩트 근방이 존재.

**일점컴팩트화(알렉산드로프):** X* = X ∪ {∞}

∞의 열린 이웃: X* \ C (C: X에서 컴팩트 닫힌집합)

| 공간 | 일점컴팩트화 |
|------|-----------|
| ℝ | ≅ S¹ |
| ℝ² | ≅ S² |
| ℝⁿ | ≅ Sⁿ |

> 💡 수직선 ℝ에 점 하나를 붙이면 원이 된다!

## 제8장 가산공리와 분리공리

> **핵심 질문:** 공간이 얼마나 '좋은가'?

### §8.1 가산공리

| | 제1가산공리 (C1) | 제2가산공리 (C2) |
|--|:---:|:---:|
| 정의 | 각 점에 가산 이웃기저 | 전체 가산 위상 기저 |
| 포함 | ← C2 ⟹ C1 | |
| 거리공간 | ✓ (B(x,1/n)) | 가산이면 ✓ |
| ℝⁿ | ✓ | ✓ (ℚⁿ 이용) |

**C2의 결론:**
- C2 ⟹ 분리가능 (가산 조밀 부분집합 존재)
- C2 + T₃ ⟹ 거리화가능 (우리손 거리화 정리)

---

### §8.2 분리공리: 정칙공간과 정규공간

**완전한 분리공리 계층:**

| 공리 | 이름 | 분리 대상 |
|------|------|----------|
| **T₀** | 콜모고로프 | 두 점 중 하나 구별 |
| **T₁** | 프레셰 | 두 점 각각 구별 |
| **T₂** | 하우스도르프 | 두 점을 서로소 이웃으로 |
| **T₃** | 정칙(Regular) | 점과 닫힌집합을 서로소 이웃으로 |
| **T₄** | 정규(Normal) | 두 닫힌집합을 서로소 이웃으로 |

```
T₄ ⟹ T₃ ⟹ T₂ ⟹ T₁ ⟹ T₀
(강한 → 약한 순서)
```

**중요 사실:**
- 컴팩트 + T₂ → T₄
- 모든 거리공간 → T₄

---

### §8.3 우리손 보조정리와 티체 확장정리

**우리손 보조정리(Urysohn's Lemma):**

> X가 정규(T₄), A·B가 서로소인 닫힌집합이면
> 연속함수 f: X → [0,1]이 존재해서 f(A) = {0}, f(B) = {1}

**티체 확장정리(Tietze Extension Theorem):**

> X 정규, A ⊆ X 닫힌집합, f: A → [a,b] 연속이면
> 연속 확장 F: X → [a,b], F|_A = f 가 존재

**동치:** T₁공간에서 정규 ⟺ 우리손 보조정리 성립

> 💡 우리손 보조정리 = 정규공간에서 위상적 분리를 연속함수로 실현.
