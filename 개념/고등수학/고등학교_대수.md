## Ⅰ. 지수함수와 로그함수

### 1. 지수 (거듭제곱의 확장)

지수는 자연수 → 정수 → 유리수 → 실수 순서로 확장됩니다.

#### 거듭제곱 법칙 (5가지)

| 법칙 | 공식 |
|------|------|
| 곱셈 | aᵐ · aⁿ = aᵐ⁺ⁿ |
| 거듭제곱 | (aᵐ)ⁿ = aᵐⁿ |
| 나눗셈 | aᵐ / aⁿ = aᵐ⁻ⁿ |
| 영 지수 | a⁰ = 1 |
| 음 지수 | a⁻ⁿ = 1/aⁿ |
| 유리수 지수 | aᵖ/ᵍ = ᵍ√(aᵖ) |

#### 핵심 조건
- **실수 지수**는 반드시 **a > 0** 이어야 정의됩니다.
- a = 0 또는 a < 0이면 실수 지수 정의 불가.

---

### 2. 로그 (지수의 역연산)

#### 정의
> aˣ = b ⟺ x = logₐb  
> (밑 조건: a > 0, a ≠ 1 / 진수 조건: b > 0)

#### 로그 법칙

| 법칙 | 공식 |
|------|------|
| 곱 | logₐ(mn) = logₐm + logₐn |
| 몫 | logₐ(m/n) = logₐm − logₐn |
| 거듭제곱 | logₐmⁿ = n · logₐm |
| 밑 변환 | logₐb = log b / log a |

#### 특수값
- logₐa = 1
- logₐ1 = 0
- 상용로그: log₁₀b = log b (밑 10 생략)
- 자연로그: ln b = logₑb (밑 e ≈ 2.718)

---

### 3. 지수함수 y = aˣ

| 조건 | 특징 |
|------|------|
| a > 1 | 단조증가, 오른쪽으로 급격히 증가 |
| 0 < a < 1 | 단조감소, 오른쪽으로 0에 수렴 |

- **점근선**: y = 0 (x축)
- **공통점**: 점 (0, 1)을 반드시 통과
- **정의역**: 실수 전체 / **치역**: y > 0
- y = aˣ 와 y = (1/a)ˣ 는 y축에 대해 대칭

#### 평행이동
> y = aˣ⁺ᵐ + n → x축 방향 −m, y축 방향 +n

#### 지수부등식 주의
- a > 1 : 지수의 대소 관계 **그대로** 유지
- 0 < a < 1 : 지수의 대소 관계 **반전**

---

### 4. 로그함수 y = logₐx

| 조건 | 특징 |
|------|------|
| a > 1 | 단조증가 |
| 0 < a < 1 | 단조감소 |

- **점근선**: x = 0 (y축)
- **공통점**: 점 (1, 0)을 반드시 통과
- **정의역**: x > 0 / **치역**: 실수 전체
- y = logₐx 는 y = aˣ 의 **역함수** (y = x에 대해 대칭)

#### 평행이동
> y = logₐ(x−m) + n → x축 방향 +m, y축 방향 +n

#### 주의사항
- 로그방정식·부등식 풀 때 **진수 조건(> 0) 반드시 확인**
- 로그부등식: 밑의 크기에 따라 부등호 방향이 바뀜

## Ⅱ. 삼각함수

### 1. 삼각함수의 정의

#### 단위원 정의 (반지름 1, 각도 θ)
- **sin θ** = y
- **cos θ** = x
- **tan θ** = y/x

#### 호도법
> 180° = π rad → 1° = π/180 rad

#### 역수 관계
- csc θ = 1/sin θ
- sec θ = 1/cos θ
- cot θ = 1/tan θ

#### 사분면별 부호

| 사분면 | sin | cos | tan |
|--------|-----|-----|-----|
| 1사분면 | + | + | + |
| 2사분면 | + | − | − |
| 3사분면 | − | − | + |
| 4사분면 | − | + | − |

> 암기법: **모(두)·사·탄·코** — 1→모두 양수, 2→sin, 3→tan, 4→cos

#### 특수각

| 각도 | 0° | 30° (π/6) | 45° (π/4) | 60° (π/3) | 90° (π/2) |
|------|-----|-----------|-----------|-----------|-----------|
| sin | 0 | 1/2 | √2/2 | √3/2 | 1 |
| cos | 1 | √3/2 | √2/2 | 1/2 | 0 |
| tan | 0 | √3/3 | 1 | √3 | 정의 안 됨 |

---

### 2. 삼각함수의 그래프

#### 기본 그래프 특성

| 함수 | 주기 | 진폭 | 정의역 | 치역 |
|------|------|------|--------|------|
| sin x | 2π | 1 | 실수 전체 | [−1, 1] |
| cos x | 2π | 1 | 실수 전체 | [−1, 1] |
| tan x | π | − | x ≠ π/2 + nπ | 실수 전체 |

#### y = a sin(bx + c) + d 변환 규칙

| 변수 | 의미 | 효과 |
|------|------|------|
| \|a\| | 진폭 | a < 0이면 상하 반전 |
| b | 주기 결정 | 주기 = 2π/\|b\| |
| c | 위상 이동 | x축 방향으로 −c/b 이동 |
| d | 수직 이동 | y축 방향으로 +d 이동 |

- **최댓값**: d + |a| / **최솟값**: d − |a|
- tan의 점근선: x = π/2 + nπ (n은 정수)

---

### 3. 삼각함수 핵심 항등식

#### 피타고라스 항등식 ⭐
```
sin²θ + cos²θ = 1
1 + tan²θ = sec²θ
1 + cot²θ = csc²θ
```

#### 덧셈 공식
```
sin(α ± β) = sinα cosβ ± cosα sinβ
cos(α ± β) = cosα cosβ ∓ sinα sinβ
tan(α ± β) = (tanα ± tanβ) / (1 ∓ tanα tanβ)
```

#### 배각 공식
```
sin 2θ = 2 sinθ cosθ
cos 2θ = cos²θ − sin²θ = 1 − 2sin²θ = 2cos²θ − 1
```

#### 반각 공식
```
sin²θ = (1 − cos 2θ) / 2
cos²θ = (1 + cos 2θ) / 2
```

### 4. 삼각함수의 활용

#### 사인 법칙
> a/sin A = b/sin B = c/sin C = 2R  
> (R: 삼각형의 외접원 반지름)

**사용 시점**: 두 각과 한 변을 알 때, 외접원 반지름 구할 때

#### 코사인 법칙
> a² = b² + c² − 2bc · cos A

**사용 시점**: 두 변과 끼인각을 알 때, 세 변을 알고 각도를 구할 때

#### 삼각형의 넓이
```
S = ½ · b · c · sin A        (두 변과 끼인각)
S = ½ · a · b · sin C
헤론 공식: s = (a+b+c)/2 → S = √(s(s−a)(s−b)(s−c))
```

#### 내접원 반지름
> r = S / s (S: 넓이, s: 반둘레)

## Ⅲ. 수열

### 1. 등차수열과 등비수열

#### 등차수열
- **정의**: 연속한 두 항의 차(공차 d)가 일정
- **일반항**: aₙ = a₁ + (n−1)d
- **합**: Sₙ = n/2 · (a₁ + aₙ) = n/2 · (2a₁ + (n−1)d)
- **등차중항**: b = (a + c)/2

#### 등비수열
- **정의**: 연속한 두 항의 비(공비 r)가 일정
- **일반항**: aₙ = a₁ · rⁿ⁻¹
- **합**: Sₙ = a₁(rⁿ − 1)/(r − 1) (r ≠ 1), Sₙ = na₁ (r = 1)
- **등비중항**: b² = ac

#### ⭐ Sₙ과 aₙ의 관계
```
aₙ = Sₙ − Sₙ₋₁  (n ≥ 2)
a₁ = S₁          (n = 1, 반드시 별도 확인!)
```

---

### 2. 수열의 합 (∑ 시그마)

#### 기본 공식 (필수 암기)

| 공식 | 결과 |
|------|------|
| ∑ₖ₌₁ⁿ c | cn |
| ∑ₖ₌₁ⁿ k | n(n+1)/2 |
| ∑ₖ₌₁ⁿ k² | n(n+1)(2n+1)/6 |
| ∑ₖ₌₁ⁿ k³ | {n(n+1)/2}² |
| ∑ₖ₌₁ⁿ rᵏ | r(rⁿ−1)/(r−1) |

#### 시그마 성질
```
∑(aₖ + bₖ) = ∑aₖ + ∑bₖ
∑c · aₖ = c · ∑aₖ
```

#### 계차수열
> aₙ₊₁ − aₙ = bₙ 일 때:  
> aₙ = a₁ + ∑ₖ₌₁ⁿ⁻¹ bₖ (n ≥ 2)

#### 부분분수 분해
> 1/(k(k+1)) = 1/k − 1/(k+1) → 망원급수(telescoping sum) 활용

---

### 3. 수학적 귀납법

자연수에 관한 명제 P(n)을 증명하는 방법 (도미노 원리)

#### 3단계 구조

**① 기저 단계**
> n = 1일 때 P(1)이 성립함을 **직접 확인**한다.

**② 귀납 가정**
> n = k일 때 P(k)가 **성립한다고 가정**한다.

**③ 귀납 단계**
> 가정을 이용해 n = k+1일 때 P(k+1)도 **성립함을 증명**한다.

**④ 결론**
> 따라서 모든 자연수 n에 대해 P(n)이 성립한다. □

#### 자주 나오는 유형
- ∑ 공식 증명
- 부등식 증명 (k+1 단계에서 가정식 삽입)
- 배수 관계 증명
- 점화식으로 정의된 수열의 일반항 증명

---

### 4. 주요 점화식 유형

| 유형 | 점화식 | 풀이 방법 |
|------|--------|-----------|
| 등차형 | aₙ₊₁ = aₙ + d | 등차수열 |
| 등비형 | aₙ₊₁ = r · aₙ | 등비수열 |
| 계차형 | aₙ₊₁ − aₙ = f(n) | 시그마로 합산 |
| 치환형 | aₙ₊₁ = p · aₙ + q | bₙ = aₙ − α 치환 후 등비 |
