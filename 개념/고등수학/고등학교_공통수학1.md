# 공통수학1 핵심 개념 요약

> 대한민국 고등학교 공통수학1 (총 5단원) 핵심 개념 정리

---

## Ⅰ. 다항식

### 01장. 다항식의 연산

#### 덧셈·뺄셈
- **동류항끼리만** 계산 (문자와 차수가 같은 항)
- 예) `(2x²+3x−1) + (x²−x+4) = 3x² + 2x + 3`

#### 곱셈 공식 (필수 암기)

| 공식 | 식 |
|------|-----|
| 완전제곱식 | `(a+b)² = a²+2ab+b²` |
| 완전제곱식 | `(a−b)² = a²−2ab+b²` |
| 합차공식 | `(a+b)(a−b) = a²−b²` |
| 완전제곱식(3항) | `(a+b+c)² = a²+b²+c²+2ab+2bc+2ca` |
| 세제곱 전개 | `(a+b)³ = a³+3a²b+3ab²+b³` |
| 세제곱 합 | `a³+b³ = (a+b)(a²−ab+b²)` |
| 세제곱 차 | `a³−b³ = (a−b)(a²+ab+b²)` |

#### 다항식의 나눗셈
- 관계식: **A = B·Q + R** (단, R의 차수 < B의 차수)
- **조립제법**: 1차식 `(x−a)`로 나눌 때 빠른 계산법

#### 항등식
- 모든 x에 대해 성립하는 등식
- **계수비교법** 또는 **수치대입법**으로 미정계수 결정
- 예) `ax²+bx+c ≡ 2x²−x+3` → `a=2, b=−1, c=3`

---

### 02장. 나머지 정리와 인수분해

#### 나머지 정리 ⭐
> 다항식 `f(x)`를 `(x−a)`로 나눈 나머지 = **f(a)**

- `(ax+b)`로 나누면 나머지 = `f(−b/a)`

#### 인수 정리
> `f(a) = 0` ⟺ `(x−a)`는 `f(x)`의 인수

- 전략: `f(±1), f(±2)...` 대입 → 0이 되는 a 찾기 → 조립제법으로 인수분해

#### 인수분해 공식

```
a²−b²       = (a+b)(a−b)
a²+2ab+b²   = (a+b)²
a²−2ab+b²   = (a−b)²
a³+b³       = (a+b)(a²−ab+b²)
a³−b³       = (a−b)(a²+ab+b²)
acx²+(ad+bc)x+bd = (ax+b)(cx+d)
```

#### 고차식 인수분해 전략
1. 공통인수 먼저 묶기
2. 치환 (`x²=t` 등)
3. 인수 정리 + 조립제법
4. 복이차식: `ax⁴+bx²+c` → `x²=t`로 치환

## Ⅱ. 방정식

### 03장. 복소수

#### 복소수 정의
```
i = √(−1),  i² = −1
z = a + bi  (a, b는 실수, i는 허수단위)
```
- **실수**: `b = 0`
- **순허수**: `a = 0, b ≠ 0`
- 두 복소수가 같다: `a+bi = c+di` ⟺ `a=c` 이고 `b=d`

#### 사칙연산
```
덧셈: (a+bi) + (c+di) = (a+c) + (b+d)i
곱셈: (a+bi)(c+di) = (ac−bd) + (ad+bc)i
나눗셈: 분모의 켤레복소수를 곱해 유리화
```

#### 켤레복소수
- `z = a+bi`의 켤레: `z̄ = a−bi`
- `z + z̄ = 2a` (실수)
- `z · z̄ = a²+b²` (실수, ≥ 0)

#### i의 거듭제곱 (주기 4)
```
i¹=i,  i²=−1,  i³=−i,  i⁴=1  → 반복
iⁿ: n을 4로 나눈 나머지로 판단
예) i²⁰²⁵ → 2025÷4 나머지 1 → i
```

---

### 04장. 이차방정식

#### 근의 공식
```
ax²+bx+c = 0 (a≠0) 의 근:
x = (−b ± √(b²−4ac)) / 2a

b=2b'(짝수)이면: x = (−b' ± √(b'²−ac)) / a  ← 계산 간편
```

#### 판별식 D = b²−4ac

| D의 값 | 근의 종류 |
|--------|----------|
| D > 0 | 서로 다른 두 실근 |
| D = 0 | 중근 (같은 두 실근) |
| D < 0 | 서로 다른 두 허근 |

#### 근과 계수의 관계 (비에타 공식) ⭐
```
ax²+bx+c = 0의 두 근 α, β에 대해:
α + β = −b/a   (두 근의 합)
α · β = c/a    (두 근의 곱)
```

활용 변환:
- `α²+β² = (α+β)²−2αβ`
- `(α−β)² = (α+β)²−4αβ`

#### 이차방정식 만들기
```
두 근이 α, β인 이차방정식:
x²−(α+β)x + αβ = 0
```
> 허근이 한 근이면 켤레복소수도 반드시 근!

---

### 05장. 이차방정식과 이차함수

#### y=ax²+bx+c 와 x축의 위치 관계

| 판별식 | 그래프와 x축의 관계 |
|--------|------------------|
| D > 0 | 두 점에서 만남 |
| D = 0 | 접함 (한 점) |
| D < 0 | 만나지 않음 |

#### 이차함수 최대·최소
```
y = a(x−p)² + q  (꼭짓점: (p, q))
a > 0: x=p에서 최솟값 q
a < 0: x=p에서 최댓값 q
```
- 범위가 주어진 경우: 꼭짓점과 양 끝 값 모두 비교!

#### 실근의 부호 조건
```
두 실근 모두 양수: D≥0, α+β>0, αβ>0
두 실근 모두 음수: D≥0, α+β<0, αβ>0
두 실근 부호가 다름: αβ<0 (D조건 불필요)
```

---

### 06장. 여러 가지 방정식

#### 고차방정식 풀이 전략
1. `f(±1), f(±2)...` 대입 → 인수 정리로 한 근 찾기
2. 조립제법으로 인수분해
3. 위 과정 반복 → 완전 인수분해
4. 각 인수 = 0으로 근 구하기

- **복이차방정식** `x⁴+ax²+b=0` → `x²=t`로 치환

#### 연립이차방정식 풀이 유형
- **유형 1** (일차+이차): 일차식을 이차식에 대입
- **유형 2** (이차+이차): 빼서 인수분해 or 합·곱 치환

## Ⅲ. 부등식

### 07장. 일차부등식

#### 부등식의 핵심 성질
> 음수를 곱하거나 나누면 **부등호 방향이 반전**됩니다!

```
a < b, c > 0 이면: ac < bc
a < b, c < 0 이면: ac > bc  ← 반전!
```

#### 연립일차부등식
- 각각 풀고 수직선에서 **교집합** 찾기

#### 절댓값 부등식
```
|x| < a  (a>0) ⟺ −a < x < a        (교집합, and)
|x| > a  (a>0) ⟺ x < −a 또는 x > a  (합집합, or)
|x−p| < a      ⟺ p−a < x < p+a
```

---

### 08장. 이차부등식

#### 이차부등식 풀이 (a>0 기준)
```
ax²+bx+c = 0의 두 근: α < β

ax²+bx+c < 0  →  α < x < β       (그래프 아래)
ax²+bx+c > 0  →  x < α 또는 x > β  (그래프 위)
```

#### 판별식 D에 따른 해의 변화

| D | `> 0` 의 해 | `< 0` 의 해 |
|---|------------|------------|
| D > 0 | x < α 또는 x > β | α < x < β |
| D = 0 | x ≠ α인 모든 실수 | 해 없음 |
| D < 0 | 모든 실수 | 해 없음 |

#### 이차부등식 항상 성립 조건 ⭐

```
ax²+bx+c > 0이 모든 실수에서 성립
⟺ a > 0 이고 D < 0

ax²+bx+c ≥ 0이 모든 실수에서 성립
⟺ a > 0 이고 D ≤ 0
```

**풀이 3단계 루틴:**
1. a > 0 확인
2. D = b²−4ac 를 k에 대한 식으로 정리
3. D < 0 이차부등식 풀기 → k의 범위 결정

## Ⅳ. 순열과 조합

### 09장. 순열과 조합

#### 합의 법칙 vs 곱의 법칙

| 법칙 | 상황 | 키워드 |
|------|------|--------|
| 합의 법칙 | 동시에 일어나지 않음 | "또는", "이거나" → 덧셈 |
| 곱의 법칙 | 연속으로 일어남 | "그리고", "동시에" → 곱셈 |

#### 팩토리얼
```
n! = n × (n−1) × (n−2) × ··· × 2 × 1
0! = 1  (정의, 반드시 암기!)
```

#### 순열 nPr — 순서 있는 선택
```
nPr = n! / (n−r)! = n(n−1)(n−2)···(n−r+1)
예) 5P3 = 5×4×3 = 60
```

#### 특수한 순열
```
원형 순열: (n−1)!
같은 것이 있는 순열: n! / (a! × b! × ···)
예) AABBC 나열: 5!/(2!×2!×1!) = 30
```

#### 조합 nCr — 순서 없는 선택
```
nCr = nPr / r! = n! / (r!(n−r)!)
예) 5C3 = 60 / 6 = 10
```

#### 조합의 성질
```
nC0 = nCn = 1
nCr = nC(n−r)          ← 대칭성 (계산 단순화 활용)
nCr = (n−1)C(r−1) + (n−1)Cr  ← 파스칼의 삼각형
```

#### 중복조합 nHr
```
nHr = (n+r−1)Cr
예) 3H2 = (3+2−1)C2 = 4C2 = 6
```

#### 순열 vs 조합 구분법

| 순열 (순서 O) | 조합 (순서 X) |
|-------------|-------------|
| "나열", "배열", "줄 세우기" | "뽑기", "선택", "고르기" |
| 회장·부회장·총무 선출 | 대표 3명 선출 |
| 직책이 다를 때 | 역할이 같을 때 |

## Ⅴ. 행렬

### 10장. 행렬과 그 연산

#### 행렬 기본 용어
```
m×n 행렬: m행 n열
(i,j) 성분: i행 j열의 원소 → aᵢⱼ
두 행렬이 같다: 크기가 같고 모든 대응 성분이 같을 때
```

#### 덧셈·뺄셈
- **크기가 같은 행렬끼리만** 가능
- 대응 성분끼리 계산
- 교환법칙 `A+B = B+A` 성립
- 결합법칙 `(A+B)+C = A+(B+C)` 성립

#### 스칼라 곱
```
k × [a b] = [ka  kb]
    [c d]   [kc  kd]
```
성질: `k(A+B)=kA+kB`, `(k+l)A=kA+lA`, `k(lA)=(kl)A`

#### 특수 행렬
```
영행렬 O: 모든 성분이 0  →  A + O = A
단위행렬 E: 대각선 1, 나머지 0  →  AE = EA = A
```

#### 행렬의 곱셈 ⭐

**가능 조건:** A의 열 수 = B의 행 수
```
A: m×n,  B: n×p  →  AB: m×p
```

**2×2 행렬 곱셈 (행×열 내적):**
```
[a b]   [e f]   [ae+bg  af+bh]
[c d] × [g h] = [ce+dg  cf+dh]
```

#### 행렬 곱셈의 성질 — 수와의 차이점! ⭐

| 성질 | 수 | 행렬 |
|------|-----|------|
| 교환법칙 | `ab = ba` ✓ | `AB ≠ BA` ✗ |
| 결합법칙 | `(ab)c = a(bc)` ✓ | `(AB)C = A(BC)` ✓ |
| 분배법칙 | `a(b+c) = ab+ac` ✓ | `A(B+C) = AB+AC` ✓ |
| `AB=O → A=O 또는 B=O` | ✓ | ✗ |
| `AB=AC → B=C` | ✓ | ✗ |

```
(A+B)² ≠ A²+2AB+B²
(A+B)² = A²+AB+BA+B²  ← AB와 BA를 따로 써야 함!
```

#### 행렬의 거듭제곱
```
A² = A×A,  A³ = A×A×A,  A⁰ = E
```

## 단원별 핵심 흐름 요약

```
Ⅰ 다항식
  다항식 연산 → 나눗셈/조립제법 → 나머지·인수 정리 → 인수분해

Ⅱ 방정식
  복소수 → 근의 공식·판별식 → 근과 계수 관계 → 이차함수 연결 → 고차·연립방정식

Ⅲ 부등식
  부등식 성질 → 일차부등식 → 연립·절댓값 → 이차부등식 → 항상 성립 조건

Ⅳ 순열과 조합
  합·곱의 법칙 → 팩토리얼 → 순열 → 조합 → 중복조합

Ⅴ 행렬
  행렬 표기법 → 덧셈·뺄셈 → 스칼라 곱 → 행렬 곱셈 → 거듭제곱·특수행렬
```

---

## 단원 간 연결 관계

- **1단원 → 2단원**: 인수분해로 이차방정식의 근 구하기
- **2단원 → 3단원**: 판별식(D)이 이차부등식 해 결정의 핵심
- **4단원**: 순열·조합은 확률 단원의 기초
- **5단원**: 행렬은 연립방정식의 행렬 표현으로 확장
