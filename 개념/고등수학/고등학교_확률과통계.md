## 1. 순열과 조합

### ✅ 핵심 개념 요약

| 구분 | 기호 | 공식 | 특징 |
|------|------|------|------|
| 순열 | ₙPᵣ | n!/(n-r)! | 순서 O, 중복 X |
| 원순열 | - | (n-1)! | 원형 배열 |
| 중복순열 | ₙΠᵣ | nʳ | 순서 O, 중복 O |
| 같은 것이 있는 순열 | - | n!/(p!q!r!…) | 같은 것 존재 |
| 조합 | ₙCᵣ | n!/{r!(n-r)!} | 순서 X, 중복 X |
| 중복조합 | ₙHᵣ | ₙ₊ᵣ₋₁Cᵣ | 순서 X, 중복 O |

### 📖 상세 설명

#### (1) 원순열

서로 다른 n개를 원형으로 배열하는 경우의 수입니다.

$$\text{원순열} = (n-1)!$$

**왜 (n-1)! 일까요?**
원형 배열에서는 회전했을 때 같은 배열을 같은 것으로 봅니다. n개를 일렬로 배열하면 n!가지인데, 원형에서는 n가지 회전이 모두 같은 배열이 되므로 n!/n = (n-1)!이 됩니다.

**예시**: 4명(A, B, C, D)이 원탁에 앉는 방법 → (4-1)! = 3! = **6가지**

#### (2) 중복순열

서로 다른 n개에서 중복을 허용하여 r개를 택해 일렬로 배열하는 경우의 수입니다.

$$_n\Pi_r = n^r$$

각 자리마다 n가지 선택지가 있고, 그것이 r번 반복되므로 n × n × ... × n = nʳ입니다.

**예시**: 0~9 숫자로 만드는 4자리 비밀번호 → 10⁴ = **10,000가지**

#### (3) 같은 것이 있는 순열

n개 중에서 같은 것이 각각 p개, q개, r개, ... 있을 때 모두를 일렬로 배열하는 경우의 수입니다.

$$\frac{n!}{p! \, q! \, r! \, \cdots} \quad (\text{단, } p+q+r+\cdots = n)$$

**예시**: 'BANANA' 6글자를 배열하는 방법
- B 1개, A 3개, N 2개
- 6!/(1!·3!·2!) = 720/12 = **60가지**

#### (4) 중복조합

서로 다른 n개에서 중복을 허용하여 r개를 택하는 조합의 수입니다.

$$_nH_r = {_{n+r-1}C_r}$$

**핵심 활용**: 방정식 x₁ + x₂ + ... + xₙ = r (음이 아닌 정수해) 의 개수 = ₙHᵣ

**예시**: 사과, 배, 감 중에서 중복을 허용해 5개를 고르는 방법
- ₃H₅ = ₇C₅ = 21가지

## 2. 이항정리

### ✅ 핵심 개념 요약

$$(a+b)^n = \sum_{r=0}^{n} {_nC_r} \, a^{n-r} b^r$$

- **이항계수**: ₙCᵣ (전개식의 각 항의 계수)
- **일반항**: ₙCᵣ aⁿ⁻ʳ bʳ

### 📖 상세 설명

#### (1) 이항정리 전개식

$$(a+b)^n = {_nC_0}a^n + {_nC_1}a^{n-1}b + {_nC_2}a^{n-2}b^2 + \cdots + {_nC_n}b^n$$

**예시**: (x+2)⁴의 전개
- x³ 항의 계수 → ₄C₁ × 2¹ = 4 × 2 = **8**
- x² 항의 계수 → ₄C₂ × 2² = 6 × 4 = **24**

#### (2) 파스칼의 삼각형

```
                1
              1   1
            1   2   1
          1   3   3   1
        1   4   6   4   1
      1   5  10  10   5   1
```

**핵심 성질**: ₙ₋₁Cᵣ₋₁ + ₙ₋₁Cᵣ = ₙCᵣ (위 두 수의 합 = 아래 수)

#### (3) 이항계수의 중요한 성질

a=b=1을 대입하면:

$$_nC_0 + {_nC_1} + {_nC_2} + \cdots + {_nC_n} = 2^n$$

→ **n개 원소의 부분집합 개수가 2ⁿ인 이유**가 바로 이것!

a=1, b=-1을 대입하면:

$$_nC_0 - {_nC_1} + {_nC_2} - \cdots + (-1)^n{_nC_n} = 0$$

→ 짝수번째 항의 합 = 홀수번째 항의 합 = 2ⁿ⁻¹

## 1. 확률의 뜻과 활용

### ✅ 핵심 개념 요약

| 용어 | 의미 |
|------|------|
| 시행 | 같은 조건에서 반복할 수 있고 결과가 우연에 의해 결정되는 실험·관찰 |
| 표본공간 (S) | 어떤 시행에서 일어날 수 있는 모든 결과의 집합 |
| 사건 | 표본공간의 부분집합 |
| 근원사건 | 한 개의 원소로 이루어진 사건 |
| 확률 P(A) | 사건 A가 일어날 가능성을 수치화한 값 (0 ≤ P(A) ≤ 1) |

### 📖 상세 설명

#### (1) 수학적 확률 vs 통계적 확률

**수학적 확률 (Mathematical Probability)**

각 근원사건이 일어날 가능성이 모두 같다고 할 때:

$$P(A) = \frac{n(A)}{n(S)} = \frac{\text{사건 A의 경우의 수}}{\text{표본공간의 경우의 수}}$$

**예시**: 주사위를 한 번 던져 짝수가 나올 확률
- n(S) = 6, n(A) = 3 (2, 4, 6)
- P(A) = 3/6 = **1/2**

**통계적 확률 (Statistical Probability)**

같은 시행을 n번 반복하여 사건 A가 r번 일어났을 때, n이 충분히 크면 상대도수 r/n이 일정한 값에 가까워지며, 이를 통계적 확률이라 합니다.

> 💡 **큰 수의 법칙**: 시행 횟수 n이 한없이 커지면 통계적 확률은 수학적 확률에 한없이 가까워집니다.

#### (2) 확률의 기본 성질

표본공간 S의 임의의 사건 A에 대하여:

$$0 \leq P(A) \leq 1$$

- P(S) = 1 (반드시 일어나는 사건)
- P(∅) = 0 (절대 일어나지 않는 사건)

#### (3) 확률의 덧셈정리

두 사건 A, B에 대하여:

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

**특히, 두 사건이 서로 배반(A ∩ B = ∅)이면**:

$$P(A \cup B) = P(A) + P(B)$$

**예시**: 1~10 중 한 수를 뽑을 때, 2의 배수 또는 3의 배수일 확률
- P(2의 배수) = 5/10, P(3의 배수) = 3/10, P(6의 배수) = 1/10
- P(A∪B) = 5/10 + 3/10 - 1/10 = **7/10**

#### (4) 여사건의 확률

사건 A에 대하여 A가 일어나지 않는 사건을 여사건 Aᶜ라 하며:

$$P(A^c) = 1 - P(A)$$

> 💡 **활용 팁**: "적어도 하나" 같은 표현이 나오면 여사건을 활용하면 훨씬 쉬워집니다!

**예시**: 동전 3개를 던질 때 적어도 한 번 앞면이 나올 확률
- 여사건: 모두 뒷면 → (1/2)³ = 1/8
- 구하는 확률 = 1 - 1/8 = **7/8**

## 2. 조건부확률

### ✅ 핵심 개념 요약

| 개념 | 공식 |
|------|------|
| 조건부확률 | P(B\|A) = P(A∩B) / P(A) |
| 곱셈정리 | P(A∩B) = P(A) × P(B\|A) |
| 독립 | P(A∩B) = P(A) × P(B) |
| 독립 ⟺ | P(B\|A) = P(B) |

### 📖 상세 설명

#### (1) 조건부확률

사건 A가 일어났다는 조건 아래에서 사건 B가 일어날 확률입니다.

$$P(B|A) = \frac{P(A \cap B)}{P(A)} \quad (\text{단, } P(A) > 0)$$

**핵심 아이디어**: 표본공간이 S에서 A로 "축소"된 상황에서의 확률!

**예시**: 두 자녀를 둔 가정에서 첫째가 딸일 때, 둘째도 딸일 확률
- A = {첫째 딸}, B = {둘째 딸}
- P(A) = 1/2, P(A∩B) = 1/4
- P(B|A) = (1/4) / (1/2) = **1/2**

#### (2) 확률의 곱셈정리

조건부확률 공식을 변형하면:

$$P(A \cap B) = P(A) \cdot P(B|A) = P(B) \cdot P(A|B)$$

**예시**: 흰 공 3개, 검은 공 2개가 든 주머니에서 공을 차례로 2개 꺼낼 때, 둘 다 흰 공일 확률 (비복원)
- P(1번째 흰 공) = 3/5
- P(2번째 흰 공 | 1번째 흰 공) = 2/4
- P(둘 다 흰 공) = 3/5 × 2/4 = **3/10**

#### (3) 사건의 독립과 종속

**독립의 정의**: 사건 A의 발생이 사건 B의 발생 확률에 영향을 주지 않을 때.

다음 세 식은 모두 동치입니다:

$$P(A \cap B) = P(A) \cdot P(B)$$

$$P(B|A) = P(B)$$

$$P(A|B) = P(A)$$

**종속**: 독립이 아닌 경우

> ⚠️ **주의**: '배반사건'과 '독립사건'은 완전히 다른 개념!
> - 배반: A ∩ B = ∅ (동시에 일어날 수 없음)
> - 독립: P(A∩B) = P(A)P(B) (서로 영향 X)

#### (4) 독립시행의 확률

매 시행에서 사건 A가 일어날 확률이 p로 일정한 독립시행을 n번 반복할 때, 사건 A가 정확히 r번 일어날 확률:

$$P = {_nC_r} \, p^r (1-p)^{n-r}$$

**예시**: 주사위를 5번 던질 때 6의 눈이 정확히 2번 나올 확률
- n=5, r=2, p=1/6
- P = ₅C₂ × (1/6)² × (5/6)³ = 10 × 1/36 × 125/216 = **1250/7776**

## 🔑 2단원 핵심 정리

| 상황 | 사용 공식 |
|------|-----------|
| A 또는 B | P(A∪B) = P(A)+P(B)-P(A∩B) |
| 적어도 ~ | 여사건 활용: 1 - P(Aᶜ) |
| A가 일어난 후 B | 조건부확률 P(B\|A) |
| A 그리고 B (연속) | 곱셈정리 P(A)·P(B\|A) |
| 서로 영향 없음 | 독립: P(A∩B) = P(A)P(B) |
| 같은 시행 반복 | 독립시행 ₙCᵣ pʳ(1-p)ⁿ⁻ʳ |

### 🌟 주요 헷갈림 포인트

**Q. 배반사건 ≠ 독립사건?**

- ✅ **배반**: 두 사건이 동시에 일어날 수 없음 (A∩B = ∅)
- ✅ **독립**: 한 사건이 다른 사건의 확률에 영향 없음

오히려 P(A) > 0, P(B) > 0인 두 사건이 배반이면 **종속**입니다! (A가 일어나면 B는 반드시 안 일어나므로 영향을 줌)

## 1. 확률분포

### ✅ 핵심 개념 요약

| 용어 | 의미 |
|------|------|
| 확률변수 X | 표본공간의 각 원소에 실수값을 대응시키는 함수 |
| 이산확률변수 | 값이 자연수처럼 띄엄띄엄 있는 확률변수 |
| 연속확률변수 | 값이 어떤 구간 전체의 실수인 확률변수 |
| 확률분포 | 확률변수가 가지는 값과 그 확률의 대응 관계 |

### 📖 상세 설명

#### (1) 이산확률변수의 평균, 분산, 표준편차

확률변수 X가 x₁, x₂, ..., xₙ의 값을 가지고 각각의 확률이 p₁, p₂, ..., pₙ일 때:

**평균 (기댓값)**:

$$E(X) = m = \sum_{i=1}^{n} x_i p_i$$

**분산**:

$$V(X) = E((X-m)^2) = \sum_{i=1}^{n}(x_i - m)^2 p_i = E(X^2) - \{E(X)\}^2$$

**표준편차**:

$$\sigma(X) = \sqrt{V(X)}$$

**예시**: 주사위 한 번 던질 때 나오는 눈 X의 평균과 분산
- E(X) = (1+2+3+4+5+6)/6 = **7/2**
- E(X²) = (1+4+9+16+25+36)/6 = 91/6
- V(X) = 91/6 - (7/2)² = 91/6 - 49/4 = **35/12**

#### (2) 확률변수 aX+b의 평균, 분산, 표준편차

상수 a, b에 대하여:

$$E(aX+b) = aE(X) + b$$

$$V(aX+b) = a^2 V(X)$$

$$\sigma(aX+b) = |a| \, \sigma(X)$$

> 💡 **포인트**: 평균은 a, b 모두 영향을 받지만, 분산은 b의 영향을 받지 않습니다! (위치 이동은 흩어진 정도를 바꾸지 않음)

#### (3) 이항분포 B(n, p)

한 번의 시행에서 사건 A가 일어날 확률이 p인 독립시행을 n번 반복할 때, A가 일어나는 횟수 X의 확률분포를 이항분포라 하며 **B(n, p)**로 나타냅니다.

$$P(X=r) = {_nC_r} \, p^r q^{n-r} \quad (q = 1-p)$$

**이항분포의 평균, 분산, 표준편차**:

$$E(X) = np$$

$$V(X) = npq$$

$$\sigma(X) = \sqrt{npq}$$

**예시**: 주사위를 180번 던질 때 6의 눈이 나오는 횟수 X
- X ~ B(180, 1/6)
- E(X) = 180 × 1/6 = **30**
- V(X) = 180 × 1/6 × 5/6 = **25**
- σ(X) = **5**

#### (4) 연속확률변수와 확률밀도함수

연속확률변수 X가 어떤 구간의 모든 실수값을 가질 때, 확률밀도함수 f(x)는 다음을 만족합니다:

1. f(x) ≥ 0
2. 전체 구간에서 f(x)와 x축으로 둘러싸인 넓이 = 1
3. P(a ≤ X ≤ b) = 구간 [a,b]에서 f(x)와 x축 사이의 넓이

> ⚠️ **중요**: 연속확률변수에서는 P(X=a) = 0 입니다!
> 따라서 P(a≤X≤b) = P(a<X<b)

#### (5) 정규분포 N(m, σ²)

평균 m, 표준편차 σ인 정규분포의 확률밀도함수는 종 모양(bell curve)이며 다음 성질을 가집니다:

**정규분포의 성질**:
- 직선 x = m에 대하여 대칭
- 평균 m에서 최댓값을 가짐
- σ가 클수록 곡선이 완만하고 넓게 퍼짐
- σ가 작을수록 곡선이 뾰족하고 가운데 집중

**정규분포의 표준화**:

X ~ N(m, σ²)일 때, 다음과 같이 표준화하면:

$$Z = \frac{X - m}{\sigma}$$

Z는 **표준정규분포 N(0, 1)**을 따릅니다.

**예시**: X ~ N(70, 10²)일 때 P(X ≤ 80)
- Z = (80-70)/10 = 1
- P(X ≤ 80) = P(Z ≤ 1) = 0.5 + 0.3413 = **0.8413** (표준정규분포표 활용)

#### (6) 이항분포와 정규분포의 관계

X ~ B(n, p)에서 **n이 충분히 크면** (보통 np ≥ 5, nq ≥ 5):

$$X \approx N(np, \, npq)$$

이를 이용해 이항분포 문제를 정규분포로 근사 계산할 수 있습니다.

## 2. 통계적 추정

### ✅ 핵심 개념 요약

| 용어 | 의미 | 기호 |
|------|------|------|
| 모집단 | 조사 대상 전체 | - |
| 표본 | 모집단에서 뽑은 일부 | - |
| 모평균 | 모집단의 평균 | m |
| 모분산 | 모집단의 분산 | σ² |
| 표본평균 | 표본의 평균 | X̄ |
| 표본분산 | 표본의 분산 | S² |

### 📖 상세 설명

#### (1) 표본평균의 분포

모평균 m, 모표준편차 σ인 모집단에서 크기 n인 표본을 임의추출할 때, 표본평균 X̄의 분포는:

$$E(\bar{X}) = m$$

$$V(\bar{X}) = \frac{\sigma^2}{n}$$

$$\sigma(\bar{X}) = \frac{\sigma}{\sqrt{n}}$$

**중심극한정리**: 모집단의 분포에 관계없이 **n이 충분히 크면** 표본평균 X̄는 근사적으로 다음 정규분포를 따릅니다.

$$\bar{X} \sim N\left(m, \, \frac{\sigma^2}{n}\right)$$

> 💡 **핵심**: 표본의 크기 n이 커질수록 표본평균은 모평균 m에 가까워지고, 흩어진 정도(σ/√n)는 작아집니다!

**예시**: 모평균 50, 모표준편차 10인 모집단에서 크기 25인 표본을 뽑을 때
- E(X̄) = **50**
- σ(X̄) = 10/√25 = **2**
- X̄ ~ N(50, 4)

#### (2) 모평균의 신뢰구간

모표준편차가 σ인 모집단에서 크기 n인 표본을 추출하여 표본평균이 x̄일 때:

**모평균 m의 신뢰구간**

| 신뢰도 | 신뢰구간 |
|--------|----------|
| 95% | x̄ - 1.96·σ/√n ≤ m ≤ x̄ + 1.96·σ/√n |
| 99% | x̄ - 2.58·σ/√n ≤ m ≤ x̄ + 2.58·σ/√n |

**일반화된 식**:

$$\bar{x} - k\frac{\sigma}{\sqrt{n}} \leq m \leq \bar{x} + k\frac{\sigma}{\sqrt{n}}$$

(95%일 때 k=1.96, 99%일 때 k=2.58)

#### (3) 신뢰구간의 길이

신뢰구간의 길이 L:

$$L = 2k \cdot \frac{\sigma}{\sqrt{n}}$$

**중요한 성질**:
- 신뢰도↑ → 신뢰구간 길이↑ (더 확신하려면 범위가 넓어짐)
- 표본의 크기 n↑ → 신뢰구간 길이↓ (표본이 많을수록 정밀해짐)
- 표본의 크기를 4배로 → 신뢰구간 길이는 1/2배

**예시**: 표본크기 100, 모표준편차 20, x̄=50일 때 95% 신뢰구간
- 1.96 × 20/√100 = 1.96 × 2 = 3.92
- 신뢰구간: **46.08 ≤ m ≤ 53.92**

#### (4) 신뢰도의 의미 ⚠️ 헷갈리기 쉬운 부분!

> "95% 신뢰구간"의 정확한 의미:
>
> ✅ 같은 크기의 표본을 반복해서 추출하여 신뢰구간을 만들면, **그중 약 95%가 모평균 m을 포함한다**는 뜻
>
> ❌ "모평균이 이 구간에 있을 확률이 95%이다"라는 의미가 **아닙니다**!
>
> (모평균은 상수이므로 '확률'로 표현하지 않음)
