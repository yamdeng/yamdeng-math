## 📐 Ⅰ. 도형의 방정식

### 01 평면좌표

#### 두 점 사이의 거리
두 점 A(x₁, y₁), B(x₂, y₂)에 대해:

$$\overline{AB} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

#### 내분점
선분 AB를 **m : n**으로 내분하는 점:

$$\left(\frac{mx_2 + nx_1}{m+n},\ \frac{my_2 + ny_1}{m+n}\right)$$

- **중점** (1:1 내분): $\left(\dfrac{x_1+x_2}{2},\ \dfrac{y_1+y_2}{2}\right)$

#### 외분점
선분 AB를 **m : n** (m ≠ n)으로 외분하는 점:

$$\left(\frac{mx_2 - nx_1}{m-n},\ \frac{my_2 - ny_1}{m-n}\right)$$

> 💡 내분은 선분 **안쪽**, 외분은 선분 **바깥쪽** 점

### 02 직선의 방정식

#### 표현 형태

| 형태 | 공식 | 사용 상황 |
|------|------|-----------|
| 기울기-절편형 | y = mx + b | 기울기와 y절편을 알 때 |
| 점-기울기형 | y − y₁ = m(x − x₁) | 한 점과 기울기를 알 때 |
| 두 점형 | (y−y₁)/(y₂−y₁) = (x−x₁)/(x₂−x₁) | 두 점의 좌표를 알 때 |
| 절편형 | x/a + y/b = 1 | x, y 절편을 모두 알 때 |

#### 두 직선의 위치 관계 (기울기 m₁, m₂)

- **평행**: m₁ = m₂, 절편 다름
- **일치**: m₁ = m₂, 절편도 같음
- **수직**: m₁ × m₂ = −1
- **교점**: 연립방정식으로 계산

#### 점과 직선 사이의 거리

점 (x₀, y₀)에서 직선 ax + by + c = 0까지의 거리:

$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$

### 03 원의 방정식

#### 표준형

$$( x - a )^2 + ( y - b )^2 = r^2$$

- 중심: (a, b), 반지름: r

#### 일반형

$$x^2 + y^2 + Dx + Ey + F = 0$$

- 원이 되는 조건: **D² + E² − 4F > 0**
- 완전제곱식으로 변환해 중심·반지름 추출

#### 원과 직선의 위치 관계 (중심-직선 거리 d)

| 조건 | 위치 관계 | 교점 수 |
|------|-----------|---------|
| d < r | 두 점에서 만남 | 2개 |
| d = r | 접한다 | 1개 |
| d > r | 만나지 않음 | 0개 |

#### 원 위의 점에서의 접선

원 x² + y² = r² 위의 점 (x₀, y₀)에서의 접선:

$$x_0 x + y_0 y = r^2$$

### 04 도형의 이동

#### 평행이동

점 P(x, y)를 x축 방향으로 a, y축 방향으로 b만큼 이동:

$$P(x, y) \rightarrow P'(x+a,\ y+b)$$

방정식 f(x, y) = 0의 평행이동 → **x를 x−a, y를 y−b로 치환**

#### 대칭이동

| 대칭축 | 점의 변환 | 방정식 치환 |
|--------|-----------|------------|
| x축 | (x, y) → (x, −y) | y → −y |
| y축 | (x, y) → (−x, y) | x → −x |
| 원점 | (x, y) → (−x, −y) | x → −x, y → −y |
| y = x | (x, y) → (y, x) | x와 y 교환 |
| y = −x | (x, y) → (−y, −x) | x → −y, y → −x |

> 💡 평행이동과 대칭이동을 동시에 적용할 때는 순서에 주의!

## 🔷 Ⅱ. 집합과 명제

### 05 집합의 뜻과 표현

#### 집합의 표현 방법

| 방법 | 예시 | 특징 |
|------|------|------|
| 원소나열법 | {1, 2, 3, 4} | 원소를 직접 나열 |
| 조건제시법 | {x \| x는 10 이하 자연수} | 조건으로 표현 |
| 벤 다이어그램 | 원으로 시각화 | 관계 파악에 유리 |

#### 핵심 용어

- **원소 (element)**: 집합을 이루는 각각의 대상. `a ∈ A`
- **부분집합**: A ⊆ B ⟺ A의 모든 원소가 B에 속함
- **진부분집합**: A ⊊ B ⟺ A ⊆ B이고 A ≠ B
- **공집합 (∅)**: 원소가 없는 집합. 모든 집합의 부분집합
- **전체집합 (U)**: 다루는 모든 원소의 집합

#### 부분집합의 개수

| 종류 | 개수 |
|------|------|
| 부분집합 전체 | 2ⁿ |
| 진부분집합 | 2ⁿ − 1 |
| 특정 원소 k개를 반드시 포함 | 2ⁿ⁻ᵏ |

---

### 06 집합의 연산

#### 기본 연산

| 연산 | 기호 | 의미 |
|------|------|------|
| 합집합 | A ∪ B | A 또는 B에 속하는 원소 전체 |
| 교집합 | A ∩ B | A와 B 모두에 속하는 원소 |
| 차집합 | A − B | A에는 속하지만 B에는 없는 원소 |
| 여집합 | Aᶜ | 전체집합 U에서 A를 제외한 원소 |

#### 원소의 개수 공식 ⭐

두 집합:

$$n(A \cup B) = n(A) + n(B) - n(A \cap B)$$

세 집합:

$$n(A \cup B \cup C) = n(A)+n(B)+n(C) - n(A \cap B) - n(B \cap C) - n(A \cap C) + n(A \cap B \cap C)$$

#### 드 모르간의 법칙 ⭐

$$(A \cup B)^c = A^c \cap B^c$$

$$(A \cap B)^c = A^c \cup B^c$$

#### 분배법칙

$$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$

$$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$$

### 07 명제

#### 역·이·대우

| 이름 | 형태 | 명제와의 관계 |
|------|------|--------------|
| 명제 | p → q | 기준 |
| 역 (逆) | q → p | 참거짓 무관 |
| 이 (裏) | ~p → ~q | 참거짓 무관 |
| **대우 (對偶)** | ~q → ~p | **항상 동치** ⭐ |

> 💡 명제와 대우는 항상 참·거짓이 같습니다!

#### 조건과 집합의 관계

- p → q가 참 ⟺ **P ⊆ Q** (진리집합 P, Q)
- p ↔ q가 참 ⟺ **P = Q**

#### 충분·필요 조건

p → q가 참일 때:

- p는 q이기 위한 **충분조건**
- q는 p이기 위한 **필요조건**
- p ↔ q 모두 참이면 **필요충분조건** (p ⟺ q)

#### 증명 방법

| 방법 | 언제 쓰나 |
|------|-----------|
| 직접 증명 | 가정에서 결론을 직접 도출 |
| 대우 증명 | ~q → ~p를 증명 (직접 증명이 어려울 때) |
| 귀류법 | 결론이 거짓이라 가정 후 모순 도출 |

#### 절대부등식 (산술·기하 평균)

$$a > 0,\ b > 0 \Rightarrow \frac{a+b}{2} \geq \sqrt{ab} \quad (\text{등호: } a = b)$$

## 📈 Ⅲ. 함수

### 08 함수

#### 핵심 용어

| 용어 | 의미 |
|------|------|
| 정의역 | 함수 f의 입력값(x)의 집합 |
| 공역 | 출력값이 될 수 있는 후보 집합 Y |
| 치역 | 실제로 대응된 출력값의 집합 (치역 ⊆ 공역) |
| 함수값 | x에 대응되는 y값, f(x)로 표기 |

#### 함수의 종류

- **일대일 함수**: 서로 다른 x → 서로 다른 f(x)
- **전사 함수 (onto)**: 치역 = 공역
- **일대일 대응**: 일대일 함수 + 전사 함수

#### 합성함수

$$( g \circ f )(x) = g(f(x))$$

> ⚠️ 일반적으로 g∘f ≠ f∘g (순서 중요!)

#### 역함수

- **역함수 존재 조건**: f가 **일대일 대응**일 때만 존재
- $f(a) = b \Longleftrightarrow f^{-1}(b) = a$
- 역함수의 그래프 = 원래 함수를 **y = x에 대해 대칭**이동

**역함수 구하는 순서**:
1. y = f(x) 로 놓기
2. x와 y를 서로 바꾸기
3. y에 대해 정리하기

### 09 유리식과 유리함수

#### 유리식 계산

- **약분**: 분자·분모의 공통인수를 나눔
- **통분**: 분모의 최소공배수로 맞춤
- **번분수**: 분자·분모를 뒤집어 곱셈으로 변환

#### 유리함수 표준형

$$y = \frac{k}{x - p} + q$$

| 요소 | 내용 |
|------|------|
| 점근선 | 수직: x = p, 수평: y = q |
| 대칭 중심 | (p, q) |
| 정의역 | x ≠ p인 실수 전체 |
| 치역 | y ≠ q인 실수 전체 |
| k > 0 | 1·3사분면 방향 쌍곡선 |
| k < 0 | 2·4사분면 방향 쌍곡선 |

#### 일반형 → 표준형 변환

$$y = \frac{ax+b}{cx+d} \quad \Rightarrow \quad \text{분자를 분모로 나눠 } y = \frac{k}{x-p}+q \text{ 꼴로}$$

> 💡 분자를 분모로 나눌 때 나머지가 k입니다. 나머지 = 0이면 상수함수!

### 10 무리식과 무리함수

#### 무리식의 조건

$$\sqrt{f(x)} \text{ 가 존재하려면 } f(x) \geq 0$$

#### 무리함수 표준형

$$y = a\sqrt{x - p} + q$$

| 조건 | 정의역 | 치역 | 방향 |
|------|--------|------|------|
| a > 0 | x ≥ p | y ≥ q | 오른쪽 위 ↗ |
| a < 0 | x ≥ p | y ≤ q | 오른쪽 아래 ↘ |

- **시작점 (꼭짓점)**: (p, q)
- 기본형 y = a√x를 x축 방향으로 p, y축 방향으로 q 평행이동

#### 무리함수의 역함수

$$y = \sqrt{x - p} + q \text{ 의 역함수: } y = (x - q)^2 + p \quad (x \geq q)$$

두 그래프는 **y = x에 대해 대칭**

#### 유리화 (분모에 무리식이 있을 때)

$$\frac{1}{\sqrt{a} + \sqrt{b}} = \frac{\sqrt{a} - \sqrt{b}}{a - b}$$
