## ① 수와 연산

### 1-1. 자연수 · 분수 · 소수의 사칙연산

- **자연수**: `//` 몫, `%` 나머지 — 소인수분해·GCD 알고리즘의 핵심 도구
- **분수**: 덧뺄셈 → 통분(분모 일치 후 분자 계산) / 나눗셈 → 역수를 곱하기
- **소수**: 자릿값 = 10의 거듭제곱 직관 → 중학 지수법칙 기초

```python
from fractions import Fraction
print(Fraction(2,3) + Fraction(1,4))  # 11/12 (통분 자동)
print(Fraction(2,3) / Fraction(4,5))  # 5/6  (역수 곱셈)
```

> ⚠️ Python 부동소수점 오차 주의: `0.1 + 0.2 ≠ 0.3` → `round()` 또는 `Decimal` 사용

### 1-2. 약수 · 배수 · 최대공약수(GCD) · 최소공배수(LCM)

- **약수**: n을 나누어 떨어지게 하는 수 (`n % i == 0`)
- **배수**: n의 정수배
- **GCD × LCM = a × b** — 반드시 기억할 핵심 관계식

```python
import math
gcd = math.gcd(12, 18)          # 6
lcm = 12 * 18 // gcd            # 36
print(gcd * lcm == 12 * 18)     # True
```

> 중학 연결: 소인수분해 → GCD·LCM / 분수 약분·통분의 핵심 도구

### 1-3. 분수 · 소수 변환과 크기 비교

- 분수 → 소수 변환 후 크기 비교
- 수직선 위에 올바르게 배치하는 능력 → 중학 유리수 수직선

```python
from fractions import Fraction
분수들 = [Fraction(3,4), Fraction(2,3), Fraction(5,7)]
print(sorted(분수들))  # 크기 순 정렬
```

### 1-4. 혼합 계산 (연산 순서)

**순서: 괄호 → 거듭제곱(`**`) → 곱·나눗셈 → 덧·뺄셈**

```python
print(2 + 3 * 4)        # 14  (×먼저)
print((2 + 3) * 4)      # 20  (괄호먼저)
# 방정식 역산: x * 3 + 2 = 14 → x = (14-2) / 3
```

> 중학 연결: 방정식 풀이 = 연산 순서의 역산

## ② 도형

### 2-1. 평면도형의 성질

| 도형 | 핵심 성질 | 중학 연결 |
|------|-----------|-----------|
| 삼각형 | 내각의 합 = **180°** | 내각·외각 정리, 피타고라스 |
| 사각형 | 내각의 합 = **360°** / 포함 관계 구조 | 평행사변형·마름모 증명 |
| 원 | 원주 = 2πr, 넓이 = πr² / π는 무리수 | 부채꼴 호·넓이, 접선 |

```python
import math
# 삼각형 나머지 각 구하기
third_angle = 180 - 60 - 80   # 40°
# 원 — 부채꼴 (중심각 90°)
arc = 2 * math.pi * 5 * (90/360)   # 호의 길이
```

### 2-2. 합동과 대칭

- **합동**: 대응변·대응각이 같음 → 중학 합동 조건(SSS·SAS·ASA)
- **선대칭**: y축 기준 `(x,y) → (-x,y)` / x축 기준 `(x,y) → (x,-y)`
- **점대칭**: 원점 기준 `(x,y) → (-x,-y)`

> 중학 연결: 좌표평면 대칭이동 / 고등: 함수 대칭

### 2-3. 각도와 선의 관계

- **맞꼭지각**: 두 직선이 교차 시 마주보는 각은 **항상 같음**
- **수직**: 두 직선이 만나는 각 = 90°
- **평행**: 두 직선이 만나지 않고 항상 같은 거리

```python
# 기울기로 수직·평행 판단
def line_relation(m1, m2):
    if m1 == m2:     return "평행"
    if m1*m2 == -1:  return "수직"
    return "교차"
```

> 중학 연결: 동위각·엇각 (평행선에서 각도 계산 문제의 핵심!)

### 2-4. 입체도형

- 면·모서리·꼭짓점을 세면 항상 성립: **V - E + F = 2** (오일러 공식)
- 전개도: 2D ↔ 3D 변환 감각 훈련

```python
# 오일러 공식 확인
def euler_check(V, E, F):
    return V - E + F == 2

euler_check(8, 12, 6)   # 정육면체: True
euler_check(5, 8, 5)    # 사각뿔:   True
```

## ③ 측정

### 3-1. 단위와 단위 환산

**길이**: mm × 10 → cm × 100 → m × 1000 → km

> ⚠️ 핵심: 넓이는 길이의 제곱, 부피는 세제곱으로 단위가 바뀜
> - 1m = 100cm → **1m² = 10,000cm²** (×100²)
> - 1m = 100cm → **1m³ = 1,000,000cm³** (×100³)

```python
길이_비 = 100
넓이_비 = 길이_비 ** 2   # 10,000
부피_비 = 길이_비 ** 3   # 1,000,000
```

> 중학 연결: 닮음비k → 넓이비k², 부피비k³

### 3-2. 평면도형의 둘레와 넓이

| 도형 | 넓이 공식 |
|------|-----------|
| 직사각형 | 가로 × 세로 |
| 삼각형 | 밑변 × 높이 ÷ 2 |
| 평행사변형 | 밑변 × 높이 |
| 사다리꼴 | (윗변 + 아랫변) × 높이 ÷ 2 |
| 마름모 | 대각선₁ × 대각선₂ ÷ 2 |
| 원 | π × 반지름² |

> 모든 공식은 "가로 × 세로"에서 출발 — 공식을 잊어도 유도 가능!

### 3-3. 입체도형의 겉넓이와 부피

- **기둥 부피** = 밑넓이 × 높이 (원기둥·각기둥 공통)
- **뿔 부피** = 기둥 부피 × **1/3** (원뿔·각뿔 공통)

```python
import math
cone_vol = (1/3) * math.pi * r**2 * h
cyl_vol  = math.pi * r**2 * h
print(cone_vol / cyl_vol)   # 0.3333... → 정확히 1/3!
```

> 고등 연결: 적분으로 1/3이 수학적으로 유도됨

### 3-4. 속력 · 거리 · 시간

```
거리 = 속력 × 시간
속력 = 거리 ÷ 시간
시간 = 거리 ÷ 속력
```

> 중학 연결: 일차방정식·연립방정식의 가장 자주 등장하는 문제 유형  
> 고등 연결: 미분 → 속도·가속도

## ④ 규칙성

### 4-1. 수열과 패턴

**등차수열** — 일정하게 더하는 패턴 (공차 d)
```
n번째 항 = 첫째항 + (n-1) × 공차
→ 고등: aₙ = a₁ + (n-1)d
```

**등비수열** — 일정하게 곱하는 패턴 (공비 r)
```
n번째 항 = 첫째항 × 공비^(n-1)
→ 고등: aₙ = a₁ × rⁿ⁻¹
```

```python
# 등차수열
def arithmetic(a1, d, n): return a1 + (n-1) * d
# 등비수열
def geometric(a1, r, n):  return a1 * (r ** (n-1))
```

### 4-2. 비와 비율 · 백분율

```
비율 = 비교하는 양 ÷ 기준량
백분율(%) = 비율 × 100
```

> 중학 연결: 비례식, 닮음비 / 고등: 삼각비(sin·cos·tan)

### 4-3. 비례식

**a:b = c:d → 내항의 곱 = 외항의 곱 → ad = bc**

```python
# 2:3 = □:12 → □ = 2×12/3 = 8
def proportion(a, b, d): return b * d / a
```

> 중학 연결: 일차방정식 풀이, 닮음 증명의 핵심 도구

### 4-4. 정비례 · 반비례

| 구분 | 식 | 특징 | 그래프 |
|------|-----|------|--------|
| 정비례 | y = ax | y/x = 일정 | 원점 지나는 직선 |
| 반비례 | y = a/x | x×y = 일정 | 쌍곡선 |

```python
# 정비례: y/x 항상 일정
# 반비례: x×y 항상 일정 (= 직사각형 넓이 일정)
```

> 중학 연결: **정비례 y=ax → 일차함수 y=ax+b** (b만 추가됨!)  
> 고등 연결: 반비례 → 유리함수

### 4-5. 문자를 이용한 식

```
초등: □나 △으로 모르는 수 표현
중학: x, y 로 표현 — 문자만 다를 뿐 구조는 동일!
```

```python
# 규칙을 함수로 표현
def matches(n): return 2*n + 1        # 성냥개비 패턴
def stair(n):   return n*(n+1)//2     # 계단 타일 → 등차수열의 합!
```

## ⑤ 자료와 가능성

### 5-1. 자료 수집 · 분류 · 정리

- 기준 설정 → 빈도 세기 → 표 작성
- 구간별 분류 → **도수분포표** (중학 직결)

```python
scores = [72, 85, 91, 68, 75, ...]
구간 = [(60,70), (70,80), (80,90), (90,100)]
# 각 구간의 도수·상대도수 계산
```

### 5-2. 그래프

| 그래프 | 용도 | 중학 연결 |
|--------|------|-----------|
| 막대그래프 | 항목별 비교 (간격 있음) | 히스토그램 (간격 없음) |
| 꺾은선그래프 | 시간별 변화·추세 | 일차함수 기울기 직관 |
| 원·띠그래프 | 전체 대비 비율 | 상대도수, 원그래프 각도 = 비율×360° |

### 5-3. 평균 — 대푯값의 출발점

```
평균 = 합계 ÷ 개수
```

> ⚠️ **가장 중요한 개념적 전환점**  
> 평균이 같아도 분포는 다를 수 있다!  
> `[50,50,50,50]` vs `[10,30,70,90]` → 평균 동일, 분포 전혀 다름  
> → 이 문제의식에서 **분산·표준편차(산포도)** 탄생

```python
data = [70, 85, 90, 72, 88, 95, 70, 83]
평균   = sum(data) / len(data)
중앙값 = sorted(data)[len(data)//2]     # 중학 예고
최빈값 = max(set(data), key=data.count) # 중학 예고
```

### 5-4. 가능성 — 확률의 씨앗

```
확률 = 사건의 수 ÷ 전체 경우의 수   (0 ≤ 확률 ≤ 1)
```

| 표현 | 수치 |
|------|------|
| 불가능하다 | 0 |
| 반반이다 | 0.5 = 1/2 |
| 확실하다 | 1 |

**경우의 수 핵심 법칙**
- 합의 법칙: A 또는 B → 더하기
- 곱의 법칙: A 그리고 B → 곱하기

```python
from itertools import product
# 주사위 2개 — 합이 7인 경우
주사위 = list(product(range(1,7), repeat=2))
합7 = [d for d in 주사위 if sum(d)==7]
print(f"확률: {len(합7)}/{len(주사위)}")  # 6/36 = 1/6
```

> 고등 연결: 순열(nPr)·조합(nCr)·이항분포·정규분포

